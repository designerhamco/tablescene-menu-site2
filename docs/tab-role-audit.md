# 탭 역할 적용 점검표

2026-10-28. 공식 사이트 전체 페이지 소스와 공통 선택 컨트롤 사용처를 조사했다. 같은 컴포넌트를 공유하는 경로는 [최종 역할 기준](tab-hierarchy-contract.md)을 상속한다. URL이나 고정 단계로 형태를 정하지 않는다.

| 페이지·영역 | 판단과 적용 |
| --- | --- |
| /faq, /faq/notices | FAQ/공지사항 전환 탭 없음. 고객센터는 FAQ 아래에 최신 공지3건·전체보기. 전체보기는 별도 공지 목록으로 이동하며 기존 /faq?tab=notices도 이 경로로 연결. 주제는 CategoryFilter 밑줄, 검색·아코디언·페이지네이션 유지 |
| /templates | 서비스 page → 디자인/기본 section → 업종/화면 구성 필터·Select → 결과. 디스플레이는 불필요한 하위 종류 탭 생략 |
| /design-system | 기준·토큰/라이브러리는 page. 본문 바로가기는 링크. 두 대표 포함 관계를 실제 공통 컨트롤로 조작하는 예시와 역할 표 제공 |
| /guides | 서비스별 전체 문서는 page. 해당 문서 목차는 작은 링크. 본문 앵커 유지 |
| /mypage?tab=menus | 이용 중/보관 중/종료됨은 state. 메뉴 카드 편집·미리보기는 실행/이동 버튼이며 탭 아님 |
| /mypage?tab=payments | 결제내역/AI 충전·사용내역은 section. 상태·날짜는 조회 폼. 금전 동작 변경 없음 |
| 마이페이지·헤더 알림, /notifications | 전체/읽지 않음은 category 밑줄형 목록 분류. 모바일 벨은 마이페이지 셸 없는 /notifications로 이동, 768px 이상은 알림 레이어. 공통 NotificationPanel의 피드·날짜·읽지 않은 표시·활성화 동작 유지 |
| 마이페이지 문의, /mypage/inquiries | 검색·문의 상태는 조회 폼/Select. 문의 작성·페이지네이션은 각 기능 유지 |
| 마이페이지 좋아요·계정, /mypage/staff | 기존 목록·폼·사이트 내비게이션. 탭 없는 곳에 새 탭 추가하지 않음 |
| /mypage/menus/[id]/edit 전체 설정 | 기본 정보/커버/메뉴판/디자인/광고/다국어/공개 설정은 page 링크. 언어는 state, 그 안 번역 대상은 section |
| /mypage/menus/new | 템플릿 주제는 CategoryFilter. 실제 템플릿 선택은 radio 카드. 사설 site-tab/색상 조합 제거 |
| /mypage/operations | 운영할 메뉴판은 state. 사이드바는 사이트 내비게이션 |
| 주문·호출 내역/설정 | 내역/설정 이동은 page 링크. 개별 상태·필터는 조회 폼. 실제 저장·운영·금전 동작 변경 없음 |
| 테이블/QR·매출·가져오기·전환·관리 미리보기 | 폼·조회·실행 컨트롤 유지. 설정 이동은 공통 NavigationTabs 역할 상속 |
| 홈·서비스 소개·템플릿 상세 | 홈 배치 데모는 state. 업종·짧은 FAQ 주제는 해당 영역 안 작은 필터. 이미지 갤러리·아코디언은 각 기능 유지 |
| /pricing, 상품 안내 | 상품 유형과 가격·설명·제공 범위를 묶는 OfferCard는 section. 실제 가격·구매·결제 변경 없음 |
| /apply 및 신청 별칭 | 설명 있는 선택 카드·Select 유지. 새 탭 만들지 않음 |
| 로그인·가입·복구·약관·정책·상세 공지 | 입력·링크·읽기 화면. 탭 없음. 공통 헤더·내비게이션 상속 |
| 관리자 공지 | 문서 목록 링크·글자 서식 토글은 각 기능 유지. 새 탭 없음 |
| 고객 메뉴판·공개 주문/호출/수령 | 사이트 탭 시스템과 분리. 고객 콘텐츠·메뉴 렌더러·제품 고유 조작 변경 없음 |

이전 고객센터 예외·고정 단계 표는 이 점검표로 대체한다. 실제 브라우저 검수·배포 결과는 docs/area-tabs-qa.md에 기록한다.
