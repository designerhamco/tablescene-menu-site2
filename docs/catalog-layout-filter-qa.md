# 카테고리 아이콘·디자인 템플릿 화면 구성 필터

2026-10-25 사용자 요청: 리스트형/앨범형 카테고리의 참고 아이콘과 비슷한 모양을 적용하고 디자인 템플릿 오른쪽 위에 같은 아이콘을 포함한 화면 구성 선택창을 추가한다.

## 구현

- 점 세 개와 가로선의 리스트, 사진 네 칸과 하단 설명선의 앨범 아이콘을 SVG로 작성했다. 외부 이미지·폰트·라이브러리 추가 없이 현재 색상을 따른다. PC 기본 카테고리 20px, 모바일 22px, 선택창 값/옵션 20px로 공유한다.
- 선택창은 기존 Radix Select와 사이트 필드·드롭다운 토큰을 사용한다. 태블릿 기본 템플릿도 같은 선택창으로 아이콘을 표시하며, 업종의 기존 네이티브 select는 유지한다.
- 디자인 템플릿 결과 행의 오른쪽에 전체 구성/리스트형/앨범형을 배치한다. 업종과 itemLayout의 교집합으로 실제 목록/개수/페이지를 계산한다. 현재 디자인 템플릿은 모두 리스트형으로 등록되어 있다. 앨범형은 빈 결과와 준비 중 안내를 표시하며 존재하지 않는 디자인이나 미리보기 링크를 만들지 않는다.
- `layout=list|album`을 기존 plan/category/filter와 함께 보존한다. 새로고침에도 복원하고 잘못된 값은 전체 구성이다. 화면 구성 변경 시 업종은 유지하고 페이지만 1로, 종류/서비스 전환 시 업종과 화면 구성/페이지를 모두 초기화한다. 기본 템플릿과 Display에는 오른쪽 필터를 표시하지 않는다.

## 검수

- `npm test`: 832건 통과. 기존 계약 테스트에 업종/화면 구성 교집합과 잘못된 값 정규화 검증을 추가했다.
- TypeScript, 변경 파일 ESLint, 최적화 빌드, diff check 통과.
- 실제 브라우저 viewport 폭 320/390/640/767/768/820/1024/1440/1920px × 두 종류 18조건: 가로 넘침 0, 기존 카테고리 분기, PC/모바일 아이콘 크기, 40px 선택창, 결과 영역 오른쪽 정렬을 확인했다. 모든 선택창의 세 옵션에 아이콘이 있고 팝업이 화면 경계를 벗어나지 않는다.
- 앨범형 빈 결과, 카페베이커리+앨범형 조합/새로고침 복원, 카페베이커리+리스트형 4개, 2페이지에서 리스트형 선택 시 1페이지/6개로 초기화, End/Enter 앨범형 선택 및 trigger 포커스 복원을 확인했다.
- 다이닝 전환 시 전체 구성/2개와 기존 요금 유지, Display 전환 시 필터 숨김/1개/신청 준비 중을 확인했다.
- 태블릿 820px 기본 선택창의 앨범형 2개와 선택값 아이콘, 모바일 390px의 리스트형 4개/카테고리 아이콘을 확인했다. 브라우저 오류 0건이다.
- 실제 계정의 좋아요·메뉴판/설정 저장·결제를 실행하지 않았다. 운영 반영은 Vercel 성공과 공개 `/apply` 화면으로 확인한다.
