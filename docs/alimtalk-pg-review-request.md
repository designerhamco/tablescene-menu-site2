# 아티메뉴 알림톡 충전 상품 PG 계약 확인 문의

2026-11-25. **사용자 승인 후 17:41 KST 포트원 공식 채널톡에 발송했고, 운영시간에 순차 답변한다는 자동 안내를 확인했다. 상담원 답변은 아직 없다.** 회사명·사용자가 승인한 가입 이메일·아래 상품 조건만 전달했다. API 키·고객 연락처·카드 정보·사업자 서류는 전달하지 않았고 계약 신청은 하지 않았다. 비공개 상담 주소와 가입 이메일은 저장소에 기록하지 않는다.

사용자 로그인 후 포트원에서 실연동 채널 0개·테스트 채널 4개·전자결제 신청 내역 없음으로 확인했다. 로컬 연결은 NHN KCP 테스트이며 사용자는 별도 PG 계약이 없다고 답했다. **과거 계약 준비 문서 `pg-site-review-readiness.md`는 KG이니시스 기준이다. 현재 KCP 테스트 설정은 확인했지만, KG이니시스에서 KCP로 변경하기로 사용자가 확정한 기록은 확인하지 못했다.** 앞서 테스트 설정만으로 KCP가 확정된 방향이라고 기재한 것은 잘못이다. 17:41 문의는 실제로 KCP를 기준으로 보냈으며 그 발송 이력은 그대로 보존한다. 이 시점에는 추가 문의·계약 신청·PG 설정 변경을 하지 않았다. 어느 PG를 선택하든 알림톡 충전 상품의 취급 조건을 확인해야 한다.

공식 근거: [포트원 포인트 충전 서비스 안내](https://help.portone.io/content/point-service). 충전형 상품의 취급·사용기간·환불 조건은 PG 및 카드사 심사에 따라 달라질 수 있으므로, 아래 실제 운영 조건을 기준으로 기존 계약 적용 또는 추가 심사 여부를 확인한다. 사용자 승인 없는 만료 기간 변경이나 임의의 수수료 공제는 하지 않는다.

## 전달할 서비스 설명

디앤디커머스가 운영하는 아티메뉴는 매장용 온라인 메뉴판·주문 운영 SaaS입니다. 기존 서비스 이용료와 별도로 조리완료 알림톡 이용대금을 선충전하는 기능을 준비하고 있습니다.

- 판매 대상: 아티메뉴를 이용하는 매장 운영자.
- 결제 금액: 10,000원 / 30,000원 / 50,000원, 부가세 포함.
- 사용 용도: 해당 계정이 관리하는 메뉴판의 조리완료 카카오 알림톡 발송 비용만 차감.
- 차감 기준: 성공 1건당 12원, 실패 시 해당 발송 금액 반환. 재발송 성공도 1건 과금.
- 계정 간 양도·송금, 다른 업체 결제, 별도의 현금 인출 기능 없음.
- 별도 소멸 기간 없이 유지하는 방식을 희망함.
- 미사용 유상 잔액 전체를 수수료 공제 없이 충전 당시의 원래 결제수단으로 환불. 사용한 발송비 제외. 여러 원 결제가 있으면 결제별로 부분/전체 취소.
- 일회성 인증 카드 결제 사용. 자동 충전·정기 청구는 이번 범위에 없음.

## 확인할 질문

1. 현재 NHN KCP 테스트 채널로 아티메뉴 구독 결제를 검수 중이며 실계약은 아직 없습니다. 신규 KCP 계약에 구독 결제와 이 알림톡 충전을 함께 포함할 수 있나요? 별도 상품 심사나 MID 분리가 필요한가요?
2. 위의 ‘소멸 기간 없음’ 조건으로 취급 가능한가요? 불가하다면 허용 가능한 계약 조건과 대안을 안내해 주세요.
3. 원 결제의 일부 금액 취소 및 여러 원 결제에 나눈 환불을 지원하나요? 취소 가능 기간과 수수료·정산 조건은 무엇인가요?
4. 결제 화면·상품 안내·환불 규정에 필요한 고지와 심사 제출 자료는 무엇인가요?
5. 별도 계약/승인이 필요하다면 기존 구독 결제 MID에 영향 없이 테스트 채널에서 먼저 결제·취소 대사를 검수할 수 있나요?

API Secret·Appkey·고객 연락처·카드 정보는 이 문의에 포함하지 않는다. 원 문의 내용과 가입 이메일 전달은 각각 사용자 승인을 받았다. 다른 데이터나 계약 신청은 이번 승인에 포함하지 않는다.

## KG이니시스 추가 문의 발송

2026-11-25 21시대. 사용자가 KG이니시스 기준 추가 문의를 명시적으로 요청해 같은 포트원 공식 상담에 발송했다. 페이지 새로고침 후에도 새 메시지가 남아 있는 것을 확인했다. 상담창은 다음 날 오전 10시부터 운영으로 표시했고 담당자 답변은 아직 없었다. 계약 신청·서류 업로드·약관 동의·결제 실행·PG 설정 변경은 하지 않았다. 가입 이메일을 다시 입력하거나 새로운 개인정보를 전달하지 않았다.

아래 희망 조건을 충족하면 KG이니시스로 진행하는 방향을 우선 검토한다고 전달했다. 음식점 손님의 음식값이 아니라 점주가 아티메뉴에 내는 SaaS 월 구독료와 알림톡 이용대금임을 구분했고, 충전은 정기/자동 충전이 아닌 일회성 카드 결제라고 명시했다.

1. 구독 카드 빌링과 알림톡 선충전을 함께 취급할 수 있는지, 각각 MID·특약·카드사 심사와 충전 업종 분류가 무엇인지.
2. 별도 소멸 기간 없이 유상 잔액을 유지할 수 있는지. 불가하다면 허용되는 이용기간과 조건.
3. 미사용분을 원 카드에 부분 취소하거나 여러 원 결제에 나누어 환불할 수 있는지. 별도 취소 수수료와 정산 후 취소에 필요한 재원·절차.
4. 원 카드 취소 기한이 지난 잔액의 환불 방법. PG 별도 환불 또는 구매자 본인 확인 후 계좌 환불의 허용 여부, 필요 확인·서류·수수료, 현금화 금지와 미사용 서비스 대금 환불의 구분.
5. 오픈 일정에 필요한 계약·빌링 특약·카드사 심사 서류 및 예상 소요 기간. 충전 심사가 늦어져도 월 구독부터 별도 승인·개통할 수 있는지.
6. 일반결제·빌링 수수료, 가입·연관리비, 정산 주기, 보증보험·결제 한도 조건.
