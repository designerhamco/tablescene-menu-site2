# 연결형 탭·말풍선·이모지 검수 — 2026-10-25

## 범위

사이트 공통 Tabs의 contained 변형을 추가하고 `/apply` 디자인/기본 목록에 연결했다. HelpTooltip/Tooltip에는 노란 brand 변형, ChoiceTile에는 시스템 이모지 옵션을 추가했다. `/design-system`은 실제 동작하는 예시를 제공한다. 실제 고객 메뉴 렌더러와 저장 데이터·결제·권한 동작은 변경하지 않는다.

## 브라우저 검수

- 실제 DOM viewport PC1440×1000, 태블릿820×1180, 모바일390×844/320×740에서 가로 넘침0px.
- 연결형 탭은 PC·태블릿192px,390px에서는171px,320px에서는136px로 표시된다. 높이는48~49px, 업종 선택은44px를 유지한다. 탭 목록 뒤의 회색 띠는 사용하지 않으며 선택 탭은 검정, 비선택 탭은 아주 옅은 회색, 패널은 흰색으로 구분한다.
- ArrowRight·Home·End 전환과 URL(category/plan/filter), 디자인/기본 목록·가격 변경, 리스트/앨범 필터, 업종 빈 목록과 전체 초기화,2페이지의 ROSY ORANGE 표시를 확인했다.
- 디스플레이는 종류 탭을 숨기고 기존 신청 준비 상태를 유지한다.
- 노란 안내 말풍선은 rgb(248,231,49)/검정 글자/꼬리로 렌더링된다. 닫기·재열기·Escape·외부 버튼 클릭 닫기를 확인했다.320px에서 실제 경계는 x16~304px이며 가로 넘침은0px다.
- 짧은 힌트는 키보드 Tab 포커스로 표시된다. 장식 이모지는 aria-hidden 영역에 있고 선택 버튼의 접근성 이름은 기존 문구다.
