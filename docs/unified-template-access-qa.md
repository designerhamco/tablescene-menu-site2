# 서비스별 단일 요금·전체 템플릿 접근 검증 (2026-11-25)

사용자 승인: 베이직·다이닝·디스플레이는 각각 현행 서비스 요금을 유지하고, 같은 서비스 안의 기본/디자인 템플릿은 동일 요금·권한으로 이용한다. 템플릿 교체는 이용권 전환이나 추가 청구를 만들지 않는다. 기존 템플릿 외형·메뉴 데이터·QR·운영 기능 게이트는 유지한다. 장식 설정에서는 실제 두께·스타일을 표시하며 inherited 값을 자동 저장하지 않는다.

임시 QA 페이지는 검증 후 제거한다. 과거 결제의 미완료 복구는 기존 저장 금액을 검증하며 새 가격표로 덮어쓰지 않는다. 미래 정상 갱신은 식별 가능한 과거 디자인 추가 요금만 제외하는 계산을 검증했다. 이 작업을 위해 실제 첫 결제·자동 갱신·환불·고객 템플릿 교체·SQL migration을 실행하지 않았다. 운영 배포 및 공개 화면 확인은 릴리스 결과에서 별도로 보고한다.
