# 아티메뉴 약관·개인정보·동의 검토 현황

기준일: 2026-11-11. **문서 위치·구현 확인·남은 검토를 구분한 내부 기록**이다. 새로운 약관이나 법적 적합성 확인서가 아니며 공개 전문, 정책, 동의 UI, 실제 처리/보관 설정을 변경하지 않는다.

## 공개 전문과 기준일의 원본

| 대상 | 원본 | 공개 경로 |
| --- | --- | --- |
| 이용약관 | [legal-documents.ts](../lib/legal-documents.ts)의 `termsContent` | [약관 페이지 코드](../app/terms/page.tsx), `/terms` |
| 개인정보 처리방침 | [privacy/page.tsx](../app/privacy/page.tsx)의 `privacyContent` | `/privacy` |
| 공통 시행일·프로모션 기간 | [policy-dates.ts](../lib/policy-dates.ts) | 각 공개 화면 |
| 상품 제공/체험·해지 안내 | [public-product-details.ts](../lib/public-product-details.ts) | 상품/신청/요금 안내 |
| 동의 유형·버전 초안 | [consent-records.ts](../lib/consent-records.ts) | 실제 가입/결제/마케팅 저장 경로와 별도 대조 필요 |

약관과 개인정보 전문을 별도 MD에 복제하지 않는다. 원문이 두 군데에서 달라지는 것을 막기 위해 MD는 원본과 검토 상태를 안내한다. 시행일과 동의 증빙 버전은 같은 값이라고 추정하지 않고 각 실제 저장 경로를 확인한다.

## 확인한 사실과 남은 확인

- 공개 약관/개인정보 원문은 존재한다. 2026-11-11에 공개 `/terms`, `/privacy`, `/pricing`을 로그인/쓰기 없이 조회해 HTTP 200과 주요 본문을 확인했다. 모든 조항의 최신 법령·실제 처리 정합성 검토를 완료한 것은 아니다.
- `consent-records.ts`의 약관/개인정보 버전은 현재 `2026-open-todo`이고 전용 동의 레코드 저장 TODO가 있다. 마케팅 동의 API도 이 버전 상수를 읽는다. 결제·가입에는 별도 증빙/저장 경로가 있을 수 있으므로 이것만으로 모든 동의 저장이 없다고 단정하지 않는다. 실제 경로별 원문 버전·시각·증빙 연결을 확인해야 한다.
- [계정 탈퇴 API](../app/api/account/delete/route.ts)는 `deletion_requested` 처리와 `hardDeleted: false`를 반환한다. [notification-events.ts](../lib/notification-events.ts)의 회원탈퇴 후 파기 고지 정책도 미활성/TODO다. 탈퇴 요청, 접근 차단, 복구 가능 기간, 실데이터 파기와 고지의 정합성은 별도 확인이 남아 있다.
- 무료체험/첫 결제/해지, 월·과거 연간 계약의 환불, 무료·구매 크레딧 구분, 실제 수집 항목/수탁자/국외 이전/보유 기간·백업과 공개 고지를 경로별로 대조해야 한다. 이전 검토에서 제기됐다는 이유만으로 지금도 모두 오류라고 보거나 이미 해결됐다고 보지 않는다.

## 검토 작업의 경계

위 미확인 사항은 위법 판정이나 정책 변경 승인으로 취급하지 않는다. 실질적인 약관/개인정보 개정이나 처리/보관 변경을 진행할 때 현재 법령·제공자 정책·실제 운영을 다시 확인하고, 적용할 변경과 시행/동의/고지/기존 계약 영향을 구체화한다. 이번 정리는 문서 탐색과 상태 기록이며, 실제 전문·가격·동의값·Production DB/Auth/Storage·결제/환불은 변경하지 않는다.
