# 기본 6종 로고·다이닝 커버 이미지 미리보기 — 2026-10-20

## 적용 범위

- 기본 6종 ‘영역·이미지’에 로고 체크를 추가한다. 기본 OFF이며 ON이면 가게명 위치에 중립 3:1 로고 자리 SVG를 보여준다. OFF로 돌아오면 가게명을 복원한다. 샘플 3:1은 업로드/표시 고정 비율이 아니다.
- 로고는 원본 비율을 유지하고 너비 75% 이내, 높이 20svh/12rem 이내에서 맞춘다. 모바일 높이 상한은 8rem이며 로고만 중앙 정렬한다. 가게설명과 메뉴의 기존 정렬·모바일 간격은 유지한다.
- 상단행 로고는 기존 텍스트 높이 계산 대신 같은 `getCanvasHeaderRatio`의 8~14% 예산을 사용한다. 로고에는 PC 한 줄 텍스트 전용 간격 축소를 적용하지 않는다. 로고/텍스트 왕복 시 높이 계산을 서로 넘기며 이미지가 헤더를 넘지 않도록 제한한다.
- 기본 다이닝은 커버 제목을 로고로 대체한다. 페이지/카테고리 제목과 좌측 내비게이션 문구는 유지한다. 기존 다이닝의 로고+제목 병기는 그대로다.
- 기본 다이닝에 독립 ‘커버 이미지’ 체크를 추가한다. 기본 OFF는 흰 배경이다. ON이면 이미지 위 검정색 75% 오버레이, 밝은 커버 제목/가게설명/페이지 이동 표시를 사용한다. 커버 밖 본문 팔레트는 유지한다.
- 기기/언어/새 창 URL에 두 선택값을 보존한다. 고객 데이터·저장 메뉴·기존 템플릿의 로고/커버 설정을 변경하지 않는다. 로고의 초기 요청이 hydration 전에 실패해도 기본 시안에서 가게명으로 복원한다.
- 다이닝 커버/일반 페이지/좌측 내비게이션 배경 및 별도 커버 설명색 편집은 이번에 구현하지 않는다. `docs/menu-editor-color-plan.md`에 후속으로 정리했다.
