# 디자인 템플릿 상세페이지

2026-10-19 사용자 제공 상세페이지 이미지의 2열 구성을 기존 ArtiMenu 사이트 시스템에 적용했다.

## 화면과 동작

- `/apply`의 썸네일과 상품명은 `/templates/[templateKey]`로 같은 창에서 이동한다. 목록의 `미리보기`는 기존 새 창 동작을 유지한다.
- 768px 이상은 왼쪽 설명과 오른쪽 정보의 2열이다. 처음에는 오른쪽 전체를 자연 높이로 펼쳐 페이지와 함께 스크롤한다. 미리보기/시작 버튼의 하단이 viewport 하단 여백에 도달하면 갤러리를 숨기고 헤더 아래 정보·하단 액션을 고정한다. 처음부터 전체가 들어가는 긴 화면에서는 열 상단이 헤더 아래 고정 위치에 도달한 뒤 전환한다.
- 고정 상태에서만 오른쪽 정보에 높이 제한을 적용하며, 넘칠 때만 내부 스크롤한다. 원래 펼친 열의 높이로 전환 지점을 계산하고 갤러리 안쪽 크기는 유지해, 축소로 인한 경계 흔들림을 방지한다. 위로 돌아가면 고정을 해제하고 갤러리/선택 상태를 복원하며 내부 스크롤을 초기화한다. 열 끝에서는 사이트 푸터를 덮지 않는다.
- 버튼 위 32px 흰색 페이드는 실제로 아래에 남은 내용이 있을 때만 표시하고, 끝까지 스크롤하거나 높이가 충분해지면 숨긴다. 폰트/이미지·기기 크기·페이지 스크롤 변화에도 다시 측정한다. 스크롤 영역은 키보드 Home/End로도 접근하며 버튼 위치와 페이지 스크롤은 유지한다.
- 상세페이지에서는 모든 기기의 AI 상담·위로가기 퀵 메뉴를 숨긴다. 공통 헤더의 선택적 prop으로 이 호출부에만 적용하며, 목록과 다른 사이트 경로의 퀵 메뉴는 유지한다.
- 767px 이하는 기존 템플릿 정보·이미지 선택·요금·액션·구독 안내 순서를 보존하고 설명 전체를 자연스럽게 이어 읽는다. 버튼 고정·내부 스크롤·페이드는 적용하지 않는다.
- 왼쪽 첫 실제 디자인 이미지 아래에 대표 영역·상품 이미지·가격 옵션·기간 할인·위젯·광고·호출·주문 8개 기능의 표를 둔다. 큰 `사용 방법` 버튼은 가이드 제작 전까지 비활성으로 표시한다. 연결 시 새 창의 베이직 탭을 사용한다.
- 이후 동일한 8개 순서로 1180×820 태블릿 시연 → 제목/설명을 반복한다. 실제 카탈로그 미리보기 렌더러에 복제한 짧은 샘플 데이터를 전달한다. 화면에 보일 때만 iframe을 유지하며 정지/재생·단계 선택·다시 보기와 동작 줄이기 설정을 지원한다.
- 지원 기능은 실제 capability를 따른다. 베이직 앨범의 가격 열·다이닝 기간 할인·Display 인터랙션 등 지원하지 않는 항목은 지원 범위를 적고 베이직 공통 기능 예시로 구분한다. 다이닝 가격 옵션은 상품별 입력으로 설명하고 앨범 이미지는 1:1/4:5/5:4 비율을 안내한다.
- 호출·후불 주문 시연은 기존 `previewOnly` 분기만 사용한다. 호출 항목 선택/전송 완료와 상품 담기/장바구니/후불 주문/주문내역까지 보여주며 실제 요청을 전송하지 않는다. 일회용 시연 장바구니는 일반 미리보기와 다른 세션 범위를 사용하고 정리한다.
- 갤러리는 전체 화면과 좌/우 확대를 제공하고 썸네일·이전/다음·키보드 좌우 키로 선택한다. 링크 복사는 현재 URL을 클립보드에 저장하고 성공/실패를 안내한다.
- 요금과 신청 링크는 기존 `getTemplateDetailInfo`의 카탈로그 가격/디자인 ID 연결을 유지한다. Display의 신청 준비 중 상태도 유지한다.
- 판매 중인 기본 디자인 10종과 디자인 템플릿 10종만 상세페이지를 연다. 모르는 키·종료·숨김·삭제 템플릿은 404이며 기본 템플릿으로 대체하지 않는다.
