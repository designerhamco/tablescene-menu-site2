# 디자인 템플릿 상세페이지

2026-10-19 사용자 제공 상세페이지 이미지의 2열 구성을 기존 ArtiMenu 사이트 시스템에 적용했다.

## 화면과 동작

- `/apply`의 썸네일과 상품명은 `/templates/[templateKey]`로 같은 창에서 이동한다. 목록의 `미리보기`는 기존 새 창 동작을 유지한다.
- 768px 이상은 왼쪽 설명과 오른쪽 정보의 2열이다. 오른쪽은 기본 사이트 헤더 아래에 sticky로 고정한다. 짧은 화면에서는 정보 열 내부를 스크롤해 요금·버튼까지 접근할 수 있다. 푸터에서는 고정을 해제한다.
- 767px 이하는 템플릿 정보·이미지 선택·요금·액션을 먼저 배치하고 설명 전체를 자연스럽게 이어 읽는다.
- 왼쪽 첫 실제 디자인 이미지 아래에 번호/아이콘/기능/설명의 4개 요약 그리드를 둔다. 이후 각 섹션은 이미지 영역 다음에 설명을 배치한다.
- 설명 이미지는 기존 실제 템플릿 캡처와 HTML 편집/기능 예시로 구성한다. 예시 UI는 실제 편집 기능처럼 동작하는 입력창이나 버튼을 만들지 않으며 예시임을 표시한다.
- 디자인 커스터마이징, 메뉴/가격/품절 관리, 다국어/QR, 할인·위젯을 설명한다. 멀티페이지는 마지막 영역을 커버/코스/단품 페이지로, Display는 이미지·동영상 소개로 분기한다.
- 호출·후불 주문은 현재 capability가 허용하는 베이직/다이닝에만 설명한다. 이용 매장 한정과 사전 이용 가능 여부 확인·매장 설정 조건을 명시한다. 실제 호출/주문·결제 동작은 연결하지 않는다.
- 갤러리는 전체 화면과 좌/우 확대를 제공하고 썸네일·이전/다음·키보드 좌우 키로 선택한다. 링크 복사는 현재 URL을 클립보드에 저장하고 성공/실패를 안내한다.
- 요금은 `template-subscription-pricing.ts`에서 가져오며 시작 버튼은 템플릿의 실제 키와 월결제 상품 키를 유지한다. Display의 신청 준비 중 상태도 유지한다.
- 판매 중인 템플릿 10종만 상세페이지를 연다. 모르는 키·종료·숨김·삭제 템플릿은 404이며 기본 템플릿으로 대체하지 않는다.

## 디자인 경계

공통 컨테이너·의미 타이포·`--ui-*`/`--site-*` 토큰과 사이트 버튼을 재사용한다. 새 스타일은 상세페이지 CSS module에 한정한다. 고객 메뉴판 엔진·기본 팔레트·fit·모바일 읽기 간격·회원/결제/DB 계약은 변경하지 않는다.

## 검증 명령

```sh
npm test
npx tsc --noEmit
npx eslint 'app/templates/[templateKey]/page.tsx' components/templates/TemplateDetailGallery.tsx components/templates/TemplateDetailStory.tsx components/apply/TemplateGallery.tsx lib/template-details.ts scripts/qa-template-details.mjs
npm run build
TEMPLATE_DETAIL_QA_BASE_URL=http://127.0.0.1:3011 node scripts/qa-template-details.mjs
git diff --check
```

검수 스크립트는 실제 DOM viewport, 가로 넘침·깨진 이미지, PC/태블릿 고정 위치·좁은 높이에서 액션 접근, 모바일 정보 순서, 접근성, 판매 템플릿 전체, 이미지/링크 복사/신청/404 경로를 확인한다. 결과와 화면은 `/tmp/artimenu-template-detail-qa`에 저장한다.
