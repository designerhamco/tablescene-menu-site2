# 디자인 템플릿 찾기 — 2026-11-11

디자인 템플릿 페이지는 베이직·다이닝·디스플레이와 기본/디자인 템플릿 탭을 유지한다. 왼쪽 업종 목록과 별도 화면 구성 선택을 상단의 **업종 / 분위기 / 색상 / 레이아웃** 셀렉트로 통합한다. 기본값은 각 필터의 대표명이며, 선택 메뉴의 전체 항목으로 해제할 수 있다.

- 기존 공통 Select, Input, FieldActionRow, Button을 사용한다. 필터 아이콘은 업종·분위기·색상·레이아웃의 의미를 전달하며 색상 옵션은 색점과 이름을 함께 표시한다. 독립 폰트·필드 크기·색상·상태를 만들지 않는다.
- 이름 검색은 대소문자·공백·전각 문자 차이를 정규화한 부분 일치다. 등록된 한글·영문 이름을 함께 검색하며 설명은 검색하지 않는다. 업종·분위기·색상·레이아웃·이름은 모두 AND 조건이다. 데이터 조회나 고객 데이터 수정은 필요 없다.
- 분위기와 색상은 `lib/catalog-facets.ts`의 편집 분류이며 기본 메뉴 디자인을 설명한다. 목업 사진이나 고객이 저장한 색상으로 추정하지 않는다. 새 디자인에는 등록된 분위기·색상 태그를 추가해야 한다. 기본 디자인은 흰색/검정색의 중립 구성이고 업종 공통이다.
- 썸네일 크게/작게 보기 도구는 필터 오른쪽에 둔다. 모바일은 필터 아래 결과 건수의 오른쪽에 배치한다. 큰 보기 1/2열, 작은 보기 2/3열로 전환하며 이름·설명·좋아요·상세/이미지 캐러셀을 유지한다. 한 페이지 6개와 페이지 선택은 그대로다. 크기 전환은 필터·검색·현재 페이지를 바꾸지 않는다. 보기 크기 전용 규칙은 해당 목록의 data 속성에만 적용하며 마이페이지 좋아요 목록의 열 수는 유지한다.
- 필터나 검색 변경은 1페이지로 돌아간다. 서비스/템플릿 종류 전환은 필터를 초기화하고 입력한 이름과 썸네일 크기는 유지한다. 빈 결과의 전체 보기로 검색·필터를 함께 해제할 수 있다.
- URL의 `plan`, `category`, 기존 `filter`(업종), `layout`, 새 `mood`, `color`, `q`, `view=small`을 통해 새로고침/공유 시 복원한다. 이전 기본 템플릿의 `filter=list|album` 주소도 레이아웃 필터로 해석한다. 알 수 없는 선택은 기본값으로 처리한다.
- 검색·필터·보기 전환 영역과 썸네일 목록은 공통 `site-content-divider`와 `site-stack-group` 간격으로 구분한다.
- 구성 간격은 기존 `--site-space-*` 토큰을 사용한다. 좁은 화면의 필터는 확보 가능한 폭에 따라 줄을 나누며 페이지 가로 넘침을 만들지 않는다. 고객 메뉴판 렌더러·결제/구독·메뉴 편집은 범위 밖이다.
