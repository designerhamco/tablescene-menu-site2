# 설명·도움말 정리 기록 — 2026-11-06

사용자 요청: 직관적인 UI를 설명서처럼 반복하지 않는다. 직접 요청한 안내, 박스 내부 설명, 상태·오류·빈 목록·데이터 정보는 보존한다. 화면 검수는 사용자가 수행하므로 이번 작업에서는 브라우저를 열지 않았다.

## 범위와 결정

`app/**/page.tsx` 85개 경로 파일과 연결된 공통 화면·팝업의 JSX를 코드 기준으로 분류했다. 리다이렉트 경로는 목적지 화면을 기준으로 판단했다. 동적 경로의 모든 계정·데이터 조합을 화면으로 검증했다는 의미가 아니다.

## 보존 확인

수정한 제품 화면의 JSX를 기준 리비전과 비교했을 때 `ContentPanel` / 카드 / 테이블 셀 / 작업 영역 / 안내 박스 내부 문단 109개가 동일하게 남아 있다. 디자인 시스템 자체의 규칙 설명은 사용자에게 요청받은 문서 콘텐츠이며 이 비교에서 제외했다.

다음 안내는 특히 보존한다.

- 테이블 관리 모바일 첫 진입의 PC 편집 권장 팝업
- 연결 팝업의 실제 OS·모델·브라우저, 기본 접힘의 선택 입력 설명, 연결 처리·성공 상태와 명시적 메뉴판 열기의 로그아웃 확인
- 실제화면 보기의 브라우저 확대·축소/전체화면 안내와 가이드 진입
- 알림 표시·보관 안내, 삭제/배치 해제 구분, 저장 실패/미저장 경고
- 박스 안 문구와 데이터 건수·수치·상태·기간·현재 대상

## 자동 적용

`SitePage` / `SitePageHeader`는 제목만 기본으로 쓴다. 필요한 설명은 `descriptionPurpose`를 명시해야 타입 검사와 `copy-purpose` 소스 검사를 통과한다. 설명을 제거해도 공통 제목→첫 콘텐츠 간격과 버튼 위치는 변경하지 않는다. 새 규칙은 문장의 필요성을 판단하는 기준이며, 본문을 CSS로 일괄 숨기는 방식으로 구현하지 않는다.

`site-copy-policy.test.ts`는 제목 전용 헤더, 사용자 요청/상태/데이터 보존과 도움말 이동을 확인한다. `check:site-ui`에 포함되어 모든 빌드에서 실행된다. `/design-system`의 ‘설명·도움말’ 예시와 공통 규칙 표는 같은 정책 데이터를 사용한다.

## 검증 결과

전체 테스트 1,098개와 공통 UI 계약 127개, 별도 TypeScript 검사(`tsc --noEmit --incremental false`), 프로덕션 빌드가 통과했다. 린트 오류는 없으며 기존 QA 스크립트의 미사용 import 경고 1개는 이번 범위에서 변경하지 않았다. 사용자 요청에 따라 브라우저 화면 검수는 수행하지 않았다.
