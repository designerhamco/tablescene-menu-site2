# AI 상담 웰컴형·노란 캐릭터 검수

## 범위

- 선택된 웰컴형을 실제 상담 폼에 적용하고 영문 칩과 하단 중복 탐색 링크를 제거한다.
- 투명 PNG 캐릭터는 원래 모양·투명도를 보존한 384×384 WebP, 14,626바이트로 최적화한다. 첫 인사와 답변 아바타에 사용한다.
- 채팅 헤더에는 단일 4방향 반짝임을 사용하고, 고객지원 런처·지원 홈 AI 아이콘·고객센터 AI 버튼·전송 버튼은 노랑/진한 글자 토큰을 공유한다. 일반 실행 버튼과 고객 메뉴판은 변경하지 않는다.
- 기존 API와 요금·요청 제한·민감정보 검사·runtime gate·국외 이전 동의 검증을 보존한다. FAQ 자동 응답이나 대화 저장 기능은 추가하지 않는다.

## 확인

- 최신 운영 글자·폼 크기를 통합한 뒤 전체 단위/계약 850건, TypeScript, 변경 TSX/test lint와 깨끗한 최적화 빌드가 통과했다. 이전 CSS 역할명에 묶인 상담창 계약은 내부 스크롤·지원 홈 이동·중복 링크 제거 기준으로 갱신했다.
- 브라우저의 실제 DOM viewport: 320×568, 390×844, 820×1180, 844×390, 1440×1000.
- 모든 크기에서 페이지/다이얼로그 가로 넘침 0px, 창 경계 안 배치, 캐릭터 로드와 흰 입력창을 확인했다.
- 최초 체크 해제와 전송 비활성, 체크 전 국외 이전 안내 전문, 체크 후 요약을 확인했다.
- 긴 답변의 내부 스크롤, 짧은 가로 화면의 폼 접근, 홈 왕복 시 현재 대화 유지, 실패 상태의 1:1 문의 연결을 확인했다.
- 두 진입점의 같은 노란 표면/진한 글자, 새 영문 칩 및 상시 중복 링크 부재, Tab 포커스 가두기, Escape와 시작 버튼 포커스 복귀, 본문 잠금 복원을 확인했다.
- 로컬 연결 값은 검수용 공개 placeholder만 사용했다. AI API는 브라우저에서 검수 응답으로 대체했고 실제 모델 요청·사용자 데이터 변경은 없었다. 브라우저 런타임 오류 0건.

## 개인정보 처리 확인

현재 상담 UI는 React 메모리에서 대화를 보관한다. 서버 라우트와 상담 서비스에는 대화 원문을 계정 DB로 저장하는 경로가 없으며, 질문은 서버를 거쳐 OpenAI로 전송된다. `store:false`는 응답 상태 저장을 끄는 설정으로, OpenAI의 별도 악용 방지 로그까지 무보관으로 만드는 설정은 아니다. 서버에는 요청 제한을 위한 IP 기반 임시 상태가 있으며, 호스팅 운영 로그와 대화 DB 저장은 구분한다.

기존 개인정보 처리방침은 고객지원 응대 목적과 AI 상담의 수탁자·국외 이전·계정 DB 미저장을 이미 설명한다. UI 리뉴얼을 이유로 동의를 제거하거나 별도 동의 요건이 충족됐다고 판단하지 않는다. 수집·이용의 적법 근거와 국외 이전 근거는 별도 문제이며, 대화 저장·분석을 도입할 때는 목적·항목·보유기간과 필요한 안내/동의를 다시 검토해야 한다.
