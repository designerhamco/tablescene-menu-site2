# 공식 사이트 컴포넌트 확장 검수 — 2026-10-25

## 범위

크몽 사용자 첨부 이미지와 크몽·잡코리아·사람인 공개 화면의 역할별 서체 대비, 큰 선택/탐색 요소, 사각 CTA와 빈 목록 구성을 기존 사이트 토큰에 반영했다. 고객 메뉴판 엔진·편집 팔레트·모바일 읽기 규칙은 수정하지 않았다.

실제 적용: 홈/서비스 CTA·사용법 진입, `/apply`의 서비스 선택/종류 탭/모바일 필터/카드 액션/빈 결과. `/design-system`은 공통 컴포넌트의 검수용 예시이며 상태 건수·좋아요·선택은 화면 안에서만 유지된다. 계정/운영의 모든 화면을 새 구성으로 전환했다는 의미는 아니다.

## 자동 검사

- 전체 단위/계약 테스트 832개 통과.
- 변경 TS/TSX ESLint (`--no-ignore`) 오류·경고 없음.
- `git diff --check` 통과.
- TypeScript 전체 검사와 Next.js Production 빌드 통과.
