# 아티메뉴 마케팅 페이지 디자인 규칙

이 규칙은 홈페이지, 서비스 소개, 인증, 고객센터, 신청·결제, MY/메뉴판과 운영 화면을 포함한 사이트 UI 전체에 적용한다. 실제 메뉴판 템플릿과 공개 메뉴·대기번호판은 고객이 편집하는 별도 타이포그래피 시스템을 사용하므로 적용 대상에서 제외한다.

## 타이포그래피 위계

`페이지 제목 > 필요한 콘텐츠 제목 > 본문 > 보조문` 순서로 크기와 시각적 중요도를 유지한다. 장식용 소제목을 추가해 단계를 채우지 않는다. 사이트 UI의 기본 서체는 Pretendard이며, 일반 페이지 제목에는 홈페이지 히어로용 디스플레이 스타일을 사용하지 않는다.

| 역할 | 공통 클래스 | 모바일 | 데스크톱 | 용도 |
| --- | --- | --- | --- |
| 디스플레이 | `type-display` | 28px | 36px (태블릿 32px) | 홈페이지·서비스 대표 문구 |
| 페이지 제목 | `type-page-title` | 28px | 36px (태블릿 32px) | 일반 페이지 H1 |
| 기능 페이지 설명 | `type-page-description` | 16px | 17px | 로그인·마이페이지·편집 화면의 기능 설명 |
| 섹션 제목 | `type-section-title` | 28px | 36px (태블릿 32px) | 큰 콘텐츠 구획 |
| 하위 섹션 | `type-subsection-title` | 22px | 26px (태블릿 24px) | 폼 단계·카드군 제목 |
| 콘텐츠 제목 | `type-content-title` | 18px | 20px | 카드·본문 제목 |
| 항목 제목 | `type-item-title` | 18px | 18px | 목록·운영 카드 제목 |
| 마케팅 도입 설명 | `type-body-lg` | 18px | 20px | 서비스·브랜드의 가치와 분위기를 전하는 도입문 |
| 기본 본문 | `type-body`, `text-copy` | 16px | 17px | 일반 설명·중요 안내 |
| 보조 본문 | `type-body-sm`, `text-support` | 14px | 15px | 도움말·부가 설명 |
| 레이블·탐색 | `type-label`, `type-nav` | 15px | 16px | 필드명·헤더 |
| 캡션 | `type-caption`, `text-meta` | 13px | 13px | 날짜·짧은 메타 정보 |

- 토큰과 클래스의 단일 기준: `styles/typography.css`
- 마케팅 설명 섹션의 공통 구현: `app/components/home/MarketingSectionCopy.tsx`
- 제목은 역할에 맞는 클래스를 반드시 사용하고, 개별 페이지에서 임의의 `text-*`, `font-black` 조합으로 다시 정의하지 않는다.
- 문구는 위치가 아니라 역할로 고른다. 마케팅 도입 설명은 서비스 가치 전달에만 사용하고, 로그인·마이페이지·편집 화면의 제목 아래 문구는 `type-page-description`을 사용한다.
- 읽는 문구는 마케팅 도입 설명·기능 페이지 설명·일반 본문·보조 본문·캡션 중 하나를 선택하며 모든 문구를 한 크기로 강제하지 않는다.
- 메뉴판과 공유하는 `text-xs`부터 `text-7xl`까지 기초 크기는 변경하지 않는다. 사이트 본문은 `text-copy`/`text-support`/`text-meta` 의미 유틸리티를 사용한다. 기초 크기는 `styles/theme.css`에서 승인된 `--font-size-*` 기초 토큰에 연결한다.
- 일반 사이트 UI의 최상위 굵기는 700이다. `font-black`과 `font-extrabold`, 숫자를 직접 넣은 글자 크기는 사용하지 않는다.
- 라우트 파일뿐 아니라 `components`의 모달·폼·MY/메뉴판 사이드바·편집기 등 실제 화면을 구성하는 중첩 UI에도 같은 계약을 적용한다.
- 홈페이지 안의 기기·메뉴판 예시처럼 실제 제품 화면을 축소해 보여주는 시각 프리뷰는 프레임 비율 유지를 위해 별도 크기 규칙을 사용할 수 있다.
- 고객이 직접 글꼴과 크기를 설정하는 공개 메뉴판·템플릿·대기번호판은 사이트 UI 계약과 분리한다.

## 설명 섹션 레이아웃

- 콘텐츠 폭은 공통 `.site-container`를 따른다. 바깥 최대 1,600px·안쪽 최대 1,520px과 공통 좌우 여백을 공유하며, 가이드 같은 일반 콘텐츠에 별도 최대 폭을 중첩해 좁히지 않는다. 폼·법률 등 승인된 읽기 영역만 예외다.
- 데스크톱: 설명과 이미지가 2열을 이루고 섹션마다 좌우 순서를 번갈아 배치한다.
- 열 사이 간격: 80px
- 모바일: 설명을 먼저 읽고 이미지를 이어서 보도록 1열로 배치한다.
- 공통 이미지 프레임 높이: 모바일 380px, 데스크톱 500px
- 검정 배경 스토리 섹션의 상하 여백: 모바일 80px, 데스크톱 96px
- 검정 배경의 첫 콘텐츠와 마지막 콘텐츠는 둥근 영역 경계에서 실제로 약 104~144px 떨어져 보이도록 겹침값을 포함해 보정한다.
- 검정 배경의 마지막 섹션은 모바일 144px, 데스크톱 208px의 하단 여백을 사용한다.

## 흰 배경 섹션 간격

- 같은 흰 배경에서 연속되는 섹션은 양쪽에 큰 여백을 중복 적용하지 않는다.
- 둥근 흰 배경의 첫 콘텐츠 상단 여백은 모바일·데스크톱 64px을 기준으로 한다.
- AI 기능과 매장 활용 장면 사이의 콘텐츠 간격은 데스크톱 기준 약 160px을 목표로 한다.
- 카드 목록 앞 간격은 모바일 56px, 데스크톱 80px 안팎으로 유지한다.

## 버튼·카드 시스템

현재 컴포넌트의 단일 기준은 `docs/site-design-system.md`와 `styles/ui-system.css` / `styles/site-design.css`다. 기존 공통 Button/Input/Tabs 등을 재사용한다.

- 기본 실행은 40px pill, 헤더는 44px, floating은 48px을 유지한다. 2026-10-25 사용자 승인 변형은 역할에 따라 48/56px CTA, 8px/6px 사각 버튼, 아이콘 선택 카드, 큰 outline 세그먼트와 밑줄 탭을 사용한다. 상세 기준은 `docs/site-design-system.md`의 최신 확장을 따른다.
- 주요 액션은 검정/흰색, 보조 CTA는 옅은 회색 무테, outline 액션은 흰색/회색 경계다. 위험·성공·정보·주의 의미 색상은 유지한다.
- hover는 색상만 바꾸고, 기본 키보드 포커스는 파란색/어두운 표면에서는 흰색이다. disabled는 기능별 안내와 비활성 동작을 유지한다.
- 일반 콘텐츠는 열린 섹션, 기능 카드만 16px 무테 표면, 판매 미리보기는 20px, 기존 히어로는 독립 32–48px 라운드다. 그림자는 떠 있는 레이어·글래스 헤더에 한정한다.
- 실제 메뉴판, 공개 메뉴·대기번호판, 축소 제품 화면의 콘텐츠는 독립된 디자인을 유지한다.

## 유지 원칙

- 새로운 랜딩 섹션은 먼저 공통 타이포그래피 컴포넌트를 사용한다.
- 섹션 제목은 구어체 종결어미를 피하고 짧고 단정한 문구로 작성한다.
- 본문은 한두 문장 이내로 유지하고 기능 설명만 남긴다.
- 노란 점과 함께 붙는 장식 소제목은 문구·여백까지 제거하며 새 화면에도 추가하지 않는다. 실제 제목과 안내 본문의 목록 기호·읽지 않은 알림 점은 유지한다. 불필요한 칩과 장식 페이지 인디케이터도 추가하지 않는다.
- 새 화면은 `site-button`, `site-card`, `site-nav-item` 또는 공통 컴포넌트를 먼저 사용하며 임의의 그림자·모서리·확대 호버를 추가하지 않는다.
