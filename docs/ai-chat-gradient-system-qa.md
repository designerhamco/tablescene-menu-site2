# AI 상담 그라데이션·공통 컴포넌트

## 현재 기준

- 웰컴형 구조는 유지하고 첫 인사·답변 캐릭터와 전용 이미지 자산을 제거한다. 헤더와 답변의 단일 반짝임은 AI 보조색을 사용한다.
- 런처·고객센터·지원 홈 AI 아이콘·전송 버튼은 공통 보라/파랑 그라데이션·흰 글자로 표시한다. `/design-system`의 AI 상태 예시도 같은 토큰을 사용한다.
- 추천 질문은 라이브러리의 실제 `Button variant="outline"`, 전송은 `Button variant="ai" size="icon"`, 입력은 `Input fieldSize="md"`를 사용한다. 질문 행의 폭/정렬만 배치하고 공통 버튼의 모서리·패딩·글자·hover/pressed/disabled/focus를 재정의하지 않는다.
- 인사말은 공통 `type-subsection-title`, 나머지 본문·메타는 기존 의미 역할이다. 노란 배경과 개별 제목 크기, 중복 입력 테두리와 자체 필드 포커스 규칙을 제거한다.
- 기존 상담 API·명시적 국외 이전 동의·runtime gate·대화 미저장·뒤로가기·오류 시 1:1 문의 연결을 유지한다.

## 검증 범위

관련 기존 단위/계약, TypeScript, 변경 파일 lint와 최적화 빌드를 실행한다. 실제 작은 모바일/일반 모바일/태블릿/가로 화면/PC에서 아래를 확인한다.

- 페이지와 창의 가로 넘침, 흰 배경, 캐릭터 이미지 부재, 공통 버튼/필드의 실제 모서리·높이·포커스
- 동의 전 요청 차단, 동의 후 추천 질문/입력/긴 답변/오류 상태, 홈 왕복 시 대화 유지
- Tab/Escape/시작 버튼 포커스 복귀, 짧은 가로 화면의 폼 접근
- 라이브러리와 실제 AI 버튼의 기본/hover/pressed/disabled 상태 일치

모델 요청은 검수 응답으로 대체하며 로컬 연결 값은 공개 placeholder만 사용한다. 운영 반영 완료는 Vercel 성공과 실제 공개 화면에서 별도로 확인한다.

## 로컬 검증 결과

- 기존 단위/계약 테스트 850개, TypeScript, 변경 TSX lint, 최적화 빌드와 diff 공백 검사를 통과했다.
- 실제 DOM viewport 320×568, 390×844, 820×1180, 844×390, 1440×1000에서 페이지/팝업 가로 넘침이 없었다. 흰 웰컴 배경과 이미지 부재, 동의 전 비활성, 긴 답변 내부 스크롤, 홈 왕복 대화 유지, 오류 문의 링크, Tab 포커스 가둠과 Escape/진입 버튼 포커스 복귀를 확인했다.
- `/design-system`과 상담창의 추천 버튼 모서리·테두리·배경·글자 크기/굵기·패딩, 입력창 모서리·테두리·배경·글자 크기/굵기·높이가 실제 computed style로 일치했다. 입력은 44px 높이/12px 모서리, 추천은 공통 8px 모서리다.
- 런처와 전송의 공통 그라데이션, 라이브러리의 기본/hover/pressed/disabled 상태를 확인했다. 브라우저 실행 오류 0건, 요청 10건은 모두 모의 응답이며 실제 모델 호출은 없었다.
