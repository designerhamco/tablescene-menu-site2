# AI 상담 초기 제품·안전 정책

최종 갱신 2026-11-27

## 목적

AI 상담은 아티메뉴의 요금제 차이, 메뉴판 제작, 디자인·다국어, 스마트호출, Display 이용 방법을 빠르게 설명하는 안내 도구다. 사람의 판단이나 계정 변경이 필요한 업무를 대신하지 않는다.

## 허용 범위

- 공개된 서비스 기능과 사용 방법 설명
- 다이닝 단일페이지·멀티페이지·Display 차이 설명
- 관리자 화면에서 사용자가 직접 할 수 있는 작업 안내
- 일반적인 이용 질문은 관련 방법이나 FAQ·이용가이드로 안내하고, 실제 계정·결제 등의 확인이나 처리가 필요할 때 1:1 문의를 안내한다.

## 금지 범위

- 계정·구독·결제·환불 상태를 조회했다고 주장하거나 직접 변경
- 실제 결제, 취소, 환불, 구독, entitlement 실행
- 비밀번호, 인증번호, 카드정보, API key, 주민등록번호 등 민감정보 요청
- 법률·세무·계약·의료 결론
- 확정되지 않은 출시일, 할인, 정책, 기능 생성
- 대화 내용을 DB에 저장하거나 계정 프로필과 결합

## 데이터와 비용 경계

- OpenAI Responses API 요청은 `store=false`로 전송한다.
- 질문은 500자, 답변은 최대 300 output token으로 제한한다. 기본 모델은 비용 효율형 `gpt-5.6-luna`를 추론 없음으로 사용해 짧은 안내에 필요한 지연과 비용만 사용하며, 상담 전용 모델을 명시적으로 설정한 경우에는 그 모델의 기본 추론 설정을 따른다.
- 이메일·전화번호·카드번호·주민등록번호·인증코드·비밀번호 값·API key로 보이는 입력은 OpenAI 요청 전에 거부한다.
- 한 네트워크 식별자에서 10분 동안 최대 6회로 제한한다.
- 서버 메모리 제한은 기본 방어선이며 다중 serverless instance의 절대 비용 상한이 아니다. Vercel Production Firewall에도 `/api/support/chat`을 IP별 10분 6회로 제한하는 `429` 규칙을 2026-09-09 적용했다.
- `store=false`는 OpenAI Responses 응답 상태를 저장하지 않는 설정이다. OpenAI의 기본 API 악용 모니터링 로그는 별도 정책에 따라 최대 30일 보관될 수 있으므로 사용자 화면에는 아티메뉴 계정·DB에 저장하지 않는다는 범위만 명확히 안내한다.
- API key와 system instruction은 서버에만 둔다.
- Production은 다른 AI 기능과 키를 공유하지 않고 `ArtiMenu AI Support` 전용 OpenAI 프로젝트의 `OPENAI_SUPPORT_API_KEY`를 우선 사용한다. 로컬·기존 환경 호환을 위해 `OPENAI_API_KEY` fallback만 유지한다.
- 전용 프로젝트는 `gpt-5.6-luna`만 허용하고 월 5달러 hard limit, 월 사용량 50%·80%·100% 알림, 15,000 TPM·10 RPM 제한을 2026-09-09 적용했다.
- UI 대화는 현재 브라우저 메모리에만 있고 새로고침·이탈 시 사라진다.

## 계정별 상담 한도

- 로그인한 계정의 첫 질문부터 24시간 동안 실제 Responses API 입출력 토큰 합계를 서버에서 집계한다. 현재 기본값은 14,000이며, 운영에서는 선택적으로 `AI_SUPPORT_CHAT_DAILY_TOKENS`로 조정할 수 있다. 사용자 화면에는 한도에 한해 재이용 가능 시각을 표시한다.
- 요청 전에 보수적으로 사용량을 예약하고, 응답이 보고한 토큰 수로 정산한다. 처리 여부가 불명확하면 예약분을 남긴다. 계정마다 동시에 한 질문만 처리하며 예약은 60초 후 만료된다. 기존 IP별 단기 제한도 유지한다.
- 한도에 도달하는 마지막 질문의 답을 먼저 보여주고 입력창을 닫는다. 그 아래에만 공식 아티메뉴 카카오톡 1:1 채팅 버튼을 표시한다. 버튼을 눌러 채팅을 열며 대화 내용은 전달하지 않는다.
- DB에는 계정 ID와 해당 시간대의 사용량 및 임시 처리 상태만 보관한다. 로그인 검증을 마친 서버만 사용량 함수에 접근하고, 계정 삭제 시 사용량 행도 삭제한다.
- 운영 배포 시 계정별 사용량 마이그레이션을 먼저 적용한 뒤 앱을 배포한다. 기존 IP 제한이 로그인 상태 확인 같은 조회 요청에도 적용되는지 확인하고, 앱 배포 후 로그인과 한도 도달 상태를 점검한다.

## Runtime과 공개

- `AI_SUPPORT_CHAT_ENABLED=true`일 때만 API가 열린다.
- gate가 닫혀 있으면 `/support/chat`은 준비 중 안내와 1:1 문의 링크만 표시한다.
- 상담 전용 OpenAI 프로젝트의 예산·사용량·모델·rate limit과 Vercel Firewall 설정은 완료했다. Vercel Production에는 상담 전용 키를 `OPENAI_SUPPORT_API_KEY` secret로 저장했으며 값을 문서·로그에 남기지 않는다.
- 2026-09-14 개인정보 처리방침 시행일을 확정한 뒤 Vercel Production Config `AI_SUPPORT_CHAT_ENABLED=true`를 추가하고 재배포해 공개했다.
- 2026-09-09 로컬 실제 API QA에서 요금제 비교·30일 무료체험·계정 변경 거절·프롬프트 탈취 거절 시나리오가 통과했다.
- 2026-09-14 Production 공개 smoke QA에서 국외 이전 동의 전 입력 비활성, 디스플레이 MP4 안내 실제 응답, 카드번호 형식의 민감정보 차단과 1:1 문의 전환을 확인했다.

## 외부 알림과의 관계

문자·알림톡·백그라운드 push는 결제 필수 기능이 아니다. 현재 앱 내 알림과 사용자가 선택한 브라우저 알림으로 충분하다. 외부 채널은 관리자가 운영 화면을 보지 않을 때의 호출 알림이나 향후 고객 픽업 완료 알림이 필요해졌을 때 업체·비용·수신 동의·실패 fallback을 정한 뒤 별도 도입한다.
