# AI 상담 초기 제품·안전 정책

최종 갱신: 2026-09-01

## 목적

AI 상담은 아티메뉴의 요금제 차이, 메뉴판 제작, 디자인·다국어, 스마트호출, Display 이용 방법을 빠르게 설명하는 안내 도구다. 사람의 판단이나 계정 변경이 필요한 업무를 대신하지 않는다.

## 허용 범위

- 공개된 서비스 기능과 사용 방법 설명
- 다이닝 단일페이지·멀티페이지·Display 차이 설명
- 관리자 화면에서 사용자가 직접 할 수 있는 작업 안내
- 답을 확정할 수 없을 때 `1:1 문의`로 전환

## 금지 범위

- 계정·구독·결제·환불 상태를 조회했다고 주장하거나 직접 변경
- 실제 결제, 취소, 환불, 구독, entitlement 실행
- 비밀번호, 인증번호, 카드정보, API key, 주민등록번호 등 민감정보 요청
- 법률·세무·계약·의료 결론
- 확정되지 않은 출시일, 할인, 정책, 기능 생성
- 대화 내용을 DB에 저장하거나 계정 프로필과 결합

## 데이터와 비용 경계

- OpenAI Responses API 요청은 `store=false`로 전송한다.
- 질문은 500자, 답변은 최대 500 output token으로 제한한다.
- 한 네트워크 식별자에서 10분 동안 최대 6회로 제한한다.
- 서버 메모리 제한은 기본 방어선이며 다중 serverless instance의 절대 비용 상한이 아니다. 공개 활성화 전 Vercel Firewall·사용량 알림·OpenAI 프로젝트 예산 경보를 함께 확인한다.
- API key와 system instruction은 서버에만 둔다.
- UI 대화는 현재 브라우저 메모리에만 있고 새로고침·이탈 시 사라진다.

## Runtime과 공개

- `AI_SUPPORT_CHAT_ENABLED=true`일 때만 API가 열린다.
- gate가 닫혀 있으면 `/support/chat`은 준비 중 안내와 1:1 문의 링크만 표시한다.
- Production 활성화는 환경변수 변경·재배포와 실제 비용·답변 품질 QA가 필요한 사람 승인 작업이다.

## 외부 알림과의 관계

문자·알림톡·백그라운드 push는 결제 필수 기능이 아니다. 현재 앱 내 알림과 사용자가 선택한 브라우저 알림으로 충분하다. 외부 채널은 관리자가 운영 화면을 보지 않을 때의 호출 알림이나 향후 고객 픽업 완료 알림이 필요해졌을 때 업체·비용·수신 동의·실패 fallback을 정한 뒤 별도 도입한다.
