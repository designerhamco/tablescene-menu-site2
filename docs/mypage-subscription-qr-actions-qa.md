# 마이페이지 구독 변경·계정 지표·QR 진입 검수

## 적용 내용

- 구독 관리 바로 다음에 독립된 구독 변경 Dialog를 제공한다. 기존 변경 API의 서버 자격 판정과 runtime gate를 재사용하며 해지 예약·종료·복구불가·변경 결제 처리 중·조회 실패에서는 숨긴다. 변경 신청은 기존 적용일·요금·디자인 동의 이후에만 진행한다.
- 직원 관리의 사장 프로필에 기존 계정 AI 잔액 조회와 인증된 사업자명을 연결한다. 직원계정 수와 함께 두 지표를 표시한다. 직원 초대·권한 정책은 유지한다.
- 내 메뉴판의 QR 다운로드를 QR 관리 링크로 바꾼다. 기존 qr.manage 검증 후 canManageTables가 참이면 매장 운영의 해당 메뉴판 테이블·QR 관리로 이동한다. 그 외는 기존 대표 QR 관리 화면을 사용한다.

## 확인

- 전체 단위·계약 테스트 879건, TypeScript, 변경 TSX lint, 최적화 빌드, diff check 통과.
- 임시 로컬 샘플(검수 후 제거)에서 이용 중에만 변경 버튼 표시, 해지 예약/종료 상태 숨김, 독립 Dialog 열기/닫기/Escape/포커스 복귀와 동의 전 신청 비활성을 확인.
- 실제 DOM 1280×720 및 390×844에서 Dialog 경계/모바일 스크롤/가로 넘침 없음 확인.
- 샘플 API는 고정 응답만 제공하고 저장은 거절했다. 운영 구독 변경 예약·청구·권한·DB 구조는 변경하지 않았다.
- 운영 확인은 배포 후 기존 로그인 세션에서 직원 관리 지표와 메뉴판 QR 진입을 읽기 동작으로 확인한다.
