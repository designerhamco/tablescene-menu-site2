# 계정·편집 UI 후속 수정 — 2026-10-23

- 복구불가·처리확인 필요는 같은 붉은 칩, 결제 완료는 밝은 회색 배경과 진한 회색 문구를 사용한다. 기존 공개·이용의 초록과 역할 칩은 보존한다.
- 구독 관리는 검정 primary, 결제 상세·로그아웃·취소·닫기 등 일반 흰색 액션은 회색 1px 경계를 유지한다. ghost는 좋아요/공유/아이콘 제어만 유지한다.
- 일반 버튼의 기본·hover·active·focus-visible·disabled 상태를 명시한다. 비활성 공개 보기와 QR 다운로드는 같은 배경/경계/문구색을 사용한다.
- 편집기는 옅은 회색 작업 바탕과 흰 헤더/탭/수정 패널, 옅은 회색 하위 설정을 구분한다. 고객 메뉴판의 그림·팔레트·간격은 변경하지 않는다.
- 긴 디자인명을 상태칩에서 분리하고 도움말은 공통 28px 원형 팝오버로 추출한다. 클릭/키보드/Escape와 화면 경계 충돌 처리를 유지한다.
