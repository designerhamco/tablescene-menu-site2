# 기본 디자인 6종 마무리 검수 — 2026-10-20

## 적용 범위

- `/design-review`에 베이직 4종과 다이닝 전면/좌측 내비게이션형 2종을 제공한다. 다이닝 기본형은 같은 예시 메뉴로 구성해 구조 차이를 비교한다. 구매/교체/저장 메뉴판 데이터는 변경하지 않는다.
- 좌상단 대표 이미지 부분만 전 기기 4:3이며 대표영역은 메뉴와 함께 스크롤한다. 다른 모바일의 서체/20px 상품 간격/26px 제목 아래/48px 섹션 간격은 유지한다.
- 묶음형·채움형은 PC/태블릿 기기별 동일 읽기 상한과 기본 간격을 사용한다. 묶음형의 글자 축소 탐색을 제거하고 넘치는 메뉴는 스크롤한다. 2/3열 상품명 가독성 판단, 가격 오른쪽 배치, 카테고리/위젯/안내 경계는 유지한다.
- 호출은 미리보기/실제 UI 모두 단일 선택이다. 다른 항목을 누르면 이전 선택을 해제한다. 최대 5개 예시, 요청 목록의 내부 스크롤/조건부 페이드, 전송 버튼 고정은 유지한다. API/RPC/접수 제한은 변경하지 않는다.
- 다이닝 모바일 옵션 상품은 상품명 → 옵션 가격 → 보조명 → 설명 순서다. PC/태블릿은 이전 위치다.
- 개수 원형은 20px 원을 유지하며 아이콘 쪽으로 약 4–5px 이동한다. Basic의 기존 타원 가능성도 명시적 같은 너비/높이로 없앤다.
- 새 좌측형은 원래 Dining B 테마에 영향을 주지 않는 중립 흰색/잉크/회색 변수만 사용한다. 내비게이션으로 메뉴가 좁아지는 768–1279px 구간의 기본형 메뉴는 한 열로 펼쳐 읽으며 내부 스크롤한다.

## 언어

- 기본 시안을 만들기 전에 번역했다가 한국어로 덮어쓰던 순서를 수정했다. 중립 시안 생성 후 원래 샘플의 안정된 ID를 이용해 ko/en/ja/zh 콘텐츠를 연결한다.
- 새 설명/위젯/안내/칩/가격 옵션은 명시적인 예시 번역을 제공한다. 보조 언어명은 승인된 영어 예시를 유지한다.
- 공통 호출/옵션/장바구니/주문내역 UI는 `MenuLocaleScope`와 명시적 사전 호출을 사용한다. 원화 금액은 통화를 변환하지 않으며 외국어에서는 ₩ 표기를 쓴다. 날짜는 선택 언어와 서울 시간대를 사용한다.
- 실제 저장 고객 콘텐츠는 기존 번역 데이터 파이프라인을 사용한다. 임의 DOM 치환, 고객 문구 자동 덮어쓰기, 실제 데이터 변경은 없다.
