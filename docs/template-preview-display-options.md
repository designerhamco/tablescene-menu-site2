# 아티메뉴 미리보기 보기옵션

## 태블릿 회전 — 2026-11-11

베이직·다이닝의 모든 리스트형/앨범형과 기본/디자이너 템플릿은 태블릿 선택 시 회전 버튼으로 가로(1180×820)·세로(820×1180)를 전환한다. 카탈로그와 저장 메뉴판 미리보기가 같은 프레임을 사용하며, 회전할 때 언어·디자인 및 해당 미리보기에서 지원하는 옵션을 유지한다. PC·모바일에는 회전 버튼을 표시하지 않는다. 디스플레이의 별도 실제 화면 미리보기는 유지한다.

복원 검증: 베이직·다이닝 20개 디자인에서 실제 회전 버튼으로 가로→세로→가로 전환 및 iframe 크기·언어/옵션 유지를 확인했다. 카탈로그/저장 메뉴판의 양방향 회전은 등록 디자인 전체 렌더 검사에도 포함한다. 관련 검사44건, 공통 사이트 UI 검사150건, TypeScript·변경 파일 lint가 통과했다. 로컬 브라우저 기록은 `/private/tmp/artimenu-tablet-rotation/report.json`이다.

## 현행 보기옵션 계약 (2026-11-11)

현재 등록과 문서 경로는 [템플릿 문서 안내](template-docs-index.md)를 따른다. Basic/Dining의 기본·디자이너·지원 앨범 디자인에 같은 패널을 연결하며 Display는 이 패널에서 제외한다. 아래 2026-10-20 검수 기록의 9종/도구막대 공간 설명은 당시 이력이다.

### 컨트롤의 소유 영역

- 상단 도구막대: PC·태블릿·모바일 기기 선택, 지원 회전, PC·태블릿 묶음형/채움형, 주문/호출 미리보기, 새 창. 지원하지 않는 엔진/기기에 기능을 강제로 노출하지 않는다.
- 보기옵션의 **기능 옵션** 탭: 콘텐츠 영역·문구·이미지·가격/판매 상태 노출.
- 보기옵션의 **디자인** 탭: 지원 배경색, 공통 한글/영문 서체, 서비스별 글자색 역할, 지원 칩 색상, 대표 텍스트 정렬, 앨범 상품 비율, 이미지·텍스트칩 라운드, 디자인 초기화.

실제 옵션 목록은 [template-preview-options.ts](../lib/template-preview-options.ts)와 [template-capabilities.ts](../lib/template-capabilities.ts)가 결정한다. 템플릿 이름만으로 별도 지원 목록을 만들지 않는다.

| 기능 그룹 | Basic | Dining |
| --- | --- | --- |
| 영역·이미지 | 광고, 로고, 대표영역, 대표상품, 상품 이미지, 위젯 중 capability가 지원하는 항목 | 광고, 로고, 커버 페이지/이미지, 상품 이미지, 위젯 중 지원 항목 |
| 메뉴 정보 | 카테고리 설명, 보조 언어명, 메뉴 설명, 일반 텍스트칩 | 페이지 설명, 카테고리 설명, 보조 언어명, 메뉴 설명 |
| 가격·판매 상태 | 가격 옵션, 가격 설명, 기간 할인, 품절 중 지원 항목 | 가격 옵션, 가격 설명, 품절 중 지원 항목 |

Basic 기본 앨범은 가격 옵션을 제외한다. Dining의 코스 상품 이미지 미노출과 코스 가격 규칙은 옵션으로 해제하지 않는다. 커버 OFF의 커버 이미지 제어 등 종속 조건도 유지한다. 실제 지원 여부와 처음 체크된 상태는 별개다. 대표영역 기본 OFF인 상단행/Van Gogh도 지원할 때 체크해 사용할 수 있다.

### 기본값·임시 예시·상태 유지

처음 체크된 상태는 스타터 실제 데이터와 기본 디자인의 초기 정책에서 읽는다. 명시적인 on/off 선택이 우선한다. 광고는 기본 OFF이며, 템플릿 고유 로고/위젯/이미지와 선택한 모양·비율은 보존한다. 없는 콘텐츠를 켰을 때의 예시는 카탈로그 전용 adapter가 공급한다. MELLOW의 대표영역 ON처럼 승인된 빈 이미지 프레임 정책이 있는 경우 그 예외를 유지한다.

기능 선택과 검증된 `designPreview` 값은 기기·회전·언어·묶음/채움·새 창에 유지된다. 탭 전환만으로 메뉴 iframe을 다시 불러오지 않는다. 디자인 초기화는 임시 디자인 선택만 지우고 해당 디자인의 기본값으로 복원한다. 디자인 선택은 구매용 스타터 기본값이나 고객 저장 데이터에 기록되지 않는다. 고객 편집기의 저장은 별도 권한 있는 저장 경로를 따른다.

### 왼쪽 로고형의 기기별 정렬 — 2026-11-13

MELLOW와 기본 왼쪽 로고형의 PC·태블릿은 가게명/로고 왼쪽·가게 설명 오른쪽으로 고정한다. 보기옵션의 정렬 선택은 비활성화하고 실제 고정 조합을 표시한다. 모바일에서 고른 값을 데스크톱의 표시값으로 오인하지 않으며 로고의 정렬도 직접 읽는다.

모바일은 명시적인 정렬값이 없을 때 가운데가 기본이다. 모바일의 왼쪽/가운데/오른쪽 선택은 유지하며 PC·태블릿으로 갔다 돌아와도 복원된다. 데스크톱 전환을 이유로 모바일 선택을 초기화하거나 저장값을 왼쪽으로 덮어쓰지 않는다. 가운데 로고형의 고정 헤더와 다른 구조의 정렬 규칙은 유지한다.

### 대표영역·회전·묶음/채움과 본문 너비

베이직 PC·태블릿의 1열 고정형·상단행형 본문은 별도 대표열과 각 선택된 메뉴 열의 실제 사용 너비를 같게 계산한다. 기본/디자이너·리스트/앨범이 같은 규칙을 사용하며, 보기옵션에 별도 열 비율 제어나 고정 50% 값을 추가하지 않는다. 세로 태블릿도 실제 본문 폭과 공통 16rem 최소 메뉴 폭·이름 가독성을 기준으로 다시 측정한다. 예를 들어 대표 1 + 메뉴 1이면 전체 2열이다.

상단행의 대표영역 ON은 본문에 같은 너비의 이미지 열을 만들고, OFF는 이를 제거해 메뉴에 너비를 돌려준다. 1열 고정형은 사진을 꺼도 가게명/설명의 고정 대표열을 유지한다. 회전·묶음/채움·폰트/이미지/가격 옵션 변경 후에도 현재 데이터로 재측정하며, 임시 옵션이나 저장된 명시적 선택을 임의로 바꾸지 않는다. 상단 헤더 세 칸, 중앙열과 좌상단 구조, 등록 이미지 비율, 모바일·다이닝은 각자의 계약을 유지한다. [베이직 동일 너비 규칙](basic-menu-scroll-policy.md#대표열과-메뉴-열의-동일-너비--2026-11-11)이 수치/구현 원본이다.

검수는 `ORDER_QA_BASE=http://localhost:3027 npm run qa:basic-equal-tracks`로 실행한다. 실제 서버 주소는 `ORDER_QA_BASE`, 결과 위치는 `ORDER_QA_OUTPUT`으로 지정한다. 이 명령은 브라우저를 여는 수동 회귀 검사이며 단위 테스트/빌드 자동 검사와 구분한다.

### 패널과 메뉴판의 경계

미리보기 보기옵션에는 제목·탭·라벨을 반복하는 상시 소개나 체험/저장 여부 설명을 다시 넣지 않는다. 사용자가 삭제한 문구는 패널·카드 안이라는 이유로 복원하지 않는다. 필요한 비직관적 적용 범위·비활성 조건만 해당 제어 옆 공통 InfoTooltip에 제공하며, 미리보기 도움말은 공통 preview 레이어를 사용한다. 모바일 PC 권장 진입 팝업과 실제 화면보기 안내는 별도 승인 범위를 따른다.

실제 바깥 브라우저 폭 960px 이상에서는 왼쪽의 밝은 overlay 패널이 기본으로 열리고, 더 좁으면 기본으로 접힌다. 사용자가 연/닫은 선택은 유지한다. 패널이 메뉴 공간을 예약하거나 메뉴판을 옆으로 밀거나 축소하지 않는다. 미리보기 프레임과 고객 메뉴판의 읽기 크기/레이아웃은 독립이다. 상세 수치는 [공통 계약의 Preview option overlay 절](template-spacing-contract.md#preview-option-overlay--2026-10-21)과 [menu-preview-fit.ts](../lib/menu-preview-fit.ts)를 따른다.

Basic은 글자색 6역할, Dining은 페이지 제목·상품명·가격·통합 설명·위젯 등을 분리한 8역할을 사용한다. Dining의 페이지/카테고리/메뉴 설명은 한 색상 역할이며, Basic의 카테고리 설명은 카테고리명 색상을 따른다. [menu-text-colors.ts](../lib/menu-text-colors.ts)와 공통 계약의 최신 색상 절이 기준이다. 라운드 제어는 로고와 Dining full-bleed 커버를 제외하며, 앨범 비율은 상품 이미지에만 적용한다. 구조가 고정한 PC·태블릿 헤더 정렬을 자유 정렬로 덮어쓰지 않는다.

미리보기 패널 UI는 공식 사이트 디자인 시스템을 사용한다. 패널이 제어하는 메뉴판의 서체·색·간격·대표 이미지 비율은 고객 renderer의 별도 규칙이다.

## 범위와 동작

- 활성 베이직 7종과 다이닝 2종의 카탈로그 미리보기에 공통 패널을 연결한다. 디스플레이는 제외한다. 고객이 저장한 메뉴의 편집기 미리보기와 실제 공개 메뉴에는 이 데이터 변환을 연결하지 않는다.
- 영역·이미지 / 메뉴 정보 / 가격·판매 상태로 분류하고 패널을 접을 수 있다. 지원 여부는 기존 template capabilities를 사용한다. 광고는 패널로 이동하고 중복 체크를 만들지 않는다.
- 베이직: 광고, 로고, 대표 영역, 대표 상품, 상품 이미지, 위젯, 카테고리 설명, 보조 언어명, 메뉴 설명, 일반 텍스트칩, 가격 옵션, 가격 설명, 기간 할인, 품절.
- 다이닝: 광고, 로고, 커버 페이지, 커버 이미지, 상품 이미지, 카테고리 설명, 보조 언어명, 메뉴 설명, 가격 옵션, 품절. 커버 OFF면 커버 이미지 체크는 비활성화한다. 기본 베이직 앨범의 가격 옵션 제외 등 기존 기본 디자인 계약은 유지한다.
- 첫 화면의 체크 상태는 각 디자이너 스타터에서 실제로 사용 중인 데이터에서 읽는다. 명시적 옵션이 없으면 기존 데이터를 그대로 반환하며 서체·색상·레이아웃·모바일 간격을 변경하지 않는다. 광고는 기본 OFF다.
- 체크 시 등록된 예시를 사용한다. 없는 로고·이미지·위젯·가격 옵션·할인·품절은 미리보기에서만 샘플로 확인할 수 있다. 보조명이 없는 스타터는 기존 영어 번역을 사용한다. 다른 언어의 보조명은 스타터 원문을 활용하며 OFF는 두 종류의 보조명 모두 숨긴다.
- ROSY ORANGE의 기존 보조명/카테고리 설명 숨김은 체크한 카탈로그 미리보기 범위에서만 해제한다. 체크하지 않은 최초 화면과 고객 공개 렌더러의 규칙은 유지한다.
- 일반 텍스트칩 OFF는 할인/품절 상태와 별개다. 가격 옵션 OFF도 활성 할인 자체를 제거하지 않는다. 코스 전체 가격과 코스 상품 이미지 미노출 규칙은 유지한다.
- 선택한 옵션은 기기·회전·언어·묶음/채움 변경과 새 창 링크에 유지된다. PC 프레임은 기존 화면 위 도구막대, 태블릿/모바일 기기 프레임은 실제 도구막대 높이 다음에 배치한다.

## 코드 경계

`template-preview-options.ts`는 지원 옵션·초기 체크 상태를 공유한다. `template-preview-data.ts`는 서버 카탈로그 샘플에만 변환을 적용한다. 고객 콘텐츠/DB/권한·결제·실주문 API 변경은 없다. `MenuPreviewDeviceFrame`은 기본 디자인과 같은 패널을 사용하고, 원본 스킨을 별도 기본 디자인 스타일로 대체하지 않는다.

## 색상별 기본값 복원 (2026-11-11)

색상 옆 복원 아이콘은 컬러피커 대신 확인 대화상자를 연다. 대상 색상명을 표시하고 ‘취소’는 현재 미리보기를 유지하며, ‘되돌리기’는 해당 색상의 미리보기 재정의만 즉시 제거한다. 추가 적용 버튼은 필요하지 않다. Escape는 대화상자만 닫고 보기 옵션 패널을 유지한다. 일반 색상 편집은 기존대로 적용/취소를 사용한다. 모든 카탈로그 기본·디자이너·앨범형의 배경/글자/칩 색상이 같은 컴포넌트를 사용하며 고객 저장 데이터는 변경하지 않는다.

멜로우의 원본 스타터는 대표영역 OFF·대표상품 미지정·실제 대표사진 없음 상태를 유지한다. 명시적으로 대표영역을 켠 카탈로그에서는 공통 빈 이미지 예시를 생성하고, 대표상품 옵션이 ON 상태면 기존 스타터 첫 상품(현재 포레스트 모카)의 번역된 이름·설명·칩·가격을 연결한다. 옵션을 끄거나 새 구매를 만들 때 이 카탈로그 전용 예시를 고객 원본에 쓰지 않는다.

## 실제 화면보기와 브라우저 안내 — 2026-11-11

카탈로그와 저장 메뉴판의 모든 기기 모드에서 실제 화면보기를 제공한다. 새 탭에 선택 모드의 device/orientation을 강제하지 않으며 실제 브라우저 크기에 반응한다. 모바일 접속에서는 메뉴판만 표시하고 전체화면·안내 버튼과 안내창을 모두 생략한다. PC·태블릿의 전체화면은 실제 API 지원 여부로 노출하고, 태블릿에는 자동 안내·PC용 확대축소·ESC 설명을 표시하지 않는다. PC·태블릿의 미지원 안내는 수동 ‘화면 보기 안내’ 안에서만 제공하며 Chrome 열기 버튼은 추가하지 않는다. 자세한 기준은 [공통 계약의 Preview workspace and actual-screen guide](template-spacing-contract.md#preview-workspace-and-actual-screen-guide--2026-10-31-current)를 따른다.

모바일에서 미리보기 작업 화면에 처음 들어오면 공통 Dialog로 “PC에서 더 편하게 볼 수 있어요”를 안내한다. “모바일로 계속 보기”로 닫으며, 같은 탭 세션에서는 템플릿/기기 변경과 새로고침 시 반복하지 않는다. 카탈로그·저장 미리보기·Display가 공유하고 실제 화면보기·내부 iframe·고객 QR 메뉴판에는 표시하지 않는다. PC·태블릿에는 이 권장 팝업을 띄우지 않는다.
