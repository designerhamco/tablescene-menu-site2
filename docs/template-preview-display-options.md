# 실제 디자인 템플릿의 보기 옵션

2026-10-20 사용자 승인: 기본 디자인 검토 화면뿐 아니라 실제 아티메뉴 디자인 템플릿 미리보기에서도 보기 옵션을 사용한다.

## 범위와 동작

- 활성 베이직 7종과 다이닝 2종의 카탈로그 미리보기에 공통 패널을 연결한다. 디스플레이는 제외한다. 고객이 저장한 메뉴의 편집기 미리보기와 실제 공개 메뉴에는 이 데이터 변환을 연결하지 않는다.
- 영역·이미지 / 메뉴 정보 / 가격·판매 상태로 분류하고 패널을 접을 수 있다. 지원 여부는 기존 template capabilities를 사용한다. 광고는 패널로 이동하고 중복 체크를 만들지 않는다.
- 베이직: 광고, 로고, 대표 영역, 대표 상품, 상품 이미지, 위젯, 카테고리 설명, 보조 언어명, 메뉴 설명, 일반 텍스트칩, 가격 옵션, 가격 설명, 기간 할인, 품절.
- 다이닝: 광고, 로고, 커버 페이지, 커버 이미지, 상품 이미지, 카테고리 설명, 보조 언어명, 메뉴 설명, 가격 옵션, 품절. 커버 OFF면 커버 이미지 체크는 비활성화한다. 기본 베이직 앨범의 가격 옵션 제외 등 기존 기본 디자인 계약은 유지한다.
- 첫 화면의 체크 상태는 각 디자이너 스타터에서 실제로 사용 중인 데이터에서 읽는다. 명시적 옵션이 없으면 기존 데이터를 그대로 반환하며 서체·색상·레이아웃·모바일 간격을 변경하지 않는다. 광고는 기본 OFF다.
- 체크 시 등록된 예시를 사용한다. 없는 로고·이미지·위젯·가격 옵션·할인·품절은 미리보기에서만 샘플로 확인할 수 있다. 보조명이 없는 스타터는 기존 영어 번역을 사용한다. 다른 언어의 보조명은 스타터 원문을 활용하며 OFF는 두 종류의 보조명 모두 숨긴다.
- ROSY ORANGE의 기존 보조명/카테고리 설명 숨김은 체크한 카탈로그 미리보기 범위에서만 해제한다. 체크하지 않은 최초 화면과 고객 공개 렌더러의 규칙은 유지한다.
- 일반 텍스트칩 OFF는 할인/품절 상태와 별개다. 가격 옵션 OFF도 활성 할인 자체를 제거하지 않는다. 코스 전체 가격과 코스 상품 이미지 미노출 규칙은 유지한다.
- 선택한 옵션은 기기·회전·언어·묶음/채움 변경과 새 창 링크에 유지된다. PC 프레임은 기존 화면 위 도구막대, 태블릿/모바일 기기 프레임은 실제 도구막대 높이 다음에 배치한다.

## 코드 경계

`template-preview-options.ts`는 지원 옵션·초기 체크 상태를 공유한다. `template-preview-data.ts`는 서버 카탈로그 샘플에만 변환을 적용한다. 고객 콘텐츠/DB/권한·결제·실주문 API 변경은 없다. `MenuPreviewDeviceFrame`은 기본 디자인과 같은 패널을 사용하고, 원본 스킨을 별도 기본 디자인 스타일로 대체하지 않는다.
