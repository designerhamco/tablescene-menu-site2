# QR 다운로드 팝업·테이블 관리 통합

## 동작

- 내 메뉴판의 사장/직원 카드에서 QR 관리를 누르면 공통 Dialog가 열린다. 열 때마다 최신 목록을 조회하며 열기만으로 다운로드나 쓰기를 실행하지 않는다.
- 대표 QR, 등록된 테이블별 다운로드 버튼을 제공한다. 비활성 테이블은 표시하되 다운로드를 비활성화한다. 등록 테이블 0개와 기능/권한 미활성을 구분하고 조회 오류는 재시도로 표시한다.
- 하단의 테이블/QR 관리 이동으로 기존 매장 운영 관리 화면을 연다. 해당 화면에 대표 QR과 테이블 관리기를 함께 제공하며 기존 `/qr` 링크는 이 화면으로 이동한다.
- QR 권한이 있는 Display 등도 대표 QR을 같은 화면에서 관리할 수 있다. 테이블 목록·관리 기능은 기존 table.manage, 허용 runtime, 이용권/템플릿 검증을 그대로 사용한다. table.manage만 있는 직원의 기존 관리 접근도 유지한다.
- 새 GET API는 서버에서 소유자/활성 직원 권한을 확인한다. 메뉴판 범위의 공개 QR 경로만 전달하고 관리용 시각·순서·세션 토큰을 팝업 DTO에 넣지 않는다. 모든 응답은 private, no-store다.

## 검증

- 기존 전체 테스트 883건과 추가 QR 탐색 권한 회귀 1건 통과. QR 조회 범위, 대표/테이블 권한 분리, runtime-off, 종료/비공개, 잘못된 ID, 미로그인/무권한, 빈 목록/조회 실패, DTO 최소화 포함.
- 변경 파일 ESLint, TypeScript 포함 최적화 빌드, git diff check 통과.
- 실제 로그인된 로컬 사장 계정에서 팝업 열기, runtime-off 안내, 관리 이동, 대표 QR을 통합 화면에서 제공하는 동작 확인.
- 실제 DOM 1280×720, 390×844, 820×1180에서 Dialog 경계와 가로 넘침 없음 확인. Escape로 닫고 QR 관리 버튼으로 포커스가 복귀함을 확인.
- 운영 배포와 QA 메뉴판의 등록 테이블 다운로드 검증은 출시 후 기록한다.

## 보존

운영 DB/Auth/Storage, 자동 청구, 실제 주문·호출, 테이블 추가·수정·교체·보관과 고객 메뉴판 디자인은 변경하지 않는다. 새 QR을 발급하지 않고 기존 공개 주소를 사용한다.
