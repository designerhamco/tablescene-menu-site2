# AI 기능 개인정보·국외 이전 고지 검토안

최종 갱신: 2026-09-09

## 목적과 현재 상태

이 문서는 실제 사용 중인 OpenAI API와 공개 예정인 AI 상담을 개인정보 처리방침에 정확히 반영하기 위한 운영 검토안이다. 공개 개인정보 처리방침의 수탁자 명칭은 한국 소재 API 고객에게 적용되는 OpenAI DPA의 계약 상대방인 `OpenAI OpCo, LLC`로 구체화했다. 아래 국외 이전 상세 문구는 사업자 또는 법률 검토가 끝나기 전까지 공개 확정문으로 간주하지 않으며, AI 상담 Production runtime은 계속 default-off로 유지한다.

## 확인된 실제 처리 계약

- 이전받는 자: OpenAI OpCo, LLC
- 연락처: privacy@openai.com
- 이용 기능: AI 설명 작성, 메뉴 정리, 자동 번역, AI 상담 답변 생성
- 이전 항목: 이용자가 AI 입력란에 작성한 텍스트, AI가 생성한 결과, 요청 처리에 필요한 기술적 메타데이터
- 이전 시기와 방법: 이용자가 AI 기능을 실행할 때 암호화된 네트워크 통신으로 전송
- 처리 목적: 요청한 AI 기능의 결과 생성, 안정성 확보와 악용 방지
- OpenAI API 보유기간: 기본 악용 모니터링 로그는 최대 30일. 법령상 더 긴 보관이 필요한 예외가 있을 수 있음
- 학습 사용: API 데이터는 기본적으로 모델 학습에 사용되지 않음
- Responses API 설정: ArtiMenu 서버는 `store=false`를 명시해 응답 application state를 저장하지 않음
- ArtiMenu AI 상담 보관: 상담 대화는 계정 DB에 저장하지 않고 현재 브라우저 메모리에서만 유지
- 메뉴 제작 AI 결과: 이용자가 저장한 설명·번역·정리 결과는 일반 메뉴판 데이터 보유정책을 따름

## 공개 고지에 필요한 항목

개인정보 보호법 제28조의8 제2항 기준으로 다음 항목을 빠짐없이 확정해야 한다.

1. 이전되는 개인정보 항목
2. 이전 국가, 시기, 방법
3. 이전받는 법인명과 연락처
4. 이용 목적과 보유·이용기간
5. 이전을 거부하는 방법·절차와 거부 시 영향

## 공개 문구 초안

### OpenAI API 이용

- 이전받는 자: OpenAI OpCo, LLC (privacy@openai.com)
- 이전 항목: AI 입력 텍스트, 생성 결과, 요청 처리에 필요한 기술적 정보
- 이전 목적: AI 설명 작성, 메뉴 정리, 자동 번역 및 AI 상담 답변 생성
- 이전 시기·방법: 이용자가 AI 기능을 실행할 때 암호화된 네트워크 통신으로 전송
- 보유·이용기간: OpenAI API 정책상 기본 악용 모니터링을 위해 최대 30일. 관계 법령에 따른 예외가 있을 수 있음
- 거부 방법과 영향: AI 기능을 사용하지 않는 방법으로 이전을 거부할 수 있다. 거부해도 일반 메뉴판 편집과 1:1 문의는 이용할 수 있으나 AI 생성·정리·번역·상담 기능은 제공되지 않는다.
- 이전 국가: 미국 및 OpenAI가 API 제공을 위해 사용하는 하위 처리 지역

## 공개 전 반드시 결정할 사항

- `이전 국가`를 위 문구와 OpenAI 최신 하위 처리자 목록 링크로 고지할지, 실제 프로젝트 데이터 처리 지역을 별도로 고정한 뒤 단일 또는 제한된 국가로 고지할지 결정
- 계약 이행을 위한 처리위탁·보관 공개를 근거로 할지, AI 기능 최초 이용 시 별도 동의를 함께 받을지 결정
- 기존 AI 설명·정리·번역 기능의 입력·저장 흐름도 같은 고지와 일치하는지 최종 운영 확인
- 개인정보 처리방침 시행일 확정

## 공개 활성화 순서

1. 위 네 가지 결정사항의 사업자·법률 검토
2. 확정된 국외 이전 상세 문구를 `app/privacy/page.tsx`에 반영
3. 개인정보 처리방침 시행일 설정
4. Production `AI_SUPPORT_CHAT_ENABLED=true` 설정과 재배포
5. 공개 상담 기능·민감정보 차단·429 rate limit·비용 사용량 smoke QA
