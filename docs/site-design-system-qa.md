# 공식 사이트 디자인 시스템 검증

## 최종 시각 기준

- 검정 바탕·흰 글자의 주요 CTA/선택 탭, 흰 바탕·검정 글자의 보조 버튼. hover/active는 무채색이며 버튼·필터는 pill이다.
- 노랑은 작은 eyebrow 표시 등 최소한의 강조에만 사용한다.
- 히어로 이미지, 1520px 최대 폭, 기기별 비율·크롭·라운드·배치는 유지한다. 글자 크기/색만 디자인 시스템을 적용한다.
- 기본 메뉴판의 콘텐츠/엔진/fit 정책은 변경하지 않는다. 미리보기 바깥 도구막대는 흰 글자의 대비를 위해 어두운 배경의 불투명도를 보완했다.
