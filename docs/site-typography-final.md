# 최종 사이트 폰트 기준

2026-10-26 사용자가 첨부한 홈 플랜 화면의 전체 비율을 기준으로 한다. PC에서 페이지 제목36px/700, 큰 구역 제목28px/700, 하위 구역 제목24px/700, 대표 가격44px/900, 페이지 설명·일반 본문17px/400, 버튼16px/600, 보조 설명15px, 하단 작은 안내13px로 역할을 고정한다.

## 단일 기준

- 기준 데이터는 `lib/site-typography.ts`의 `SITE_TYPE_STEPS`와 `SITE_TYPE_ROLES`다. 실제 CSS는 `styles/typography.css`, 라이브러리의 역할 표는 같은 데이터를 직접 표시한다. 단위·계약 검사가 CSS와 데이터의 일치를 확인한다.
- 사이트 전용 단계는 13·14·15·16·17·18·20·22·24·26·28·32·36·44px다. 읽는 UI에 이 밖의 크기나 fluid clamp, 임의 px·rem·vw를 추가하지 않는다. 제목 상한36px, 대표 가격 상한44px, 읽는 문구 하한13px다.
- 모바일은 768px 미만, 태블릿은 768–1023px, PC는 1024px 이상이다. 기기별로 고정된 단계를 사용하며 rem과 브라우저 글자 확대는 존중한다.

## 관리 화면의 밀도

마이페이지, 메뉴 편집기, 매장 운영 화면의 **페이지 제목은 일반 페이지와 같은 기준**을 쓴다. 페이지 제목은 모바일28px·태블릿32px·PC36px/700이다. 제목 바로 아래 문구는 마케팅 문구가 아니라 기능 설명이므로 모바일·태블릿16px·PC17px/400의 `type-page-description`을 사용한다. `.site-management-scope`의 조밀한 역할 체계는 그 아래의 실제 작업 영역에만 적용한다. 큰 구역 제목24px/700, 폼 구역 제목20px/700, 콘텐츠 제목17px/600, 항목 제목16px/600, 일반 본문15px/400, 보조 설명14px/400, 라벨14px/600, 메타13px/500로 고정한다. 통계와 작은 결제 금액은24px/700이다. 같은 역할이 페이지마다 달라지지 않게 하고, 카드·폼·내역의 밀도만 페이지 도입부보다 낮춘다.

마이페이지의 안내 문단은400, 상태·메타 강조는500, 폼 라벨과 조작 문구는600을 사용한다. 관리 화면에서 열리는 결제·구독·계정·편집 확인창도 같은 범위를 상속하되, 공통 팝업 제목18px과 본문14px 기준은 유지한다.

로그인·가입·복구뿐 아니라 베이직·다이닝·디스플레이·고객센터·신청·요금·템플릿 목록과 상세 화면에서 H1 바로 아래 설명은 모두 `type-page-description`을 사용한다. 비밀번호 찾기, 이메일 찾기, 회원가입, 로그인 복귀 같은 계정 보조 이동은 `type-body-sm`을 사용해 페이지 설명보다 작게 표시한다. `type-body-lg`는 페이지 상단의 별도 크기가 아니라 섹션 안에서 기본 본문보다 강조할 짧은 문장에만 사용한다.

베이직·다이닝·디스플레이처럼 화면을 전환하는 글자는 본문이 아니다. 탭·세그먼트의 컨트롤 라벨이며 큰 상위 탭은16px, 일반 탭은15px, 조밀한 하위 탭은14px을 사용한다. 템플릿 상세에서는 디자인명 아래 문구가 페이지 설명17px, 기능 섹션의 설명이 기본 본문17px, 기능 카드 요약이 보조 본문15px, 날짜·과금 주석이 메타13px이다.

## 적용 범위와 경계

메인·서비스·가격·상품·템플릿 목록과 상세·고객센터와 공지·가이드·로그인/가입/계정복구·신청·마이페이지·문의·결제·알림·계정·직원·운영·편집·관리자·약관/개인정보/오류 화면의 읽는 UI를 포함한다. 공통 Dialog·Popover·Toast·폼과 카드도 같은 기준을 따른다. 탭·알림창의 형태, 색상, 배치, 서비스 동작은 이번 폰트 정리에서 바꾸지 않는다.

고객이 제작하는 메뉴판과 Display/Pickup 등 손님용 엔진, 메뉴판 미리보기/제품 시연 그림 안의 글자, 로고와 사용자가 따로 승인한 푸터 장식 워드마크는 별도 그래픽 경계다. 메뉴판 기초 `--font-size-*`, 저장된 글자 설정·실제 렌더러·모바일 읽기 비율은 변경하지 않는다. 사이트 전용 `--site-type-*`만 사용한다.

공지의 저장 데이터와 편집 기능은 유지하고, 공개 화면은 기존 허용 크기를 공통 단계 변수에 연결한다. 실제 데이터 저장·결제·AI 질의·동의는 폰트 검수에 포함하지 않는다.
