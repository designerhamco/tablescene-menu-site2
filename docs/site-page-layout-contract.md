# 일반 페이지의 제목과 첫 콘텐츠

박스 안쪽·본문 묶음·폼과 버튼 정렬은 [본문 구성 계약](site-content-layout-contract.md)을 함께 따른다. 페이지 도입부의 간격과 박스 내부 간격은 소유자가 다르며 중복하지 않는다.

2026-10-29 사용자 요청. 공통 서체만 적용하고 페이지마다 상단 패딩·margin을 추가하던 구성을 대체한다.

- 베이직·다이닝·디스플레이 소개·약관·템플릿 목록·FAQ·공지 목록·이용가이드·신청·요금·마이페이지·운영의 일반 제목은 components/layout/SitePageHeader.tsx를 사용한다.
- 헤더 아래 제목 시작은 --site-page-heading-top, 즉 공통 compact 페이지 여백이다. 기본40–64px, 기존 와이드 보정에서는 최대72px이다. 같은 뷰포트에서 일반 페이지 H1 시작 높이는 같다.
- 제목과 설명은 --site-page-title-description-gap=12px. 설명을 포함한 제목 그룹에서 첫 콘텐츠는 --site-page-intro-content-gap, 모바일32px·768px 이상40px다. 여러 줄 설명은 자연스럽게 높이가 늘어난다.
- 공개 일반 페이지는 가운데, 관리 페이지는 시작 정렬이다. 문자 정렬을 바꾸어도 수직 간격은 동일하다. 홈의 홍보 히어로·인증 폼·상품 상세의 별도 구성 역할과 고객 메뉴판 렌더러는 분리한다.
- 제목 그룹에 mt/pb/mb를 페이지마다 중복으로 더하지 않는다. 보조 설명은 그룹 안의12px 간격, 알림 박스·검색·탭·폼은 그룹 다음의 첫 콘텐츠 간격을 사용한다.
- 템플릿 목록의 서비스 탭과 영역 탭은 명시적인32px 그룹 간격이다. 기본 Tabs gap과 별도 margin을 중복으로 더하지 않는다.

## 탭

선택한 최상위 탭의 글자·3px 밑줄·18px·600과 클릭 높이는 유지한다. 밑줄은 클릭 영역 하단에서4px 위로 올려 글자와 가깝게 배치한다. 비선택 글자만 --ui-tab-inactive-text=#969696으로 더 연하게 표시한다.

영역 탭은 연결형 사각 버튼이며 바깥 네 모서리만8px다. 선택은 검정 바탕·흰 글자, 비선택은 흰 바탕·보조 글자색이다. sm44px/상하10px/좌우20px/최소128px, md52px/상하12px/좌우24px/최소160px, lg56px/상하14px/좌우28px/최소176px를 유지한다. equal 분배는 최대36rem에서 같은 폭을 나누며 모바일도 한 줄로 맞춘다. 긴 콘텐츠형 목록은 내부 가로 스크롤을 유지한다. 템플릿은 카테고리부터 페이지네이션까지 밝은 회색 --ui-surface-muted로 묶고 무테·반응형 내부 여백을 사용한다.

추가 가능한 룸·문서 작업 영역에는 `Tabs purpose="section" appearance="document"`를 사용할 수 있다. 흰 선택 탭이 아래 기준선에 연결되며 생성 행동은 탭 옆의 TabsAction으로 구분한다. 기존 section 영역형의 기본 디자인과 다른 탭 역할은 유지한다. 크기·색·포커스·비활성은 공통 문서형 계약을 따른다.

## 고객지원

헤더 고객센터는 마우스오버·클릭·키보드로 열리는 공통 Popover다. 자주 묻는 질문 /faq, 공지사항 /faq/notices, 이용가이드 /guides의 세 페이지로 연결한다. 모바일 메뉴는 고객센터를 서비스와 같은 대분류의 펼침 버튼으로 두고 이 세 페이지를 하위에 표시한다. 푸터도 같은 페이지들을 제공한다. FAQ 아래 공지 목록을 혼합하지 않는다. 기존 FAQ5개·공지10개 페이지 나눔과 공지 상세 경로, AI 상담과1:1 문의는 유지한다.


새 페이지 기본 틀·자동 검사·레거시 이전 원칙은 [자동 적용과 회귀 방지](site-system-enforcement.md)를 따른다. 공지사항은 큰 FAQ 검색 영역 대신 공통 BoardList와 목록 상단의 작은 검색 도구를 사용한다.


## 모바일 본문·푸터 간격 (2026-11-01)

`styles/site-spacing.css`의 의미 기반 토큰을 사용한다. 767px 이하에서는 관련 문구8px, 제목/설명12px, 작은 블록16px, 콘텐츠 묶음24px, 주요 콘텐츠32px, 독립 카드48px, 새 섹션64px, 표면 안쪽20px다. 제목 위치40px·제목 그룹/첫 콘텐츠32px는 기존 계약을 유지한다. 숫자는 16px 기본 rem 환산이며 뷰포트별 글자 배율로 보정하지 않는다.

본문 묶음은 `site-stack-copy`, `site-stack-block`, `site-stack-group`, `site-stack-content`, `site-stack-section`을 사용한다. 이 묶음은 자식의 수직 margin을 없애 gap 한 곳에서 간격을 소유한다. SitePageHeader 경계에 stack 여백을 중복으로 더하지 않는다. 같은 역할의 간격 변경은 공통 토큰에서 하고 페이지 CSS에서 `--site-space-*`를 재정의하지 않는다.

모바일 템플릿 목록은 탭 안내 위아래24px, 배경 안쪽20px, 필터/결과32px, 도구/목록24px, 이미지/카드 정보16px, 카드 사이48px, 페이지네이션 위32px, 별도 상담 영역까지64px다. 좁은 폭의 도구는 기존 순서를 지키고 자연스럽게 줄바꿈한다. 버튼 크기나 기존 기능 위치를 간격 수정으로 바꾸지 않는다.

모바일 푸터는 위32px·좌우24px, 소개/접이식 메뉴32px, 접이식 본문 위8px·아래24px, 약관/저작권16px다. 767px까지 접이식을 사용하고768px 이상은 기존 펼친 구성을 유지한다. 모든 메뉴는 기본 접힘,44px 링크와56px 요약 행, 둥근 회색 면과 내부에서 잘리는 워드마크를 유지한다. 회색 면의 바깥 테두리를 추가하지 않는다.

서비스 소개·홈의 일반 섹션 제목/설명12px·첫 콘텐츠32px, 카드 묶음24px, 주요 섹션64px를 같은 역할 토큰에 연결한다. 이용가이드의 영상/설명24px·문서 사이64px도 동일하다. PC/태블릿 기존 간격과 고객 메뉴판의 독립 모바일 규칙은 변경하지 않는다.

실측과 적용 범위는 [모바일 간격 검수](mobile-site-spacing-qa.md)를 참고한다.


## 설명·도움말 최소화 (2026-11-06)

제목만 기본으로 표시하고 필요한 조건은 공통 도움말에 둡니다. 사용자 요청·박스 내부·상태·데이터·필수 주의사항의 보존 기준과 `descriptionPurpose` 계약은 [디자인 시스템](site-design-system.md#설명도움말-최소화-2026-11-06)을 따릅니다. 코드 전수 점검 범위는 [설명 정리 기록](site-copy-audit.md)에 기록합니다.


룸처럼 독립 선택 버튼이 필요한 영역은 `Tabs purpose="section" appearance="rooms"`를 사용한다. 왼쪽 고정 추가 행동과 스크롤되는 룸 선택, 조건부 오른쪽 페이드와 룸 관리 패널의 최신 계약은 [디자인 시스템의 룸 선택·관리 도구](site-design-system.md#룸-선택관리-도구-2026-11-10-이전-룸-탭-내-이름-편집오른쪽-삭제-배치-대체)를 따른다. `site-content-heading-row data-layout="toolbar"`는 제목과 보기 선택을 모바일에서도 한 행에 두는 공통 변형이다.


운영 메뉴의 제목은 `SectionHeader`의 `type-section-title`로 통일한다. 현재 선택 메뉴판명·소개 문구를 본문 제목에 반복하지 않고, 선택기가 있는 경우 같은 헤더 오른쪽의 공통 `ViewStyleSelect`를 쓴다. 필수 조건은 기존 InfoTooltip, 실제 기간·개수·오류는 원래 위치를 유지한다.
