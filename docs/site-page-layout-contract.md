# 일반 페이지의 제목과 첫 콘텐츠

2026-10-29 사용자 요청. 공통 서체만 적용하고 페이지마다 상단 패딩·margin을 추가하던 구성을 대체한다.

- 베이직·다이닝·디스플레이 소개·약관·템플릿 목록·FAQ·공지 목록·이용가이드·신청·요금·마이페이지·운영의 일반 제목은 components/layout/SitePageHeader.tsx를 사용한다.
- 헤더 아래 제목 시작은 --site-page-heading-top, 즉 공통 compact 페이지 여백이다. 기본40–64px, 기존 와이드 보정에서는 최대72px이다. 같은 뷰포트에서 일반 페이지 H1 시작 높이는 같다.
- 제목과 설명은 --site-page-title-description-gap=12px. 설명을 포함한 제목 그룹에서 첫 콘텐츠는 --site-page-intro-content-gap, 모바일32px·768px 이상40px다. 여러 줄 설명은 자연스럽게 높이가 늘어난다.
- 공개 일반 페이지는 가운데, 관리 페이지는 시작 정렬이다. 문자 정렬을 바꾸어도 수직 간격은 동일하다. 홈의 홍보 히어로·인증 폼·상품 상세의 별도 구성 역할과 고객 메뉴판 렌더러는 분리한다.
- 제목 그룹에 mt/pb/mb를 페이지마다 중복으로 더하지 않는다. 보조 설명은 그룹 안의12px 간격, 알림 박스·검색·탭·폼은 그룹 다음의 첫 콘텐츠 간격을 사용한다.
- 템플릿 목록의 서비스 탭과 영역 탭은 명시적인32px 그룹 간격이다. 기본 Tabs gap과 별도 margin을 중복으로 더하지 않는다.

## 탭

선택한 최상위 탭의 글자·3px 밑줄·18px·600과 클릭 높이는 유지한다. 밑줄은 클릭 영역 하단에서4px 위로 올려 글자와 가깝게 배치한다. 비선택 글자만 --ui-tab-inactive-text=#969696으로 더 연하게 표시한다.

영역 탭은 연결형 사각 버튼이며 바깥 네 모서리만8px다. 선택은 검정 바탕·흰 글자, 비선택은 흰 바탕·보조 글자색이다. sm44px/상하10px/좌우20px/최소128px, md52px/상하12px/좌우24px/최소160px, lg56px/상하14px/좌우28px/최소176px를 유지한다. equal 분배는 최대36rem에서 같은 폭을 나누며 모바일도 한 줄로 맞춘다. 긴 콘텐츠형 목록은 내부 가로 스크롤을 유지한다. 템플릿은 카테고리부터 페이지네이션까지 밝은 회색 --ui-surface-muted로 묶고 무테·반응형 내부 여백을 사용한다.

## 고객지원

헤더 고객센터는 마우스오버·클릭·키보드로 열리는 공통 Popover다. 자주 묻는 질문 /faq, 공지사항 /faq/notices, 이용가이드 /guides의 세 페이지로 연결한다. 모바일 메뉴와 푸터도 같은 페이지들을 제공한다. FAQ 아래 공지 목록을 혼합하지 않는다. 기존 FAQ5개·공지10개 페이지 나눔과 공지 상세 경로, AI 상담과1:1 문의는 유지한다.


새 페이지 기본 틀·자동 검사·레거시 이전 원칙은 [자동 적용과 회귀 방지](site-system-enforcement.md)를 따른다. 공지사항은 큰 FAQ 검색 영역 대신 공통 BoardList와 목록 상단의 작은 검색 도구를 사용한다.
