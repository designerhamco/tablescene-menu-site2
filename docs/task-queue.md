## 2026-10-28 매장 운영 테이블 우선 흐름

- 메뉴판 선택을 상단 탭에서 왼쪽 고정 영역의 셀렉트로 옮기고 현재 이용 가능한 메뉴판만 제공한다. 종료·완전 취소·보관은 제외하며 이용기간이 남은 해지 예약과 공개 전 준비는 유지한다.

- 상품별 주문 ON/OFF는 이번 변경 범위에 포함하지 않는다. 상세: `docs/table-first-operations-qa.md`.
