# 홈 마케팅 화면과 서비스 이동 검증

검증일: 2026-10-16

## 변경

- Next Link로 변경된 주소를 `OriginalApp`의 화면 선택과 스크롤 복원에도 사용한다. 별도 BrowserRouter의 이전 주소가 남아 다이닝·디스플레이 본문이 어긋나던 경로를 제거했다.
- 홈의 기존 히어로 기기 모형을 사용자가 제공한 `투명 배경의 카운터와 세 기기.png`로 교체했다. 투명도를 보존한 1536×1024 WebP는 `public/assets/artimenu-home-hero.webp`이며 약 93KB다.
- 히어로 프레임은 밝은 회색 `#f4f4f5`, 최대 너비 1520px, 32/40px 모서리로 제한한다. 이미지 원본 비율을 유지하며 다음 섹션과 겹치지 않는다.
- 템플릿과 기능 소개는 흰 바탕·어두운 글자, AI와 매장 활용 영역은 어두운 바탕·밝은 글자로 전환했다. 홈의 가이드 CTA는 렌더링하지 않는다.
- 공통 헤더는 스크롤 여부와 관계없이 흰색, 푸터는 검정 계열을 사용한다. 디스플레이 소개 본문의 기존 섹션 색상은 유지한다.

## 실제 브라우저 결과

개발 서버와 로컬 Production 빌드에서 각각 12개 검사가 통과했다.

- PC 1440×1000, 모바일 390×844에서 다이닝→디스플레이→다이닝 3회 반복, 뒤로/앞으로 가기, 새로고침, 디스플레이 직접 진입 후 다이닝 이동이 모두 주소와 본문을 함께 전환했다.
- `/services/basic`, `/services/menu`, `/services/screen`의 직접 진입과 기존 리디렉션을 확인했다.
- 실제 DOM viewport를 아래 치수와 대조했다. 모든 폭에서 가로 넘침 0px, 이미지 비율 유지, 히어로 다음 섹션의 겹침 없음, 요청한 표면/본문 색상, 가이드 미노출을 확인했다.
