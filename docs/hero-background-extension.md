# 아티메뉴 메인 히어로 구도와 배경 노출

2026-11-19 사용자 최종 명확화: **확장 사진을 사용하면서 위험한 신체·과한 인물 노출 부분만 가린다.** 확장본 전체를 빼고 원본과 블러만 사용한 중간 구현은 폐기한다. 공식 사이트 메인 첫 사진 시퀀스만 대상이다.

## 사진·목업 구도

- 장면 높이는 기존100svh다. 기기와 원본 사진은 중앙16:10 노트북 프레임(`min(창 너비, 창 높이 × 1.6)`)에 둔다. 높이 기준 기기 크기·화면 중앙 기준 위치를 유지한다.
- 확장 배경은 별도 뒤쪽 레이어에서 같은 카메라를 사용한다. 생성본1536×1024의 중앙 절반에 원본 사진이 들어 있으므로 원본 좌표에 `matrix(2,0,0,2,-768,-512)`로 맞춘다. 확장 사진과 마스크를 함께 이동·확대하며 가로로 억지로 늘리지 않는다.
- 정상적인 확장 배경은 선명하게 남긴다. 사진의 유한한 끝과 가린 구멍만 기존 인물 없는 매장 사진의 블러·페이드로 연결한다. 와이드에서 원본 바깥 배경이 실제로 보이도록 하되 새 얼굴·몸·비정상 팔은 노출하지 않는다.
- 원본 사진·실제 메뉴 UI가 중앙 기기를 소유한다. 배경 확장본의 중앙 기기 영역은 투명하게 제외해 빈 화면이나 중복 기기가 드러나지 않게 한다.
- 1024px 미만은 기존 기기 폭 제한·초점·제목 회피를 유지한다. 정상적인 천장·벽·테이블의 확장 영역으로 상하 여유를 보완하고 사람·팔을 추가 노출하지 않는다.

## 마스크의 고정 기준

마스크는 **화면 px/화면 비율이 아니라 확장 사진 자체의1536×1024 좌표와 비율**에 고정한다. 같은 사진 속 부위는 창 크기·가로세로 비율·스크롤 확대·역방향 이동과 무관하게 같은 비율로 가린다. 모니터 종횡비가 다르므로 화면 전체에서 가려지는 면적까지 같게 맞추지는 않는다. 달라지는 것은 주변 배경의 노출량이며 가릴 대상은 달라지지 않는다.

심하게 잘린 손목·길어진 팔·추가 생성된 얼굴/몸은 윤곽이 남는 흐림이 아니라 **완전 투명 마스크**로 제외한다. 주변 정상 사진과 연결하는 경계에만 페이드를 둔다. 원래 사진에 있던 정상 손·기기·부분 인물 구도는 유지한다.

- 매장: 인물이 없으므로 확장 배경과 바깥 가장자리 페이드 사용.
- 카운터: 오른쪽 아래 끊긴 소매/팔 영역 제외.
- 다이닝: 왼쪽 생성 고객 얼굴/상체, 오른쪽 생성 직원 얼굴/몸, 하단 추가 신체 제외.
- QR: 왼쪽 생성 고객 얼굴/상체와 하단 길어진 팔/몸 제외.

## 제공 자산·제작 경계

`public/assets/hero-cafe-v3/{venue,counter,dining,phone}-surroundings.svg`가 실제 제공 자산이다. 각 SVG는 기존 생성 사진을 그대로 포함하되 사진 좌표의 마스크를 내부에 고정한 네이티브 합성 자산이다. 파일을 단독으로 열어도 문제 영역이 가려져 있다. 원시 `hero-cafe-v2/*-expanded.webp`는 공개 자산이나 별도 로딩 경로로 복원하지 않는다.

새 사진 픽셀을 생성하거나 기존 목업을 다시 그리지 않았다. 원본 생성 사진은 이전 내장 image_gen 작업 #669의 `f0cc63774aef405c007c2f22e1356a4e194e54bc` 커밋에서 읽는다. `scripts/build-hero-surroundings.mjs`가 사진을 재샘플링하지 않고 SVG 마스크와 합성한다. `provenance.json`에 원본 경로·커밋·SHA256·좌표 매핑을 기록한다. 마스크 조정 시 이 스크립트와 실제 이미지 검수를 함께 갱신한다.

## 장면 연결·원본 복원 — 2026-11-19 후속 수정

첫 매장 사진 `hero-cafe-v1/venue.webp`의3대 TV와 설치 구조는 유지한다. 두 번째 태블릿 장면은 모니터를 작게 바꾼 천장형 수정본이 첫 사진과 다른 공간처럼 보였으므로, 사용자 요청에 따라 **정확한 기존 `hero-cafe-v1/counter.webp`로 복원**한다. 폐기한 `counter-ceiling.webp`는 공개 자산에서 제거한다. 이 장면은 새 사진을 재생성하거나 유사한 구도로 대체하지 않는다. 전환 시간·초점·배율·화면 투영 좌표는 그대로다.

모바일(<768px) 마지막 QR 장면만 사진·손·휴대폰·투영 메뉴·QR 강조를 같은 카메라 캔버스에서 아래로 함께 이동한다. 이동량은 창 높이의2.5%, 최대24px이며, 실제 제목 위 여유(사진 좌표의 기기 아래쪽810px 기준)를 넘지 않는다. 크기·가로 위치는 유지한다. 다른 장면,768px 이상 태블릿·PC의 위치와 구도는 변경하지 않는다.

## 검증

`lib/hero-background-layout.ts`가 프레임·좌표 매핑을 소유한다. `scripts/qa-hero-backgrounds.mjs`는 브라우저가 실제 해석한 SVG 알파를 읽어, 확인된 얼굴/팔 좌표가 완전히0이고 정상 확장 배경 좌표는 불투명하게 남는지 화면별로 확인한다. 원본·배경 카메라의 위치/배율 일치, 높이 기준 목업 크기/위치, 원시 확장본 요청0건, 이미지 로드, 가로 넘침, 확대·역방향 이동·모바일 스와이프도 확인한다. 새 확장 사진은 먼저 인물/신체 경계를 다시 검수해야 하며 기존 마스크를 다른 사진에 그대로 재사용하지 않는다.
