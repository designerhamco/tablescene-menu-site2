# 아티메뉴 서비스·요금·이용권 기준

기준일: 2026-11-25. 현재 코드 원본과 공개 안내의 문서 지도다. 아래 가격표는 조회용 요약이며 실행 코드의 가격 원본을 대체하지 않는다.

## 서비스와 이용권

| 서비스 | 구성 | 신규 신청 안내 |
| --- | --- | --- |
| 베이직 | 같은 메뉴판의 기본 디자인/디자이너 스킨, 리스트/지원 앨범, 공통 contained reading | 메뉴판 1개당 월 구독 |
| 다이닝 | 커버·본문 페이지, 코스/일반 카테고리, 전면/좌측 탐색, 리스트/지원 앨범 | 메뉴판 1개당 월 구독 |
| 디스플레이 | TV/모니터용 별도 renderer | 공개 신청 화면은 준비 중. 가격표나 호환 코드가 있다고 판매/결제가 활성화된 것은 아님 |
| 커스텀 | 개별 상담 범위 | 고정 월요금이 아니라 별도 견적 |

베이직·다이닝·디스플레이 각각의 서비스 요금 하나로 해당 서비스의 모든 지원 템플릿을 사용한다. 기본 디자인/디자인 템플릿(`CatalogKind`)은 외형과 탐색 구분이며 가격·권한의 차이가 아니다. 기존 `menu_design_access: standard`나 버전이 없는 유효 계약도 동일하게 접근한다. 신규 Basic/Dining 계약은 호환 필드에 `all`을 기록한다. 템플릿 교체는 업종 제한·추가 요금·이용권 전환·차액·다음 결제일 예약 없이 편집기에서 적용한다. 서비스 간 교체·소유권·만료 제한과 운영 기능 게이트는 유지한다. 메뉴·QR·운영 설정·계약을 새 스타터로 덮어쓰지 않으며 템플릿별 디자인 스냅샷을 보존한다. 지원 디자인은 [템플릿 등록표](template-docs-index.md)를 따른다. 퇴역 디자인은 새로 선택하지 않는다.

## 현행 월요금

Basic/Dining 원본은 [menu-plan-pricing.ts](../lib/menu-plan-pricing.ts)의 `menuPlanPricebook`/`getMenuPlanMonthlyPrice`다. 가격표/계약 버전은 `2026-11-25`, 통화는 KRW이며 부가세 포함이다.

| 서비스 | 정상 월요금 | 얼리버드 월요금 |
| --- | --- | --- |
| 베이직 전체 템플릿 | 5,900원 | 4,900원 |
| 다이닝 전체 템플릿 | 8,900원 | 6,900원 |
| 디스플레이 안내 금액 | 12,900원 | 10,900원 |

디자인 추가 요금은 없다. 과거 견적/동의 금액은 `legacyMenuPlanPricebook`에 보존하며 현재 가격을 계산하는 원본으로 사용하지 않는다. Display 금액은 [display-pricing.ts](../lib/display-pricing.ts), 실제 신청 준비 상태는 [Display 신청 페이지](../app/apply/display/page.tsx)를 함께 확인한다. Display의 판매/결제 준비 게이트는 열지 않는다. 연간 가격·예전 금액은 과거 계약/환불 호환용일 수 있으므로 신규 월요금으로 사용하지 않는다.

프로모션 기간은 [policy-dates.ts](../lib/policy-dates.ts)가 소유한다. 현재 표시는 2026년 10월 1일~12월 31일이며 실제 적용 여부는 서버의 자격/기간 검증을 따른다. 코드의 현재 가격과 이미 결제·동의한 계약 금액을 구분한다.

## 체험·청구·기존 계약

[공개 상품 안내](../lib/public-product-details.ts)와 [business-free-trial.ts](../lib/business-free-trial.ts)는 계정당 최초 1회 30일 체험, 결제수단 등록, 체험 종료 후 첫 결제 및 체험 종료 전 해지 시 첫 결제 미실행을 설명한다. 실제 체험 제공은 기능 활성화와 서버 자격 검증을 통과해야 한다. 문서만으로 특정 계정의 체험/청구 여부를 판정하지 않는다.

과거 영수증·주문·결제 복구 금액은 새 가격표로 재계산하지 않는다. `2026-10-21` 월 계약 중 식별 가능한 디자인 포함 추가 요금만 다음 정상 갱신에서 제외한다: Basic 6,800→4,900/7,800→5,900원, Dining 8,800→6,900/10,800→8,900원. 원래 얼리버드/정상가 유형은 유지하며 갱신 성공 뒤 구독의 다음 청구 금액을 기록한다. 실패·건너뜀·dry run에서는 계약을 쓰지 않는다. 연간·예전 상품·별도 금액은 보존한다. 현재 구독 안내는 정상 갱신 계산과 같고 과거 결제 상세는 실제 원장 금액을 사용한다.

[기존 전환 원장](runbooks/menu-plan-change-reservations.md)의 신규 POST/서버 예약 접수는 종료한다. 과거 동의 예약의 조회·취소·고정 견적 갱신·중복 결제 방지는 보존하고 기존 환경 실행 게이트를 열지 않는다. 메뉴판의 현재 권한은 예약의 과거 `standard` 필드와 무관하게 같은 서비스 전체다. 해지·환불은 [공개 약관 원문](../lib/legal-documents.ts)과 해당 서버 경로를 함께 확인한다. 이 문서는 환불 정책을 새로 정하지 않는다.

## AI 크레딧

[AI 크레딧 정책](ai-credit-policy.md)은 첫 메뉴판 생성 완료 시 6개를 계정당 1회 지급하는 기준이다. 사용 비용과 충전 금액의 원본은 [ai-credits.ts](../lib/ai-credits.ts)다. 현재 비용은 설명/부분 번역 1개, 메뉴 정리/전체 번역 3개이며, 충전은 10개 1,500원·30개 3,900원·60개 6,900원이다. 무료 지급과 별도 구매 크레딧의 정책/기록을 혼동하지 않는다.

## 가격·서비스 변경의 완료 기준

가격 원본, 서버 견적/결제 검증, 상품 상세/목록/신청/요금/FAQ 안내, 관련 약관/동의의 영향 범위와 이 문서를 함께 확인한다. 가격이 안내 컴포넌트에 직접 들어간 경우도 검색한다. 과거 문서/영수증을 일괄 재계산하지 않는다. 내부 상품키의 single/multi는 고객 서비스 명칭을 바꾸는 이유로 수정하지 않는다.

관련 자료: [서비스 명칭 기준](service-category-copy-contract.md), [이용권 도입·운영 적용 기록](runbooks/menu-design-subscription-contract.md), [주문·호출 계약](order-call-product-contract.md), [약관·개인정보 검토 현황](legal-policy-review.md).

2026-11-11 문서 대조에서는 현재 가격 코드를 읽고 공개 `/pricing`, `/terms`, `/privacy`의 HTTP 200 응답과 주요 안내 존재를 확인했다. 실제 결제·환불·구독 변경·고객 데이터 쓰기는 하지 않았다. 모든 가격 표시 경로의 회귀 검수나 실제 청구 검증 완료를 뜻하지 않는다.

## 2026-11-25 변경 전 읽기 점검

운영 DB 읽기 집계에서 구독 27건, 전환 원장 0건을 확인했다. 유효한 월 6,800원 Basic 계약 1건과 월 6,900원 Dining 계약 1건이 있었다. 집계만 수행했으며 고객 데이터·청구·취소·환불·SQL migration은 실행하지 않았다. 과거 문서의 금액/전환 QA는 당시 기록이며 현행 가격 정책의 증거로 재사용하지 않는다.
