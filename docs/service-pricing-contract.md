# 아티메뉴 서비스·요금·이용권 기준

기준일: 2026-11-11. 현재 코드 원본과 공개 안내의 문서 지도다. 아래 가격표는 조회용 요약이며 실행 코드의 가격 원본을 대체하지 않는다.

## 서비스와 이용권

| 서비스 | 구성 | 신규 신청 안내 |
| --- | --- | --- |
| 베이직 | 같은 메뉴판의 기본 디자인/디자이너 스킨, 리스트/지원 앨범, 공통 contained reading | 메뉴판 1개당 월 구독 |
| 다이닝 | 커버·본문 페이지, 코스/일반 카테고리, 전면/좌측 탐색, 리스트/지원 앨범 | 메뉴판 1개당 월 구독 |
| 디스플레이 | TV/모니터용 별도 renderer | 공개 신청 화면은 준비 중. 가격표나 호환 코드가 있다고 판매/결제가 활성화된 것은 아님 |
| 커스텀 | 개별 상담 범위 | 고정 월요금이 아니라 별도 견적 |

Basic/Dining의 `standard`는 같은 서비스의 기본 디자인, `all`은 같은 서비스의 기본+디자이너 디자인 이용 범위다. 디자인 이용권은 운영 기능 권한 자체를 확대하지 않는다. 다른 서비스로 교체하지 않으며 기존 메뉴·QR·계약을 새 스타터로 덮어쓰지 않는다. 기본 디자인은 현재 Basic 7종·Dining 4종이며 [템플릿 등록표](template-docs-index.md)를 따른다.

## 현행 월요금

Basic/Dining 원본은 [menu-plan-pricing.ts](../lib/menu-plan-pricing.ts)의 `menuPlanPricebook`/`getMenuPlanMonthlyPrice`다. 가격표 버전은 `2026-10-19`, 통화는 KRW이며 부가세 포함이다.

| 서비스·이용권 | 정상 월요금 | 얼리버드 월요금 |
| --- | --- | --- |
| 베이직 기본 디자인 | 5,900원 | 4,900원 |
| 베이직 디자인 포함 | 7,800원 | 6,800원 |
| 다이닝 기본 디자인 | 8,900원 | 6,900원 |
| 다이닝 디자인 포함 | 10,800원 | 8,800원 |
| 디스플레이 안내 금액 | 12,900원 | 10,900원 |

디자인 포함은 Basic/Dining 기본 요금에 월 1,900원을 더한다. Display 금액은 [display-pricing.ts](../lib/display-pricing.ts), 실제 신청 준비 상태는 [Display 신청 페이지](../app/apply/display/page.tsx)를 함께 확인한다. 연간 가격·예전 금액은 과거 계약/환불 호환용일 수 있으므로 신규 월요금으로 사용하지 않는다.

프로모션 기간은 [policy-dates.ts](../lib/policy-dates.ts)가 소유한다. 현재 표시는 2026년 10월 1일~12월 31일이며 실제 적용 여부는 서버의 자격/기간 검증을 따른다. 코드의 현재 가격과 이미 결제·동의한 계약 금액을 구분한다.

## 체험·청구·기존 계약

[공개 상품 안내](../lib/public-product-details.ts)와 [business-free-trial.ts](../lib/business-free-trial.ts)는 계정당 최초 1회 30일 체험, 결제수단 등록, 체험 종료 후 첫 결제 및 체험 종료 전 해지 시 첫 결제 미실행을 설명한다. 실제 체험 제공은 기능 활성화와 서버 자격 검증을 통과해야 한다. 문서만으로 특정 계정의 체험/청구 여부를 판정하지 않는다.

기존 계약·영수증의 금액은 새 가격표로 재계산하지 않는다. 고객이 선택한 이용권 전환은 [다음 결제일 전환 계약](runbooks/menu-plan-change-reservations.md)을 따르며 중간 차액/즉시 청구/자동 이관을 임의로 추가하지 않는다. 해지·환불은 [공개 약관 원문](../lib/legal-documents.ts)과 해당 서버 경로를 함께 확인한다. 이 문서는 환불 정책을 새로 정하지 않는다.

## AI 크레딧

[AI 크레딧 정책](ai-credit-policy.md)은 첫 메뉴판 생성 완료 시 6개를 계정당 1회 지급하는 기준이다. 사용 비용과 충전 금액의 원본은 [ai-credits.ts](../lib/ai-credits.ts)다. 현재 비용은 설명/부분 번역 1개, 메뉴 정리/전체 번역 3개이며, 충전은 10개 1,500원·30개 3,900원·60개 6,900원이다. 무료 지급과 별도 구매 크레딧의 정책/기록을 혼동하지 않는다.

## 가격·서비스 변경의 완료 기준

가격 원본, 서버 견적/결제 검증, 상품 상세/목록/신청/요금/FAQ 안내, 관련 약관/동의의 영향 범위와 이 문서를 함께 확인한다. 가격이 안내 컴포넌트에 직접 들어간 경우도 검색한다. 과거 문서/영수증을 일괄 재계산하지 않는다. 내부 상품키의 single/multi는 고객 서비스 명칭을 바꾸는 이유로 수정하지 않는다.
