# 통합 컴포넌트와 실제 사용처 검수 — 2026-10-26

## 범위

사용자 첨부 참고6장의 알림 패널, 현황 카드, 필터, 거래형 상세 카드, 안내 바, 날짜/차트/링, 공유 모달과 옵션별 요금 카드를 아티메뉴 공통 컴포넌트로 매핑한다. 기존 `/design-system`에 기준·토큰 탭을 추가하고 실제 사용처와 같은 구현을 보여준다. 라이브러리 예시를 운영 데이터처럼 표현하지 않는다.

## 검증 기록

- 기존 전체832개 테스트 통과. 헤더 레이어와 운영 카드 계약 검사는 옮겨진 공통 컴포넌트 연결을 검사하도록 갱신했다.
- 타입 검사와 변경 TSX 린트 통과.
- 로컬390×844에서 알림 예시의 미확인1→0 전환, 빈 상태, 조회 결과 없음/복원, 상세 펼치기, 날짜25일의120,000원 표시, 디자인 포함 탭의월6,800원/정상가7,800원과 실제 이동 경로를 확인했다.
- SVG title을 단일 문자열로 렌더링해 초기 hydration 불일치를 수정했다. 날짜 줄의 flex 기준 폭과 내부 overflow를 수정해 모바일 전체 가로 넘침을0px로 복원했다.
- 저장·결제·환불·주문 상태 변경·호출 처리·실제 알림 읽음 변경·알림 권한 동의는 검수에서 실행하지 않는다.
- 실제320×740,390×844,820×1180 라이브러리와1440×1000 요금 화면에서 페이지 가로 넘침0px를 확인했다.
- 실제 템플릿 상세에서 공유 모달의 현재 링크 일치, 복사 성공, Escape 닫기 후 원래 버튼으로 포커스 복귀를 확인했다.
- Production 빌드 성공. 기존 조회·신청 경로를 유지하며 새 유료 실행은 추가하지 않았다.
