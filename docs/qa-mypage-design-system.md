# 마이페이지 디자인 시스템 점검 — 2026-10-25

## 원인과 변경

공통 type-nav 토큰이14px에서 PC16px로 확대되어 공식 헤더까지 커졌다. 헤더는14px로 복원한다. 마이페이지에는 기존 개별 pill 링크 탭, 서로 다른 빈 목록, 명시적 site-field 연결이 없는 네이티브 폼과 작은 메뉴판 액션이 남아 있었다.

NavigationTabs는 기존 URL·권한·건수를 유지하는 링크 탐색이다. 선택 상태는 aria-current=page로 전달한다. 메뉴/결제/운영 전환에 적용했으며, 계정 사이드 메뉴도 활성 페이지와14px/40px 탐색 규격을 사용한다. 일반 설명은400, 라벨/값은 기존 강조를 유지한다. 빈 목록은 같은 EmptyState에 연결하고 문맥에 맞는 heading level을 보유한다. 메뉴판 편집/미리보기/공개/QR은40px 라운드 사각, 일반 폼·모달·편집·운영 실행은40px 라운드 사각이다.

- 수정 전 로그인된 전용 QA 세션에서6개 주요 메뉴와 문의 검색의 실제 규격을 확인했다. 문의 검색은 이미16px/40px/16px 라운드의 공통 규칙을 사용하고 있었다.
- 일부 하위 화면은 기능/권한 게이트로 상위 페이지로 이동하므로, UI에 기능을 강제로 노출하지 않고 해당 소스와 기존 권한 계약 테스트로 검사한다.
- Production build, TypeScript, 변경 파일 ESLint와 전체 단위 테스트를 확인한다. 운영 반영 후에는 로그인 세션의 전체 주요 메뉴 및 접근 가능한 하위 화면에서 PC/태블릿/모바일을 다시 확인한다.

### 공통 수정

- NavigationTabs는 활성 링크가 가로 스크롤 영역 밖에 있을 때 해당 rail의 scrollLeft만 조정한다. 선택 변경·폭 변경·서체 로드에 맞춰 다시 확인하며 본문 세로 위치는 이동하지 않는다. 실제 링크·권한·건수·aria-current는 유지한다.
- 호출관리와 다국어2묶음은 기존 공통48px/16px/4px underline 탭을 사용한다. 다국어의 언어·대상 상태와 편집 초안은 기존 상위 상태로 보존한다.
- 연결형 패널의 상단 오른쪽 누락을 고친다. 탭과 연결하는 상단 왼쪽을 제외한 바깥 모서리는12px로 같다.
