# 표시 아이콘 표면 규칙 검수 (2026-11-03)

사용자가 확정한 기준은 아이콘의 바로 뒤 표면이다. 흰색 알림 영역의 옅은 회색·노랑 바탕을 보존하고, 회색·유색 위에 겹친 별도 아이콘 바탕만 제거한다. 페이지 전체 배경을 기준으로 삼거나 모든 아이콘 바탕을 일괄 삭제하지 않는다.

## 적용

- 공통 `site-indicator-icon` + `data-icon-surface="white" | "colored"`. colored는 background transparent, border 0, shadow none만 적용하며 기존 글자색·SVG 크기·슬롯·간격은 보존한다.
- EmptyState는 회색 표면, MetricCard는 실제 white/muted 카드별 표면을 전달한다. 흰 NotificationPanel의 바탕과 읽지 않은 점은 보존한다. 알림 행 hover가 회색으로 바뀌면 아이콘 바탕만 제거한다.
- 디자인 시스템의 배경 3종·회색 안 흰 카드 비교 예시, 디자인 시스템/컨트롤 문서와 AGENTS 규칙을 갱신했다. 공통 아이콘 CSS를 개별 페이지에서 재정의하면 사이트 시스템 검사가 차단한다.
- 아이콘 버튼·로고·프로필·제품 화면 일러스트와 고객 메뉴판 렌더러는 변경하지 않는다. 데이터·저장 로직·권한 변경이 없다.

## 검증

- 전체 테스트 999개, 사이트 UI 계약 104개, TypeScript와 변경 파일 ESLint, 별도 출력 경로 Production 빌드 통과.
- Chrome 실제 320×1000, 390×1000, 820×1000, 1440×1000: fonts loaded, 가로 넘침 0px, 비교 예시 아이콘 6개 모두 해당 영역 안에 위치한다.
- 흰 표면의 중립 아이콘 바탕 rgb(240,241,243), 흰 카드의 초록 바탕 rgb(240,253,244) 유지. 회색 rgb(247,248,250)·유색 rgb(255,248,214) 표면 위 아이콘 바탕은 transparent다. 색 바탕을 제거한 경우 추가 border 0px / shadow none을 확인했다.
- 흰 알림 영역의 바탕은 unread rgb(255,248,214), read rgb(240,241,243), 읽지 않은 점 rgb(196,16,16)을 유지한다. 실제 알림을 클릭하거나 읽음 상태를 바꾸지 않았다. hover 규칙은 CSS/계약 검사 범위로 확인했다.
- 기존 운영 테이블 빈 상태를 배포 전 읽기 전용으로 측정: 흰 바탕, 슬롯48×48px, SVG28×28px, 선1.5px. 수정된 동일 공통 컴포넌트는 슬롯48×48px, SVG28×28px을 유지하며 바탕만 transparent다. 현황 아이콘도 슬롯40×40px, SVG20×20px을 유지한다.
- 로컬 브라우저 오류 로그 0개. 원본 측정·스크린샷은 로컬 `tmp/qa/indicator-surface/`에 보관한다.
