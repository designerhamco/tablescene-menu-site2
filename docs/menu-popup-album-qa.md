# 광고 팝업·앨범형 — 2026-10-20

## 동작과 범위

- 기본 디자인 보기 옵션 팝업 기본 OFF. ON은 3장 중립 예시를 표시하며 기존 6종과 새 앨범형 모두 지원한다. 팝업 선택은 기기/언어/새 창에 보존한다.
- 메뉴관리 기본 정보에 광고 팝업 사용/이미지 최대 3장 추가·삭제·저장을 제공한다. 기존 권한 검사·5MB JPG/PNG/WebP 업로드 흐름을 사용한다. 저장 이전에는 공개 메뉴를 바꾸지 않는다. 미등록/기존 메뉴는 OFF다. Display 제외.
- 저장 형태는 `menu_sites.settings.advertisementPopup={enabled,images:[{imageUrl,imagePath}]}`다. 기존 설정과 합쳐 저장하며 스키마/RLS 변경은 없다. 서버는 최대3장·본인 메뉴 draft/popup 경로·프로젝트 Storage 공개 URL 일치를 확인한다. owner/staff `menu.edit` 쓰기 게이트를 재사용한다.
- 팝업은 원본 비율을 유지하고 한 장일 때 dot가 없다. 2·3장은 dot 클릭/마우스 드래그/모바일 터치 스와이프와 방향키로 이동한다. 하단 닫기/당일 숨김과 단순 X를 제공한다. Radix dialog로 포커스·Escape·본문 스크롤 잠금을 처리한다.
- 당일 숨김은 메뉴별 localStorage 만료시각이며 한국 시간 자정까지다. 일반 닫기는 다음 진입에 다시 보여준다. 미리보기에서는 체크/닫기를 시험하되 고객용 당일 숨김을 저장하지 않는다.
- 기존 6종을 유지하고 `basic-first-column-album`, `basic-top-row-album`, `dining-full-page-album`, `dining-sidebar-album` 4종을 같은 기본 구조의 새 검토 시안으로 추가한다. 기존 일반 템플릿/고객 데이터/상품 표시 방식은 변경하지 않는다. 유료 구독·편집기 디자인 선택 확장은 기존 후속 단계다.
- 앨범 카드는 정사각형 사진 위, 이름/보조명/설명, 가격·인접 담기 순서다. PC/태블릿은 가용 폭과 최소 카드 폭에 따라 자동 열 수를 사용한다. 모바일은 1~2열이며 긴 다이닝 가격 옵션이 있으면 넓은 카드가 우선이다. 대표영역·언어·고정 버튼은 기존 구조를 재사용하고 메뉴만 스크롤한다. 상품이 적어도 카드 트랙 폭을 유지한다.
- 베이직 앨범은 가격 옵션 열을 지원하지 않으며 해당 보기 옵션도 숨긴다. 가격 설명·할인·품절·일반 칩은 유지한다. 다이닝은 실제 세로 가격 옵션과 코스 전체 주문을 유지한다. 기존 목록형의 모바일 옵션 순서는 변경하지 않는다.
- 대표영역 내용 정렬 선택은 후속이며 `docs/task-queue.md`에 기록했다. 긴급 모바일 사진 커버 바 투명화는 PR #269로 먼저 배포했다.
