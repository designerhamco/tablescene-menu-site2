## 현재 계약

- 기본 디자인 보기 옵션 이름은 **광고**, 기본 OFF다. 기기·언어·새 창 이동에 선택을 보존한다. 기존 6종 목록형과 앨범형 4종을 지원한다.
- 메뉴관리의 별도 **광고** 탭으로 등록 UI를 이동했다. 최대 3장 추가·제외·저장, 기존 `menu.edit` 권한 및 5MB JPG/PNG/WebP 업로드 경로, 저장 전 draft 정책을 유지한다. 저장 결과/오류도 해당 탭에서 표시한다. Display는 제외한다.
- `menu_sites.settings.advertisementPopup={enabled,images:[{imageUrl,imagePath}]}`를 기존 JSON 설정에 합쳐 저장한다. 스키마/RLS/Storage 정책 변경 없음. 서버는 최대3장, 본인 메뉴 draft/popup 경로, 프로젝트 Storage URL 일치를 검사한다.
- 광고 이미지는 레이어 너비를 채운다. 높이가 화면을 넘는 긴 이미지는 `cover`로 잘릴 수 있다. 예시는 대표영역과 같은 중립 이미지 자리이며 3장 배경 명도만 조금 다르다.
- 이미지 안쪽 하단에 6px dot/14px 중심 간격을 사용한다. 1장은 숨기고 2·3장은 dot 클릭/마우스 드래그/터치 스와이프/방향키로 이동한다. 흰 X에 그림자를 적용하며 배경 박스는 없다. 레이어 테두리/외곽 포커스 선/하단 탭을 제거했다. 키보드로 진입한 실제 컨트롤의 포커스는 유지한다.
- 오늘 하루 보지 않기와 localStorage 숨김 로직을 제거했다. 이전 숨김 키가 남아 있어도 읽지 않으며 일반 닫기 후 재진입 시 다시 표시한다. Radix 포커스 트랩·Escape·스크롤 잠금은 유지한다.
- 베이직 앨범은 가격 옵션 열을 지원하지 않으며 가격 설명·할인·품절·칩은 유지한다. 가격 행의 담기 아이콘은 카드 오른쪽 끝이다. 앨범에서는 기존 목록형 13rem 가격 최대 너비를 해제해 실제 카드 너비로 정렬한다. 상단행 앨범의 대표영역 기본 OFF, 명시적 ON은 가능하다.
- 다이닝 앨범은 가격 옵션마다 점선/우측 가격을 하나씩 표시하고 담기는 카드 오른쪽 끝에 둔다. 모바일 일반 상품과 단독 페어링은 가격 옵션과 무관하게 같은 최소 카드 폭·열 간격으로 1~2열을 사용한다. 가격이 설정된 코스는 이미지 금지·아이템 1열을 지키며 코스 전체만 주문한다.
- 기존 6종 목록형과 고객 템플릿의 서체/간격/모바일 읽기 규칙, 대표영역/호출/주문 팔레트는 유지한다. 대표영역 정렬과 확장 색상 편집기는 후속이다.
