# 아티메뉴 서비스 명칭과 안내 기준 — 2026-11-11

고객에게 보이는 서비스 분류는 **베이직 / 다이닝 / 디스플레이**다. 원페이지·단일페이지·멀티페이지를 상품이나 요금제의 이름으로 사용하지 않는다. 여러 페이지, 커버, 한 화면 등의 표현은 실제 화면 구성의 기능 설명에만 사용한다.

- 템플릿 목록·상세·신청/결제·내 메뉴판·구독/결제 내역·복구 안내·FAQ·AI 상담·약관/개인정보 안내에서 같은 명칭을 사용한다.
- 기본 디자인 / 디자인 포함은 서비스와 별개인 이용권 범위다. 템플릿 상세의 가격 라벨은 서비스와 이용권을 함께 표시한다.
- `lib/service-categories.ts`는 표시용 분류다. 명확한 구독 상품키를 우선하고, 이전 통합 구독과 상품키 없는 메뉴판은 실제 템플릿으로 구분한다. 근거가 없으면 임의로 다이닝이나 베이직이라고 표시하지 않는다.
- 마이페이지의 서비스 배지, 구독명, 결제 내역의 필터와 서비스 칸은 실제 상품/메뉴판의 분류를 사용한다. 복구 가능한 구독 후보와 기존 승인 조건은 유지한다.
- 신규 베이직·다이닝은 메뉴판별 월 구독과 같은 서비스 내 이용권 범위의 디자인 교체를 안내한다. 기존 구독은 기존 계약을 유지한다. 위젯 등 지원 기능은 디자인마다 다를 수 있다.
- 내부 `single`/`multi`, `business_basic_*`, `serviceType: basic`, 렌더러의 one-page/multi-page 명칭은 호환성을 위한 식별자다. 고객 문구 정리를 이유로 변경하거나 데이터 마이그레이션하지 않는다.

이번 약관·개인정보 안내 수정은 서비스 명칭 정리와 베이직의 목록 누락 보완이다. 요금, 결제 주기, 무료체험, 해지, 환불, 개인정보 처리·보유 조건, 시행일은 변경하지 않는다. 기존 결제/영수증 데이터는 수정하지 않는다.

## 검증

- 전체 테스트 1,232개, `check:site-ui`(사이트 시스템 자동 검사 포함), 별도 TypeScript 검사, 프로덕션 빌드 통과.
- 변경 파일 ESLint 오류 0개. 기존 ignore 대상인 FAQ 파일 안내 경고만 확인.
- 로컬 프로덕션 빌드(3004)에서 실제 뷰포트 1440×1000, 820×1180, 390×844 확인. 세 서비스와 기본 디자인 상세, 주문 진입/요약, 약관/개인정보/다이닝 소개에 가로 넘침 없음.
- 로그인된 마이페이지에서 내 메뉴판의 세 서비스 배지와 결제 내역의 독립 필터를 확인. 결제·복구·구독 변경·사업자 확인은 실행하지 않음.
