# 고객센터 FAQ·공지 목록 구성

2026-10-29 사용자 승인: FAQ/공지사항 전환 탭을 없애고 FAQ 아래에 최신 공지 최대3건과 전체보기를 둔다. 공통 검색 필드, 밑줄 주제 분류, FAQ 아코디언, ContentList, 버튼·글자·간격 토큰을 유지한다.

- /faq는 FAQ를 바로 표시하고 최신 공지를 게시일/ID 내림차순으로 최대3건 조회한다. 공개 상태이며 게시일이 현재 이전인 글만 포함한다. 고정 공지 우선 정렬은 전체 목록에서만 유지한다.
- /faq/notices는 기존 검색·주제·페이지 이동이 있는 전체 공지 목록이다. /faq?tab=notices는 이 경로로 연결하고 상세의 목록 복귀도 같은 경로를 사용한다.
- 최신 공지는 서버에서 별도로 스트리밍하므로 FAQ 사용을 막지 않는다. 로딩·빈 목록·조회 실패를 구분하고 전체보기 링크는 항상 제공한다. FAQ 검색·주제 변경은 최신 공지에 영향을 주지 않는다.
- 운영 DB/Auth/Storage·공지 원문과 공개 상태를 변경하지 않는다. 현재 공개 공지1건은 그대로1건만 표시한다. 3건을 채우기 위한 임의 공지는 등록하지 않는다.

검증: 전체 단위/계약900건, 변경 파일 ESLint, TypeScript, 최적화 빌드 통과. 최신3건의 정렬·공개 범위·빈 목록·실패·전체 목록 기존 정렬은 격리 검증했다. 브라우저에서 1280×720, 820×1180, 390×844와 320×780의 FAQ/공지 구분·가로 넘침, 검색/해제·주제·FAQ 펼치기, 전체보기·상세·목록 복귀·과거 링크 연결을 확인했다. 운영 배포 완료는 공급자 성공과 /faq 실제 화면으로 확인한다.
