# 메뉴 편집기 배경·대표영역 설정 — 2026-10-21

승인한 배경·정렬을 기존 디자인 저장 경로에 연결했다. 새 값을 선택하지 않은 고객 메뉴판의 스킨·모바일 간격은 유지한다. 운영 데이터 일괄 수정이나 스키마 변경은 없다.

## 메뉴관리 → 디자인

- 베이직: 페이지 배경색 / 보조 배경색 / 대표영역 내용 정렬(템플릿 기본·왼쪽·가운데·오른쪽). 보조 배경이 페이지와 다르면 기존 공통 패널 로직으로 내부 여백과 색상 가장자리 기준 열 간격을 예약한다. 같거나 기본이면 기존 비패널 배치다. 모바일 메뉴 간격·가격·안내 앵커는 변경하지 않는다.
- 다이닝: 본문 페이지 / 커버 / 좌측 메뉴열 배경을 독립 저장한다. 메뉴열은 좌측 내비게이션형만 표시하고 모바일 페이지 탭에도 같은 배경·대비색을 적용한다. 커버 배경은 기존 커버 탭과 같은 `multi_page_cover_background_color`를 재사용한다. 이미지·75 기본 불투명도·본문 이동 구조는 별개다.
- 다이닝 커버 소개 글자색은 본문 설명색과 독립한다. 서체 그룹은 가게명/카테고리명/나머지 문구 세 그룹을 유지한다. 커버 소개의 큰 크기도 유지한다.
- 기존 공통 컬러피커의 HEX 입력과 옆 되돌리기를 재사용한다. 저장·다시 열기·전체 기본값 복원·디자인 교체 복귀를 지원한다. 기본 디자인의 초기화는 원래 디자이너 서체가 아닌 중립 기본 서체로 돌아간다.
- 이미지 모양은 기존 다섯 프리셋을 유지한다. 상품 이미지 비율 선택은 저장된 앨범 디자인에만 노출한다. 목록형에 저장된 과거 비율은 숨긴 필드로 보존한다.

## 저장과 권한

`lib/menu-design-surfaces.ts`는 입력 검증·기본값·JSON 적용을 공유한다. 기존 서버 액션의 소유자/편집 권한 확인과 제한된 메뉴 행 갱신·재검증을 유지한다. 폼 마커가 없는 구버전 요청은 새 설정을 지우지 않는다. 설명·이미지·할인·불투명도와 알 수 없는 기존 키는 보존한다. 디자인 스냅샷에 다이닝 커버 배경을 포함해 교체 후 복원한다.

카탈로그 디자인 옵션에도 대표영역 정렬과 다이닝 커버 소개색을 제공한다. 고객 공개 메뉴는 URL 미리보기 옵션 대신 저장한 값으로 렌더링한다.

- 운영 고객 계정의 실제 저장 행은 검사를 위해 변경하지 않는다.
