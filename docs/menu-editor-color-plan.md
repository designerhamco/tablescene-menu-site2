# 메뉴 편집기 색상 설정 후속 — 2026-10-20

이 문서는 승인한 방향과 현재 지원 범위를 정리한다. 독립 배경색과 다이닝 커버 설명색은 후속이며, 공통 나머지 글자 색상은 2026-10-20에 UI·저장·렌더러를 연결했다.

## 현재 지원

- `TypographySettingsForm`: 가게명/카테고리 색상은 가능하다. `otherText`도 메뉴명/설명/가격 역할에 한 색상을 함께 지정·저장·초기화한다. 기본값을 유지하면 각 스킨의 기존 색상을 사용한다.
- 다이닝 커버 배경색/불투명도는 커버 설정에서 지원한다. 기본 불투명도는 75이며 기존 A/B 기본색은 각각 #0D172A/#401E24다.
- 다이닝 일반 페이지와 좌측 내비게이션 배경은 렌더러 테마 변수로 존재하지만 독립 고객 설정은 아직 연결하지 않았다.
- 커버의 가게설명에는 독립 색상 설정이 없다. 로고 등록 기능은 기존 다이닝에도 있지만 현재는 커버 제목과 함께 표시한다. 기본 디자인의 로고 대체는 이번 미리보기 범위에만 적용한다.

## 후속 구현 범위

1. 베이직: 페이지 배경색 / 선택적 대표영역 배경색. 별도 대표 배경이 없거나 페이지와 같으면 기존 배치다. 별도 색이면 패널 내부 여백과 패널 끝 기준 외부 공통 여백을 분리하며, 실제 패널 폭을 이름 가독성 기반 열 계산에 포함한다. 1열은 오른쪽, 중앙열은 양쪽 경계를 적용한다.
2. 다이닝: 커버페이지 배경색 / 일반 페이지 공통 배경색 / 좌측 카테고리 내비게이션 배경색을 독립 설정한다. 사용자가 말한 ‘메뉴열’은 좌측 내비게이션 열이다. 전면페이지형에서는 좌측 열 설정을 숨긴다. 모바일에서 내비게이션이 상단 탭으로 변할 때의 색상 연결도 명시하고 기존 간격은 유지한다.
3. 다이닝 가게설명: 커버 가게명 아래 설명색을 메뉴 본문의 설명색과 별도로 조절한다. 가게명/일반·코스 카테고리/페이지 제목/나머지 글자의 역할별 색상과 혼동하지 않도록 그룹을 구분한다.
4. `DONE` 공통 나머지 글자 색상 UI·저장·렌더러. 커버 설명의 독립 색상은 3번 후속이다. 커버 이미지 위 오버레이 색/불투명도는 기존 설정을 재사용한다. 로고와 커버 이미지 ON/OFF는 별개다.
5. 기존 저장 메뉴판은 새 설정을 명시하지 않으면 기존 템플릿 팔레트를 유지한다. 저장·초기화·미리보기·디자인 교체 보존을 함께 검증한다. 색상을 추가한다고 고객 데이터나 기본 팔레트를 일괄 재작성하지 않는다.

## 이번 미리보기의 범위

기본 6종의 로고는 기본 OFF, 가게명 대체, 원본 비율 보존, 모바일 중앙 정렬이다. 기본 다이닝 커버 이미지도 기본 OFF/흰 배경이며 ON이면 검정색 75% 오버레이와 밝은 커버 글자를 사용한다. 기존 디자이너/고객 메뉴판의 로고 병기와 커버 팔레트는 바꾸지 않는다.
