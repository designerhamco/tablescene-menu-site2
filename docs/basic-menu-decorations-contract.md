# 베이직 공통 장식 기능 — 2026-11-25 승인

기존 템플릿의 기본 모습과 저장된 디자인을 유지하면서 장식을 개별 설정한다. 장식 설정 자체는 요금·구독을 변경하지 않는다. 템플릿 접근 정책은 별도의 [서비스·요금 기준](service-pricing-contract.md)을 따른다. 다이닝·디스플레이·비활성 다중 페이지 엔진은 장식 공통화 대상이 아니다.

## 설정과 기본값

보기 옵션의 **장식 기능** 탭은 상·하단 패턴 띠와 다섯 종류의 선을 소유한다. 일반 템플릿 미리보기는 기능 옵션/디자인 옵션/장식 기능, 베이직 편집용 미리보기는 디자인 옵션/장식 기능을 제공한다. 기기·레이아웃·호출·주문 컨트롤은 기존 위치와 권한을 유지한다.

상단 **장식 선택**에서 기능 옵션과 같은 체크박스로 사용 여부를 고른다. 체크 상태는 저장된 명시적 설정과 템플릿 기본값을 그대로 읽으며, 처음 열었다는 이유로 기본값을 저장하지 않는다. 선택한 선의 두께·스타일·색상 설정만 아래에 보여준다. 체크를 해제해도 지정했던 디자인 값은 지우지 않아 다시 체크하면 복원한다. 템플릿 기본 상태로 돌아갈 때는 기존 장식 초기화/편집 되돌리기를 사용한다.

두께·스타일은 실제 적용 중인 값을 바로 선택 표시하며 **템플릿 기본** 항목은 두지 않는다. 편집 가능한 값은 **1·2·3 CSS px**와 **실선·파선·점선**이다. 템플릿 고유 두께가 1.6px처럼 선택지 밖이면 현재 수치를 읽기 전용 항목으로 보여주고 임의 반올림하지 않는다. 미리보기의 실제 border/구분선/점 표현을 읽기만 하며 처음 열거나 기기를 변경해도 저장값을 생성하지 않는다. 값이 없으면 원래 CSS의 가변 두께·그라디언트 점 표현을 그대로 유지한다. 사용자가 선택한 속성만 명시적으로 저장하며 기존 장식 초기화/편집 되돌리기로 원래 표현을 복원한다. 색상은 디자인 옵션과 같은 컬러피커에서 직접 지정하고 기본색 복원 버튼으로 기존 연결색에 돌아간다. **기본색 유지/직접 지정**의 저장 의미는 그대로이며 별도의 색상 방식 선택 단계는 두지 않는다. 직접 지정한 색은 해당 선에만 적용한다.

ONUE(`restaurant_onue_a`)와 기본 좌상단(`basic-upper-left`)은 패턴 띠를 지원하지 않는다. 기존 체크무늬가 있거나 업로드된 패턴 이미지가 있을 때만 띠를 켤 수 있다. 기존 패턴 이미지 업로드, 소유 경로 검증, 띠 두께 옵션(8–32px)을 유지한다. 선 두께 1·2·3px는 패턴 띠 두께가 아니다.

대표 영역과 메뉴 열의 경계에는 새 열 구분선을 만들지 않는다. 중앙 대표 영역 양쪽의 메뉴 열은 이웃한 열이 아니므로 중앙 영역을 가로지르는 구분선도 만들지 않는다. 실제 메뉴 열 사이 선의 양쪽에 각각 페이지 안쪽 여백을 확보하며 전체 간격은 `2 × 페이지 inset + 선 두께`이다. `getMenuColumnDividerGeometry`가 실제 레이아웃과 숨은 측정 후보에 같은 폭을 제공한다.

상품 구분선은 마지막 상품, 열 끝, 카테고리·위젯·안내 경계에 표시하지 않는다. 카테고리 사이 선도 새 열의 첫 카테고리나 위젯 다음에는 표시하지 않는다. 신규 상품·카테고리 구분선은 기존 간격 안에 그려 문구/사진을 누르거나 간격을 더하지 않는다. 글자 크기, 모바일 읽기 간격, 등록된 대표 이미지 비율은 변경하지 않는다.

## 저장과 호환

`page_settings.design.decorations`는 선택적으로 저장한다. 스키마 변경이나 고객 데이터 일괄 갱신은 없다. 설정이 없는 기존 메뉴판에는 새 기본선을 만들지 않으며 기존 CSS의 두께·스타일·불투명도를 유지한다. 명시적 사용/사용 안 함 또는 스타일 변경만 새 동작을 요청한다.

`lib/menu-decorations.ts`가 입력과 적용 범위를 관리한다. 미리보기의 `PreviewDesign.decorations`는 전체 설정 스냅샷이다. 키 자체가 없으면 저장된 장식을 유지하고, 명시적인 빈 객체는 장식 설정을 템플릿 기본으로 되돌린다. 알 수 없는 키, 허용하지 않은 두께/스타일, 안전하지 않은 색상은 정규화에서 제거한다.

**디자인 반영 → 편집 페이지 최종 저장** 경로를 유지한다. 디자인 옵션 초기화와 장식 초기화는 서로의 설정을 지우지 않는다. 편집용 장식 편집 되돌리기는 해당 편집 초안만 제거해 저장된 장식을 다시 표시한다. 기존 패턴 띠 편집 스위치와 미리보기 표시 설정을 함께 반영하며 이미지/두께 편집이 새 표시 초안을 덮어쓰지 않는다.

템플릿 교체의 기존 디자인별 스냅샷은 전체 design 객체와 장식을 함께 복원한다. 상품·카테고리·주소·주문 설정을 교체하지 않는다. 앨범형에서는 제외된 세 종류의 설정을 렌더링하지 않는다. 템플릿 샘플로 되돌리기는 장식을 포함한 표현 설정을 제거하며 고객 콘텐츠를 유지한다.

## 검증

`lib/menu-decorations.test.ts`는 입력 검증, 기본값 무변경, 앨범형·모바일 제외, 미리보기/최종 저장 일치, 디자인별 스냅샷과 초기화를 검증한다. `scripts/qa-menu-decorations.mjs`는 실제 기기 viewport, 선 두께/스타일/색상, 자동 색 연결, 동일 열의 경계, 패턴 예외, 탭과 초기화를 검증한다. `DECORATIONS_QA_BASELINE`을 지정하면 이전 버전과 장식 미설정 화면의 좌표·글꼴·색상·기본선을 직접 비교한다. 검수 과정에서 고객 데이터 쓰기를 수행하지 않는다.

2026-11-25 검수에서는 기본 7종과 기본 디자인 7종을 PC 1440×900, 태블릿 1180×820/820×1180, 모바일 390×844에서 비교했다. 장식 미설정 상태의 좌표·서체·색상·기본선은 기준 버전 `f3b83454`와 일치했다. 선 9개 조합, 긴 메뉴명의 연결선, 기본 장식 끄기, 직접 지정/자동 색 복귀, 디자인/장식 탭 이동과 초기화, 앨범형 제외, 패턴 예외를 확인했다. 다중 페이지·다이닝·디스플레이의 장식 범위 제외, 저장된 패턴 ON에 대한 기존 미리보기 OFF 우선순위도 회귀 테스트에 포함한다. 빌드와 타입·린트·공통 UI 검사를 함께 실행한다.

같은 날 체크박스 구성 변경은 단위·회귀 1,408건, 타입·린트·운영 빌드로 검증했다. 기존 7종의 원래 체크 상태와 초안 미생성, 해제/재선택 시 디자인 값 유지, 컬러피커/기본색 복원, 초기화를 확인했다. 모바일 390×844와 태블릿 820×1180/1180×820에서는 앨범형의 세 가지 제외와 선택한 설정만 표시되는 구성을 확인했다. 렌더러·저장 데이터 형식·요금·교체 권한은 수정하지 않았다.


## 2026-11-25 미리보기 색상·점선 보정

새로 켠 메뉴명–가격 연결선은 기존 컬러피커의 기본 연결 대상인 메뉴 설명색을 실제 선에도 적용한다. 현재 설명색·저장된 supporting 역할색·템플릿 기본 설명색 순서를 따르며, 직접 지정한 연결선 색이 우선한다. 기존 ROSY 원래 연결선의 고유 색과 불투명도는 유지한다. 컬러피커의 기본색도 렌더링된 연결선에서 직접 지정값만 제외하고 읽어, 원래 색과 지정색·초기화 대상이 다르게 추정되지 않도록 한다. 읽기 과정은 저장 데이터나 맞춤 값을 만들지 않는다.

편집한 점선은 점 지름을 선택 두께와 같게, 점 사이 빈 간격을 두께의 2배로 표시한다(반복 주기 3배). 1/2/3px는 각각 지름 1/2/3px, 빈 간격 2/4/6px다. 투명한 기존 border 영역 안에 원형 패턴을 칠하므로 선 두께·열 양쪽 여백·제목과 아이템 간격은 바뀌지 않는다. 가로선과 세로선에 동일 기준을 적용하고 실선·파선 및 편집하지 않은 native 장식은 유지한다.

패턴 띠 미지원 안내는 온유를 포함해 “기본 좌상단 디자인은 패턴 띠를 지원하지 않습니다.”로 표시한다. 지원 여부·기기·앨범 적용 범위는 기존 그대로다.

보정 검수: 전체 테스트 1,457건, 공통 UI 검사 175건, 타입·린트·운영 빌드 통과. `scripts/qa-decoration-leader-colors.mjs`는 PC 1440×900/태블릿 1180×820/모바일 390×844의 기본·디자인 템플릿에서 설명색과 연결선색, 별도 메뉴 기본정보색, 직접색/복원, 설명 숨김, 점선 가로·세로 주기와 1/2/3px 두께, native ROSY 색·불투명도를 26건 검증한다. 두 좌상단 템플릿의 안내 문구도 확인한다. 기존 장식 탭·초기화와 선 9개 조합·긴 메뉴명·OFF 회귀 검증을 함께 통과했으며 고객 쓰기는 0건이다.

최신 기준 브랜치에 병합된 알림톡/테이블 작업공간의 신규 import로 기존 격리 테스트 두 곳의 대역이 빠져 있던 항목을 보완했다. 통합 주문 폼과 기기 설정 리다이렉트 검증의 원래 단언은 유지하며, 리다이렉트 전에 채널 조회·쓰기가 호출되면 실패하도록 한다. 운영 알림톡·주문·권한 로직은 변경하지 않았다.
