# ArtiMenu PG 사이트 심사 준비

최종 갱신: 2026-08-24

이 문서는 PortOne·KG이니시스 계약 심사 전에 공개 사이트가 갖춰야 할 항목을 정리한다. 플랫폼 이용료 결제와 음식점 QR오더 결제·지급대행은 별도 도메인으로 유지하며, 계약 전에는 실제 QR오더 PG 호출이나 음식점 지급 기능을 활성화하지 않는다.

## 심사 안내 이미지 기준

1. `DONE` 실제 판매 가능한 상품 3개 공개
   - 아티메뉴 베이직 개인 1개월 체험 6,600원
   - 아티메뉴 베이직 사업자 월결제 9,900원
   - 아티메뉴 베이직 사업자 연결제 95,000원
2. `DONE` 0원·임의가격·품절 상품을 판매 상품 목록에서 제외
3. `DONE` 상품별 공개 상세 페이지에 이용기간, 제공 시점, 실물 배송 없음, 교환·청약철회·환불 기준 표시
4. `DONE` 모든 공개 페이지 Footer에 사업자등록 정보와 통신판매업 신고정보, 연락처, 주소, 대표자 표시
5. `NEEDS_HUMAN` 회원 전용 구매 흐름을 심사자가 확인할 수 있는 검토용 계정 준비

## 사이트에서 완료한 항목

- 사용자 표시 브랜드를 `아티메뉴`와 `ArtiMenu`로 통일한다.
- 과거 공개 URL과 세션·저장 데이터 호환을 위해 내부 route, cookie, localStorage, DB 식별자는 즉시 이름을 바꾸지 않는다.
- `/pricing`에서 현재 판매 가능한 Basic 3상품을 분리해 표시한다.
- `/products/basic-trial`, `/products/basic-monthly`, `/products/basic-yearly`에서 상품별 상세와 신청 동선을 제공한다.
- QR오더 소개는 준비 중 상태와 실제 미제공 범위를 명시한다. PG 계약·지급대행 심사 전에는 실결제·정산 제공을 광고하지 않는다.
- 이용약관과 개인정보 처리방침, 고객지원 연락처를 Footer에서 상시 확인할 수 있다.

## 심사 신청 전에 사람이 확정할 항목

- 정식 서비스 오픈일과 약관·개인정보 처리방침 시행일
- 오픈 할인 시작일·종료일
- Production 공개 도메인과 페이지별 최종 육안 확인
- 검토용 계정 ID/PW, 로그인 후 구매 화면 접근 가능 여부
- 회원가입·이메일 인증·비밀번호 재설정 메일의 실제 수신
- 사업자등록증의 상호·대표자·사업자번호·주소와 Footer 표시의 최종 일치 확인
- 실제 사용하는 결제사·인증·호스팅·메일·AI 업체와 국외 이전 국가·보유기간을 기준으로 개인정보 처리방침 확정
- PortOne 경로의 KG이니시스 전자결제 계약과 KG이니시스 신버전 AML 지급대행 특약 심사

## 계약 전 구현하지 않는 항목

- 음식점 QR오더 실제 선결제, 취소, 환불, 웹훅
- 음식점 서브몰 등록, KYC·AML 자료 수집, 지급 요청과 대사
- 음식점 API Secret 입력·보관
- 지급 주기, 차지백, 수수료, 지급 보류·환수 정책의 임의 확정
- 기존 아티메뉴 플랫폼 이용료 결제·구독·환불·entitlement 구조와 QR오더 결제의 통합

## 권장 제출 순서

1. 공개 사이트와 Basic 3상품, Footer, 약관을 Production에서 최종 확인한다.
2. 검토용 계정으로 회원가입·로그인·신청 화면까지 확인한다. 실제 결제는 실행하지 않는다.
3. 오픈일과 정책 시행일을 확정해 사이트에 반영한다.
4. PortOne 경로로 KG이니시스 신규 PG 계약 심사를 접수한다.
5. 전자결제 계약 승인 후 KG이니시스 신버전 AML 지급대행 특약을 별도로 신청한다.
6. 계약서와 기술 담당자 답변에 맞춰 QR오더 결제·지급 도메인을 설계하고 테스트 환경부터 구현한다.
