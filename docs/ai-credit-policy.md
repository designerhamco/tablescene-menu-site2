# AI 크레딧 지급 정책

최종 갱신: 2026-08-28

## 웰컴 크레딧

- 계정의 첫 메뉴판 생성이 성공한 시점에 AI 크레딧 6개를 계정당 평생 1회 지급한다.
- 회원가입만으로는 지급하지 않는다.
- 다이닝·디스플레이·체험·유료 요금제 종류와 관계없이 동일하다.
- 추가 메뉴판, 신규 구독, 재구독, 정기 결제 갱신에는 추가 지급하지 않는다.
- 보유 크레딧은 계정의 모든 메뉴판에서 공유한다.
- 구독 해지·메뉴판 보관만으로 보유 크레딧을 회수하지 않는다.

## 기존 계정

- 기존 잔액과 거래 내역은 수정·회수·재계산하지 않는다.
- 기존 `grant` 또는 `included_grant` 내역이 한 건이라도 있는 계정은 이미 최초 혜택을 받은 것으로 간주하여 6개를 추가 지급하지 않는다.
- 구매한 AI 크레딧과 사용 차감 규칙은 변경하지 않는다.

## 기술 경계

- `grant_ai_first_menu_welcome_credits` RPC가 메뉴판 소유권과 계정의 최초 메뉴판인지를 재검증한다.
- 계정 단위 advisory transaction lock과 부분 unique index로 동시 요청의 중복 지급을 막는다.
- RPC는 `service_role`에만 열고 `anon`, `authenticated`, `public`에서는 실행할 수 없다.
- 메뉴판 생성·스타터 데이터·이용 권한 기록이 완료된 후 서버에서만 RPC를 호출한다.

## 배포 순서

1. migration을 Production에 1회 적용한다.
2. 함수·index·권한 postcheck를 실행한다.
3. 애플리케이션 PR을 병합해 Vercel에 배포한다.
4. 신규 QA 계정의 첫 메뉴판에서 6개 1회 지급과 추가 메뉴판·재구독 미지급을 확인한다.

Production migration 적용과 실제 메뉴판 생성 QA는 사람 승인 후에만 실행한다.
