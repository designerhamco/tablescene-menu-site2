# 위젯 순서·안내사항·열 분리선 검수 — 2026-11-10

## 현재 승인 정책

같은 날 먼저 배포한 bottom 위젯 도킹/이동 잠금 정책은 이후 사용자 요청으로 폐기했다. 모든 지원 Basic/Dining 위젯은 전체 카테고리 앞·사이·뒤로 자유롭게 이동한다. 기존 bottom JSON은 입력 호환만 유지하고 원래 순서의 flow로 읽는다. 새 스타터와 기존 권한 검사 뒤의 저장은 flow로 정규화한다. 배치 선택과 이동 잠금, 도킹 재배치·측정·auto 간격 코드는 제거했다.

Basic 안내사항은 마지막 실제 콘텐츠 뒤에 놓으며 별도 바닥 맞춤 공간을 만들지 않는다. 일반 상단행 고정형은 상단 오른쪽 안내를 유지하고, 로고 왼쪽형(MELLOW)은 콘텐츠 뒤에 둔다. 중앙열형도 대표열 안내를 콘텐츠 뒤로 옮긴다. 모바일도 같은 구조별 위치를 사용하면서 독립 읽기 크기/간격을 유지한다.

Dining 위젯은 페이지 안의 전체 카테고리 사이에서만 이동한다. 코스 제목·설명·가격·전체 아이템은 하나의 원자적 영역이다. 안내사항은 커버 하단 내부 여백 위의 한 가로 행이며, 실제 문구 수에 따라 1/2/3개 균등 열이다. 빈 문구는 생략하고 긴 문구는 해당 열 안에서 줄바꿈한다. 페이지 이동과 호출 UI가 안내를 가리지 않도록 실제 높이를 반영한다. 커버 재진입 시 ref의 실제 마운트에 맞춰 다시 관찰하고, 이탈 시 높이 보정을 해제한다. 커버 OFF에 새 페이지를 자동 생성하지 않는다.

`lib/menu-widget-placement.ts`는 편집/직렬화/기존 권한 저장 경로의 순서 정책을 공유한다. `lib/menu-notices.ts`는 명시적 빈 안내와 기존 필드의 fallback 의미를 공유한다. DB 스키마·권한·업로드·고객 데이터는 변경하지 않았다. 기존 구성 페이지 위/아래 이동 대상 오류 수정도 유지한다.

MELLOW 세로 분리선 양쪽 여백은 각각 페이지 내부 여백이다. 총 열 간격은 `2 × inset + 1px`이며 후보 측정과 실제 렌더링에 같은 계산을 사용한다. 이미지 비율, 색상, 서체, 모바일 읽기 크기와 대표영역의 승인된 기기별 비율은 유지한다.

## 브라우저 검증

실제 렌더러와 구성 UI를 사용하는 개발 전용 `/__qa/widget-placement`에서 검사했다. Production에서는 404이며 고객 메뉴를 읽거나 쓰지 않는다. 최종 저장 서버 액션은 실행하지 않았다.

- `scripts/qa-widget-placement.mjs`: **170개 고유 조건 통과**. 첫 전체 검사 중 구형 header selector와 모바일 호출 겹침을 발견한 조건은 수정 후 해당 전체 분류를 다시 검사했다.
- 활성 Basic 7종 × PC 1440×900 / 태블릿 1180×820 / 모바일 390×844. PC에서 맨 위/맨 아래 위젯, 위젯 2개, 안내 없음, 숨김/위젯 없음, 긴 콘텐츠와 채움형 검사.
- 모든 중립 Basic 리스트 5종/앨범 2종의 태블릿·모바일: 일반 상단 안내 유지, 왼쪽 로고형 하단 흐름, 중앙형 안내 이관, 위젯 원래 순서 확인.
- Dining A/B의 일반·가격 코스 카테고리에서 세 기기별 혼합 순서와 코스 내부 위젯 없음 확인. 중립 전면/사이드바 리스트·앨범, 커버 이미지 OFF, 긴 안내도 검사.
- Dining A/B × 세 기기 × 안내 0/1/2/3개, 호출 ON에서 커버 바닥 간격/균등 열/줄바꿈/페이지 이동 접근/커버 재진입을 검사. 호출 버튼과 안내사항의 실제 경계를 확인.
- 추가 Basic 전종 PC·태블릿 호출 ON과 320/430px 모바일 호출 ON, Dining 이미지 OFF·긴 안내·호출 ON 검사. 실제 viewport, 수평 넘침, 위젯 중복, 스크롤 끝 접근, 자연 안내 간격과 세로선 양쪽 여백을 비교.
- `scripts/qa-widget-editor.mjs`: **구성 UI 4종 통과**. 기존 bottom 샘플도 드래그 핸들 활성, 위/아래 버튼과 실제 마우스 드래그로 첫/중간/끝 이동, 로컬 편집 반영 후 숨김 최종 JSON의 순서와 flow 값 일치를 확인.
- 브라우저 예외 **0**, 고객 데이터 쓰기 요청 **0**. QA 중 GET/HEAD/OPTIONS 외 요청을 차단했다.

실행 환경은 사용자가 보는 로컬 작업 체크아웃의 3027 서버이며, 실제 CSS viewport로 검사했다. MELLOW 실제 화면 보기의 반응형 동작은 사용자가 정상임을 확인하여 변경하지 않았다. 단위/사이트 공통 검사, 타입/린트 및 최종 배포 증거는 PR 검증 기록에 기록한다.
