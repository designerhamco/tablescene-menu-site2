# 아티메뉴 디스플레이 메뉴판·미리보기 계약

기준일: 2026-11-19. 현행 코드 동작과 이번 미리보기 변경 범위다. 문서의 존재는 신규 신청 활성화나 운영 데이터 변경 완료를 뜻하지 않는다.

## 사용자 승인 수동 미리보기·직접 안내 — 2026-11-19 최신

- 카탈로그와 실제 화면 보기는 자동 페이지 순환을 하지 않는다. 하단 포인터 접근/터치/키보드 포커스 시 이전·현재/전체·다음과 언어 메뉴를 표시한다. 첫/끝 페이지의 바깥 방향은 비활성화하며, 상단 수동 탐색 및 현재 페이지/언어 URL을 동기화한다. 공개 송출의 기존 8초 자동 순환은 이번 요청 범위와 별도다.
- 최초 안내는 검은 반투명 전체 화면, 하단 가까운 흰 문구, 아래를 가리키는 위아래 모션, 하단 중앙 닫기 버튼이다. 모션 감소 설정에서는 화살표를 정지한다. Escape 및 닫기 모두 안내를 닫고 기존 메뉴 상태를 보존한다.
- 카탈로그 첫 진입에는 즉시 안내를 표시한다. 실제 화면 보기에서는 기존 확대/전체화면 안내 팝업을 닫은 직후 직접 안내를 표시한다. 원래 팝업이 자동 노출되지 않는 환경은 직접 안내를 바로 표시한다. 옵션 변경 시 반복 노출하지 않으며 새 페이지 진입/reload 및 도움말 재열기는 가능하다.
- 아래 초기 구현 검증 이력의 실제 화면 8초 순환과 세션 숨김 안내는 이 최신 승인으로 대체한다. Basic/Dining 안내·공개 고객 데이터는 변경하지 않는다.

## 아티메뉴 공통 뷰어 제어 스타일 — 2026-11-19

하단 페이지 탐색과 언어 메뉴는 고객 템플릿 아트워크와 독립된 ArtiMenu 공통 뷰어 UI다. `MenuViewerPagination` / `MenuViewerControls.module.css`와 언어 선택기의 `viewer` 변형을 사용한다. 흰 플로팅 표면·중립 경계/그림자·검정 카운터·공식 사이트 서체 및 공유 SiteArrow를 사용하며 메뉴 저장 서체와 썸머 블루 팔레트를 상속하지 않는다. 언어 트리거와 펼친 언어 목록도 같은 표면/포커스/선택 상태를 사용한다. 기존 하단 위치·포인터/터치/키보드 표시·수동 이동·언어/URL 동기화는 유지한다. 다른 템플릿의 기존 언어 변형과 메뉴 아트워크는 변경하지 않는다.

로컬 브라우저에서 1280×720의 하단 흰 언어 박스·공유 화살표·펼친 메뉴·50px 높이 일치를 확인했다. 320px 실제 화면에서는 페이지 박스 x=16/폭166px, 언어 박스 x=199.8/폭100.2px로 겹침과 가로 넘침이 없었다. 언어를 English로 바꾼 뒤에도 2페이지를 유지했다. 뷰어 글꼴은 실제 computed 값으로 Tenor Sans/Pretendard 공통 스택을 확인했다. 상단 툴바는 후속 사용자 승인에 따라 불투명한 밝은 회색 실행 버튼·검정 문구·은은한 경계와 무배경 도움말/접기 아이콘을 사용한다. 이전 흰색14% 면/30% 경계 시안은 [현재 버튼 계약](site-control-contract.md)으로 대체한다.

## 현재 페이지 엔진

- 현재 등록 디자인은 `display_menu_a`(SUMMER BLUE / 썸머 블루)다. `DisplayMenuA.tsx`는 Basic contained-reading 및 Dining 페이지 엔진과 분리한다.
- 표시 가능한 등록 페이지를 순서대로 사용한다. 메뉴 페이지에는 전체 메뉴형 또는 이미지+메뉴 분할형, 프로모션 페이지에는 전체 이미지 또는 영상을 사용한다. 스타터는 이미지 프로모션/분할 메뉴/전체 메뉴/영상 프로모션 4페이지다.
- 전체 메뉴는 기본 2열이며 한 카테고리·8상품 이하는 1열이다. 카테고리를 쪼개지 않고 행 예산으로 양쪽을 배분한다. 열 내부 순서는 유지하지만 전체 읽기 순서가 원본의 연속 분할과 항상 같다는 보장은 없다.
- 분할형은 이미지와 메뉴 50:50, 이미지 좌우 선택, 메뉴 1열이다. 프로모션 미디어는 화면을 채운다. 영상은 기존 자동 재생/음소거/반복 규칙을 유지한다.
- 넘치는 콘텐츠가 자동으로 새 페이지를 만들지는 않는다. 실제 영역 측정과 `--display-row` 기반 글자/여백 보정을 사용하며, 밀집 보정 단계에서 보조명/일반·판매 상태 배지의 표시가 생략될 수 있다. 옵션 ON이 모든 밀집도에서의 표시를 보장하지 않는다.
- 공개 화면은 여러 페이지일 때 8초마다 순환한다. 공개 화면의 언어 제어는 하단 포인터 접근/터치 또는 키보드 포커스 시 나타난다. 공개 화면에 수동 페이지 선택을 새로 추가하지 않는다.
- 묶음형/채움형 사용자 선택은 지원하지 않는다. 과밀 콘텐츠의 페이지 분할·가독성 기준은 후속 설계이며 이번 변경으로 자동 분할이나 배치 모드를 추가하지 않는다.

## 카탈로그 미리보기

[보기 옵션 계약](template-preview-display-options.md)의 디스플레이 전용 절을 따른다. 상단 수동 페이지 탐색과 왼쪽 옵션은 공통 shell을 재사용하며 내부 디스플레이의 별도 행 예산/페이지 타입/가격/미디어 로직을 교체하지 않는다.

페이지 명령과 상태는 동일 origin의 부모/해당 iframe 사이에서만 교환한다. public 모드에서는 명령을 받지 않는다. 미리보기 iframe과 새 창의 하단 수동 제어는 포인터 접근/터치/키보드 포커스 때 나타나며 상단 상태와 동기화한다. 언어 변경은 현재 페이지와 옵션을 유지하며 외부 상단 링크에도 반영한다.

디스플레이 언어 선택은 문서 reload 없이 클라이언트 경로 갱신으로 번역된 데이터를 반영한다. 수동으로 이동한 현재 페이지와 임시 보기 옵션, 열린 옵션 탭/패널·도구막대, 닫은 안내 상태를 유지한다. 렌더러 인스턴스를 페이지 쿼리로 재생성하지 않고 언어별 메뉴 크기는 다시 측정한다. 언어 목록은 선택 직후 닫고 트리거로 포커스를 돌린다. 수정키 클릭/새 탭 열기는 실제 링크의 기본 동작을 유지한다. 새 진입이나 명시적 reload의 최초 안내 정책은 그대로다. Basic/Dining의 언어 선택에는 적용하지 않는다.

언어 전환 검증: 로컬 최적화 빌드의 1280×720 카탈로그에서 1→3페이지 이동 후 한국어→영어→일본어 전환, 가격 옵션 OFF/L 크기/이미지 오른쪽/디자인 탭 유지, 접은 패널·도구막대 유지, iframe src 불변과 외부 페이지·언어 링크 동기화, 열린 안내 0개를 확인했다. 실제 화면 보기에서도 1→3 이동 후 영어 전환, 820×1180 중국어 및 320×740 한국어 전환에서 3페이지·옵션 유지/가로 넘침 0/안내 재노출 없음을 확인했다. 번역 후 fit settled 및 명시적 reload의 최초 안내 재노출도 확인했다. 전체 단위검사 1,355개, 사이트 UI 계약 168개, TypeScript/변경 파일 ESLint/최적화 빌드를 통과했다.

새 창 실제 화면 보기는 자동 순환 없이 하단 이전·현재/전체·다음 버튼으로 수동 이동한다. public 모드로 전환하거나 고객 설정/DB에 쓰지 않는다. 매장 공개 송출의 자동 순환 조건은 유지한다.
