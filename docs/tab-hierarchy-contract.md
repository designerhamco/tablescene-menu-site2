# 사이트 탭 위계 계약

## 한 화면의 순서

탭은 위에서 아래로 범위가 좁아진다. 실제 화면에 필요하지 않은 단계는 생략할 수 있지만, 아래 단계가 위 단계보다 더 크거나 강하게 보이면 안 된다.

| 위계 | 의미 | 공통 API | 기본 표현 | 대표 사용처 |
| --- | --- | --- | --- | --- |
| 1 · 최상위 | 페이지·주요 화면 전환 | `Tabs hierarchy="primary"`, `NavigationTabs purpose="page"` | 사각 연결형 · 검정 선택면 | 베이직/다이닝/디스플레이, 편집 설정 화면 |
| 2 · 주요 분류 | 페이지 안의 콘텐츠·가이드 묶음 | `Tabs hierarchy="secondary"` | 4px 밑줄 | 가이드, 디자인 시스템 콘텐츠 분류 |
| 3 · 보조 분류 | 현재 목록의 조건 또는 본문 위치 이동 | `site-filter`, 본문 링크 | 작은 필터·링크 | 업종, FAQ 주제, 가이드 바로가기 |
| 4 · 영역 내부 | 하나의 설정·도구·목록 영역 안의 상세 내용 전환 | `Tabs hierarchy="embedded"` | 흰 콘텐츠 면에 붙는 상단 탭 | 템플릿 종류, 미리보기 기능/디자인, 번역 항목 |

파일형·산 모양 윤곽을 사용하던 `contained` 예외는 폐기한다. 목록 종류를 바꾸더라도 하나의 목록 영역 안에서 내용이 전환되면 4단계 `hierarchy="embedded"`의 `area` 표현을 사용한다.

## 페이지 전환과 상태값 변경

- **페이지·주요 화면 전환**: `Tabs hierarchy="primary"`는 `page` 변형이다. 8px 외곽 모서리의 사각 연결형으로 표시하고 선택 면은 검정·흰 글자, 비선택 면은 흰색·진한 글자다. 서비스별 전체 화면, 편집 설정 화면 전환에 사용한다. URL 이동은 같은 표현의 `NavigationTabs purpose="page"`를 사용하며 링크 의미를 유지한다.
- **상태값 변경**: `Tabs hierarchy="state"`는 기존 `outline` 둥근 세그먼트다. 옅은 회색 레일, 흰 선택 면과 검정 선택 테두리를 사용한다. 이용 중/보관 중/종료됨, 이미지/목록 보기, 선택 언어에 사용한다. 상태를 URL에 보존하는 링크는 `NavigationTabs purpose="state"`다.
- URL이 바뀐다는 이유만으로 페이지 전환으로 분류하지 않는다. 동일 목록의 상태·표현 값만 바뀌면 상태값 변경이다. 밑줄형은 문서·가이드의 콘텐츠 구획, 알림 등 기존 독립 레이어의 콘텐츠 분류에 사용한다.

## 선택 절차

1. URL만 이동하거나 본문 위치만 바꾸면 탭이 아니라 링크를 사용한다.
2. 업종·주제 같은 보조 조건은 `site-filter`, 이용 상태·보기 방식·선택 언어 같은 현재 화면의 상태값은 `state`를 사용한다.
3. 실제 탭 패널을 바꾸면 영향 범위를 확인해 primary, state, secondary, embedded 중 하나를 고른다.
4. embedded는 항상 area다. 선택 탭을 흰 콘텐츠 면의 상단 경계에 연결하되 사선·산 모양 윤곽을 만들지 않는다.
5. 한 화면에서 같은 위계의 서로 다른 모양을 섞지 않는다. 중첩 탭은 반드시 한 단계 낮춘다.

## 크기와 표면

- `lg` 48px/16px: 넓은 공개 페이지의 주요 전환.
- `md` 44px/15px: 마이페이지·편집기의 일반 분류.
- `sm` 40px/14px: 영역 안의 상세 전환과 밀도 높은 도구.
- 모양은 위계로 먼저 정하고, 크기는 화면 밀도로 정한다. 모양을 바꾸기 위해 크기를 바꾸지 않는다.
- PC·태블릿(768px 이상)의 사각 페이지 탭은 내용 폭과 좌우 각각 24px 여백으로 표시하며 가로 전체로 늘리지 않는다. 모바일은 기존 가로 폭·영역 내 스크롤을 유지한다.
- 영역형 콘텐츠는 흰 면을 사용한다. 선택 탭만 흰 면과 연결하고 비선택 탭은 옅은 회색 무테 면으로 구분한다.
- 상단 탭 경계에는 곧은 1px 기준선을 사용하며 사선·산 모양 mask·그림자를 사용하지 않는다.
- 영역 탭의 옆면은 수직으로 유지한다. 위쪽 두 모서리만 공통 8px 라운드 토큰을 사용하고 아래 모서리는 0이다. pill 토큰을 사용하지 않으며, 일반 탭은 최소 144px 너비로 나란히 붙인다.
- 흰 콘텐츠 영역의 좌우·하단에는 테두리를 두지 않는다. 선택 탭의 윤곽선과 탭 아래 기준선만 유지한다.
- 선택, hover, pressed, focus, disabled는 공통 Tabs 상태를 그대로 사용하며 페이지 CSS에서 다시 정의하지 않는다.

## 현재 적용

- 고객센터 공지사항/FAQ는 사용자 지정 구성에 따라 secondary 밑줄 탭을 사용한다. 그 아래 주제는 작은 필터를 유지하며 사각 페이지 탭으로 승격하지 않는다.
- 템플릿의 베이직/다이닝/디스플레이는 primary, 디자인/기본 템플릿은 embedded area다.
- 편집기 번역 언어는 state, 그 아래 번역 항목은 embedded area다.
- 미리보기 기능/디자인 옵션은 embedded area다.
- 마이페이지·운영·편집 화면 이동은 사각 `NavigationTabs purpose="page"`, 내 메뉴판 이용 상태는 둥근 `purpose="state"`다.
- 알림·요금 카드처럼 독립 레이어 안에서 가장 위에 놓이는 기존 밑줄 분류는 해당 레이어의 secondary로 유지한다.

고객 메뉴판의 `.menu-typography`, `.aube-table-root`, `[data-template-artwork]`와 메뉴 템플릿 렌더러는 이 계약의 적용 대상이 아니다.
