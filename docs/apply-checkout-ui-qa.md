# 모바일 카테고리 및 신청 화면 보정

2026-10-18 사용자 요청. 이전 드롭다운 정책의 모바일 부분은 이 기준으로 대체한다.

- `/apply` 업종은 767px 이하에서 56px 원/22px 아이콘/이름의 버튼 목록이다. 선택은 검정/흰색이며 목록 내부에서 가로로 이동한다. 768–1023px select와 1024px 이상 세로 목록은 유지한다. 세 표현은 같은 카테고리/선택 상태를 사용한다.
- 신청 화면의 읽기 순서를 기본 정보→유형→디자인→구매자로 맞추고 실제 DOM도 같은 순서다. 폼은 최대 1280px, 넓은 PC는 오른쪽 352px 주문 요약/약관과 48px 간격을 둔다. 좁은 화면은 한 열이다. 긴 사이드바 전체를 화면 위에 고정하지 않는다.
- 선택 카드는 `site-choice`로 공통 검정 CTA pill 규칙에서 제외하고, 전용 클래스의 16px 모서리/흰 바탕/검정 경계와 체크 표시를 사용한다. 신청 디자인은 판매 목록과 같은 실제 이미지 컴포넌트를 쓴다. 639px 이하는 가로형 소형 카드, 그 이상은 2열 이미지 카드다. 내부 template key와 반복 태그/노란 배지는 제거한다.
- 선택한 디자인 이미지는 주문 요약에도 연결한다. 연락처의 세 입력은 실제 좁은 폭 안에 들어가며 개별 접근성 이름이 있다. 약관 체크박스와 프로모션 입력에도 이름을 연결한다.
- 원페이지↔멀티페이지 전환 시 기존 업종만 남아 호환 디자인이 보이지 않던 문제를 수정했다. 기존 호환 디자인 선택 규칙으로 결정된 디자인의 업종을 표시 상태에도 적용한다. 가격 계산/결제/인증/API/고객 메뉴판 엔진은 수정하지 않았다.
