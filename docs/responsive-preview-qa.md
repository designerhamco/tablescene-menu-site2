## 화면 크기 기준

기준은 CSS viewport다. 공통 글자 역할은 1,600px까지 기존 크기, 1,920px에서 +4%, 2,560px에서 +12%, 2,600px 이상에서 최대 +12.5%다. 모든 역할이 같은 비율로 변한다. root rem과 고객 메뉴판의 기초 크기는 유지한다. 공통 바깥 간격만 상한을 갖고 확대하며 콘텐츠 최대 폭은 유지한다. 라이브러리와 폰트 계약도 같은 기준을 설명한다.

로그인은 좁은 단일 폼을 viewport 높이만큼 중앙 정렬하고 있었다. 배포 전 측정에서 1440×900, 3440×1440 모두 폼 폭416px·제목36px이었고 제목 top은207px→477px로 증가했다. 마이페이지는 여러 열의 자연 흐름과 폭 제한으로 공간을 채우며 제목 top136px였다. 로그인은 main 높이의 상한56rem과 폼 폭26–29.25rem을 적용했다. 최종 3440×1440에서는 제목40.5px, 설명18px, 폭468px, 제목 top228px, main 높이896px이다. 1440×900은 제목36px·폭416px·top207px로 유지된다.

## 공통 미리보기

두 목적 모두 기기 선택·태블릿 회전·새 창·도구 접기를 공유한다. 저장 메뉴판은 수정하기와 프레임 전체화면을 제거했다. 전체화면은 두 목적 모두 detached 실제 화면에서만 제공한다. 카탈로그 전용 기능·디자인·호출/주문·배치 체험은 왼쪽 옵션에 배치한다. 디자인 서체·색상 필드는 좁은 패널에서 한 열로 배치하고 셀렉트 화살표 공간을 확보한다.

목업의 바깥 표시 크기만 가용 공간에 맞추고 중앙에 배치한다. iframe 내부는 PC1440×900 / 태블릿1180×820 또는820×1180 / 모바일390×844를 유지한다. 960px 이상 카탈로그의 열린 패널은 왼쪽 공간을 확보하고 나머지 canvas의 중앙을 사용한다. 패널을 접어도 iframe 문서·스크롤은 유지된다. 실제 저장 데이터와 인증·권한·고객 메뉴 렌더러를 변경하지 않았다.
