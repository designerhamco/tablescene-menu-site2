# 직원 호출 선택·스크롤 미리보기 검수

기준일: 2026-10-20

## 범위

- 기존 `MAX_STAFF_CALL_ITEMS = 5`, 항목명 30자 제한을 유지한다. 관리자가 저장한 항목을 덮어쓰지 않는다.
- 기본/디자이너 템플릿의 대화형 미리보기에 서비스별 5개 예시를 제공한다.
  - 베이직: 물 요청, 식기 요청, 테이블 정리, 계산 요청, 직원 호출.
  - 다이닝: 주문 요청, 계산 요청, 와인 문의, 물 요청, 직원 호출.
- 미리보기는 복수 선택/전체 해제/한 번에 전송한 내용 확인을 제공한다. 선택이 없으면 전송할 수 없다. 실제 API 요청은 발생하지 않는다.
- 실제 수신 API/RPC는 기존 한 항목 전송 계약을 유지한다. 실제 모달은 단일 선택이며 설명 문구도 구분한다. 여러 RPC를 개별 호출하는 우회는 중복/재호출 제한 및 부분 성공 문제 때문에 사용하지 않는다.
- 실접수 복수 요청은 관리페이지 단계에서 하나의 호출에 선택 항목 스냅샷을 보관하고, 운영 수신/확인/완료/취소 및 중복 방지를 함께 연결해야 한다. 이번 변경은 DB/주문/결제/운영 데이터를 변경하지 않는다.

## 화면 규칙

- 요청 목록만 스크롤한다. 제목/닫기와 보내기/미리보기 안내는 목록 바깥에 둔다.
- 목록 끝에 내용이 남을 때만 흰색 하단 페이드를 표시하며, 끝에서는 숨긴다. 휠/터치/리사이즈/내용 높이 변화를 관찰한다.
- 짧은 가로 화면에서는 모달 여백을 줄여 최소 한 항목과 전송 버튼을 노출한다. 기존 Pretendard/CTA 500/8px 버튼/사방 테두리/단순 X를 유지한다.
- 다이닝의 아래로 닫기 제스처는 상단 핸들에서 시작할 때만 허용한다. 요청 목록의 터치 스크롤이 시트를 끌거나 닫지 않는다.
- 메뉴판의 PC/태블릿/모바일 본문 및 장바구니 동선은 변경하지 않는다.
