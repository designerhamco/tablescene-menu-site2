# 히어로 기기 테두리 복원 검수

이 문서는 이전 SVG 구현의 검수 이력이다. 현재 구현은 사용자 제공 PSD를 Photoshop에서 합성한 단일 이미지이며 `qa-hero-psd-composite.md`를 따른다.

2026-10-18. 기준 커밋 `6a73f4b`에서 기기 화면 관련 파일만 분리해 검수했다.

## 문제와 수정

이전 틈 보정은 화면 덮개를 베젤까지 확장했다. 특히 뒤쪽 모니터 화면에서 앞쪽 휴대폰을 제외하는 마스크가 휴대폰의 금속 테두리를 포함하지 않아 위·오른쪽 기기 외형을 가렸다.

- 태블릿/휴대폰 화면은 원본 3344×1882 사진의 밝은 화면 경계를 따라 추출한 픽셀 정렬 윤곽을 사용한다. 어두운 베젤을 덮지 않으며 원본 센서 모양도 별도 윤곽으로 보존한다.
- 모니터 덮개에서 제외하는 휴대폰 영역은 화면뿐 아니라 위쪽과 오른쪽 금속 테두리까지 포함한다.
- 원본 사진, 히어로 프레임, 자동 슬라이드 로직과 고객 메뉴판은 변경하지 않았다.

## 검증

- 실제 viewport 320/390/768/992/1440/2560px: 사진과 SVG의 정렬, 화면 색, 4장 직접 선택/로딩, 가로 넘침·브라우저 예외 없음.
- 원본 해상도에서 기존 밝은 틈 10곳의 화면 색을 검사한다. 추가로 휴대폰 금속 테두리 6곳과 태블릿 오른쪽 위·휴대폰 위/오른쪽 베젤 영역의 어두운 픽셀을 원본 사진과 비교한다. 총 2,767개 기기 픽셀의 채널별 차이가 2 이하이며 기존 경계 10곳도 통과했다.
- 390/1440px 및 원본 해상도 확대 캡처에서 태블릿 모서리와 휴대폰의 위/오른쪽 외형 복원을 확인했다.
- 자동 순환, 진행 인디케이터, 정지/복귀, hover, 키보드, 화면 밖/문서 비활성, 터치, 모션 감소 검수를 모두 통과했다.
- TypeScript, 변경 파일 ESLint, Production build, diff 공백 검사를 통과했다.
