# ArtiMenu 공식 사이트 디자인 시스템

2026-10-18 사용자 제공 컴포넌트 참고 문서를 기존 사이트 시스템에 재매핑했다. 원문/CSS 복사나 별도 Mobbin 스타일시트 없이 `--ui-*`와 기존 의미 클래스를 수정한다.
기존 서비스·계정·신청·운영 흐름은 유지하고, 사이트 UI의 시각 규칙을 통일한다.

- 흰 캔버스, 본문 `#15181e`, 보조 `#4b515b`, muted `#717680`, subtle `#f8f9fb`, border `#dbdee3`.
- ArtiMenu의 기존 대표 노랑은 `#f8e731`이다. 작은 eyebrow 점과 기존 추천 표시의 4px 점에만 매우 적게 사용한다. 버튼·선택 상태는 검정/회색이며, 성공·오류·주의·정보의 의미 색상은 별도로 유지한다.
- 주요 CTA·선택 탭은 검정 배경/흰 글자, 보조 CTA는 옅은 회색 배경/검정 글자의 무테 pill, 명시적인 `outline` 버튼은 흰 배경/옅은 경계로 구분한다. hover·active는 연회색 또는 짙은 회색으로 연결한다. 노랑은 아주 작은 장식 점에만 사용한다. Hero eyebrow와 체크리스트의 장식용 초록 표현은 제거한다.
- Pretendard, 히어로는 이미지·프레임 비율·라운드·배치·크롭을 유지하고, 타이포·색상만 공통 토큰을 적용한다. 히어로 제목 32/36/48px, 나머지 페이지 제목 32–48px, 섹션 20–24px, 카드 14–16px, 메뉴 14px. 의미 기반 `.type-*` 역할을 사용한다.
- **브랜드 인상: 밝고 단정하며 정보 구분이 명확한 UI.** 외곽 카드를 제거한 자리는 제목·구분선·옅은 배경으로 다시 구성한다. 필터는 옅은 회색 배경, 반복 내역은 상하 구분선과 정렬된 정보 열, 부가 안내는 옅은 배경과 왼쪽 선을 사용한다. 입력·선택·outline 컨트롤의 회색 1px 경계는 유지하며 보조 CTA의 옅은 표면과 구분한다. 로그인·가입·복구는 가운데 정렬된 좁은 폼이다. 입력창은 CTA pill과 어울리는 16px, 선택 컨트롤은 12px 라운드이며 disabled outline 버튼도 경계가 보인다. 소개 이미지 20–32px, 기존 히어로의 독립 32–48px/배치, 판매 목록 미리보기 16px·레이어 16px, 안내 6px, 토스트 8px는 유지한다. 기본 버튼 높이는 40px이며 CTA·탭은 pill이다. 기능 카드와 이미지를 가진 카드는 무테/16px/무그림자 표면을 명시적으로 사용한다. 그림자는 떠 있는 레이어와 글래스 헤더에만 사용한다.
- FAQ 상담 진입은 아이콘·제목/설명·이동 화살표가 있는 16px 라운드의 짧은 외곽선 버튼이다. 질문 목록은 외곽 카드 없이 상하/행 구분선으로 읽는다. 마이페이지는 PC에서 사이드 구분선과 세로 메뉴, 모바일·태블릿에서는 작은 계정 요약과 줄바꿈 가능한 가로 메뉴를 사용한다. 결제 내역의 정보 열은 모바일 2열/넓은 PC 4열이며, 375px 미만 필터는 날짜/선택 값이 잘리지 않도록 1열이다.
- 사용자 요청에 따라 문서의 1160px 컨테이너 대신 기존 히어로 **안쪽 최대 1520px** 기준을 공유한다. 바깥 컨테이너 1600px, 좌우 `clamp(20px, 3vw, 40px)`. `.site-container`와 `.site-gutter`는 동일한 좌우 경계를 만든다. 폼·법률 본문 같은 읽기 영역은 이 안에서 좁은 폭을 유지할 수 있다.
- 판매 갤러리: 1280px 이상 3열, 640–1279px 2열, 639px 이하 1열. 열 간격 24px, 행 간격 40px. 서비스 탭은 검정/흰색이고 키보드 좌우/Home/End 탐색을 지원한다. 홈의 기존 공유 그리드 기준은 유지한다.
- 홈·다이닝의 디자이너 템플릿 소개는 흰 배경의 디자인 화면 캐러셀을 사용한다. 베젤·검정 테두리·카메라 장식은 없으며, 이 쇼케이스만 사용자 지정 `clamp(12px, 1.5vw, 20px)` 라운드를 사용한다. 중앙은 가장 크고 선명하다. 인접 화면은 약 68% 크기·3px 블러·62% 불투명도, 더 먼 화면은 최소 48% 크기·약 6px 블러·24% 불투명도이며 거리별로 연속 변한다. 인접 화면의 중심은 중앙보다 6–12px 위, 더 먼 화면은 최대 24px 위에 놓는다. 3.2초마다 순환하고 마우스 hover나 화살표 클릭 후에도 재생한다. 키보드 포커스/드래그/화면 밖/비활성 탭 및 명시 일시 정지는 재생을 멈춘다. 모션 감소 설정은 기본 자동 재생을 끄되 재생 버튼으로 직접 시작할 수 있고, 이동은 애니메이션 없이 바꾼다. 화면 안은 추후 사용자 이미지로 교체할 임시 메뉴 시안이며 실제 메뉴판 디자인과 독립적이다. 흰 배경·검정 CTA·판매 갤러리·디스플레이 소개의 기존 목록은 유지한다.
- 기본 헤더: 중앙 메뉴는 다이닝 → 디스플레이 → 템플릿 → 고객센터 순서다. 로그인 전 오른쪽은 테두리 없는 ‘로그인·회원가입’ → 검정 pill ‘만들기’, 로그인 후에는 테두리 없는 알림 벨 → 세로 구분선 → ‘마이 메뉴’ → ‘만들기’다. 모바일·태블릿의 기본 헤더는 기존 햄버거 메뉴와 로그인 후 알림 진입을 유지한다. 알림은 모든 기기에서 같은 기존 Bell(23px, 선 두께 2.1)을 공유하며 데스크톱의 벨 영역과 세로 구분선 간격은 8px다.
- PC·태블릿(768px 이상): **홈/다이닝·디스플레이 서비스 소개와 그 호환 별칭만** 스크롤 후 메뉴만 남는 글래스 헤더. 로고·만들기·알림·계정·햄버거는 숨긴다.
- 모바일 및 고객센터·템플릿 목록·계정·신청·운영·채팅·법률 등 나머지 경로: 기본 상단 부착 헤더. 모바일 전체 메뉴는 포커스 제한/Escape/포커스 복원을 지원하는 Dialog다.
- 스크롤 200px 이후에는 방향과 무관하게 ‘맨 위로’만 표시한다. 모션 감소 환경은 즉시 이동한다.

## 컴포넌트 표현 기준 (2026-10-18)

- 크기·타이포·콘텐츠 폭·카드 비율은 아티메뉴 기준을 유지한다. 일반 CTA/아이콘 40px, 헤더 CTA 44px, floating/큰 CTA 48px이다. 기능 없는 장식 애니메이션이나 새 컴포넌트 라이브러리는 추가하지 않는다.
- `site-button-secondary`는 옅은 회색 pill, `site-button-outline`는 경계가 필요한 별도 액션이다. 흰 배경/외곽선으로 선언된 기존 액션은 outline 표현을 유지한다. 헤더 텍스트 링크는 배경 없이 색상만 바뀐다.
- 입력창은 현재 16px 라운드/기본 최소 40px 높이와 오류·읽기 전용·비활성 의미를 유지한다. 검색은 회색 pill이다. 네이티브 checkbox/radio는 18px와 공통 검정 선택색을 쓰며 숨겨진 필드·switch는 크기 변경에서 제외한다.
- `site-tabs`/`site-tab`는 52px rail과 40px 탭을 공유한다. 기본 rail은 옅은 회색, 제품 데모는 흰색이다. 선택 상태는 검정/흰색이다. Radix 탭과 공개 갤러리는 같은 클래스로 연결하며 기존 ARIA/키보드 동작을 보존한다.
- 일반 본문·계정 섹션은 열린 구성을 유지한다. 기능 카드만 `site-card-surface`, 선택 가능한 카드는 `site-card-interactive`를 사용한다. 기능 카드/레이어는 16px, 판매 목록 미리보기는 16px, 큰 히어로는 기존 독립 32–48px이다. 고객 메뉴판/미리보기 내부에는 카드 규칙을 전파하지 않는다.
- 배지는 짧은 capsule, dropdown/select 항목은 최소 36px/8px 라운드/옅은 hover를 사용한다. FAQ는 기존 구분선 목록과 열림 상태를 유지하고 `aria-expanded`와 답변 연결을 제공한다.
- 기본 포커스는 파란색 외곽선, 어두운 표면은 흰색 외곽선이다. hover/active는 150ms 색상 전환이며 공통 버튼/탭은 모션 감소 설정에서 전환을 끈다. 오류는 붉은 경계·포커스로 전달한다.
- 위 기준이 과거 컴포넌트 수치와 충돌할 때 현재 기준을 따른다. 기능/인증/결제/API와 메뉴판의 간격·fit·팔레트는 이 시각 변경의 대상이 아니다.

## 템플릿 선택 화면과 정렬 (2026-10-18 사용자 보정)

- 서비스 전환은 검정 선택 pill을 유지하고 가운데 배치한다. 업종은 1024px 이상 세로 카테고리 목록, 768–1023px는 네이티브 select, 767px 이하는 아이콘 원형 버튼과 이름을 나열한 가로 목록이다. 모바일 원은 56px, 아이콘은 22px이며 선택한 원만 검정/흰색이다. 항목이 늘어나면 목록 안에서 가로 스크롤하고 키보드 포커스도 보이는 영역으로 이동한다. 항목 증가를 가로 pill에 의존하지 않는다. 카테고리 변경·서비스 변경 시 페이지는 1로 돌아간다.
- 카드는 4:3 실제 메뉴판 이미지·16px 라운드, 16px/600 상품명, 12px 메타데이터, 13px 설명과 텍스트 액션으로 구성한다. 이미지 우하단의 작은 원형 화살표도 실제 미리보기 링크 안에 있다. 본문은 읽기 편하게 왼쪽 정렬한다. 외곽선은 6%/1px 안쪽이며 그림자는 없다.
- 추천은 기존 featuredBasic/featuredDisplay 데이터에만 연결하고, 작은 회색 글자와 대표색 4px 점으로 표시한다. 임의의 New/인기 주장을 추가하지 않는다. 노란 버튼·노란 선택 탭·채운 추천 배지는 사용하지 않는다.
- 6개씩 나누어 데스크톱 3열을 두 행으로 구성한다. 하단 중앙의 페이지네이션은 검정 선택/8px 라운드 사각형이며 처음·이전·다음·끝을 지원한다. 페이지 번호는 모바일 3개, 640px 이상 7개 창으로 제한해 목록이 커져도 넘치지 않는다.
- 실제 캡처 정본은 `public/template-previews/`에 있으며 `scripts/capture-template-catalog-previews.mjs`로 다시 생성한다. 새 키를 지원 목록과 캡처에 추가하기 전에는 기존 썸네일을 fallback으로 사용한다. 고객 메뉴판 엔진·내부 팔레트·fit은 변경하지 않는다.
- 일반 소개 페이지의 제목·설명·섹션 소개·CTA 그룹은 제한된 콘텐츠 폭 안에서 중앙 정렬한다. 템플릿 목록은 가운데 놓인 컨테이너 안에 카테고리/그리드를 배치한다. 카드 본문·폼·FAQ 질문·법률 본문·계정/편집 사이드바는 읽기와 작업에 필요한 정렬을 유지한다.

## 홈·다이닝 히어로 (2026-10-18)

- 첫 장은 기존 기기 사진, 나머지 세 장은 기존 다이닝/베이커리/커피 사진을 임시로 사용한다. 4초마다 600ms 페이드로 순환한다. 하단 네 개 인디케이터 중 활성 항목은 남은 시간을 보여주는 채움형 pill이며 직접 선택과 재생/정지를 지원한다.
- 진행 표시의 CSS 애니메이션 완료 이벤트가 이미지 전환도 담당해 두 개의 타이머가 어긋나지 않는다. 이미지 로딩 전/화면 밖/문서 비활성/키보드 포커스에서는 진행을 멈춘다. 모션 감소 환경은 기본 정지, 직접 재생 시 페이드 없이 전환한다. 좌우 키와 모바일 가로 스와이프도 지원한다.

- 기기 화면을 교체할 때는 레이어 PSD에서 해당 화면 도형/마스크를 사용해 완성 이미지를 다시 내보낸다. 별도 SVG 좌표 보정을 재도입하지 않는다. 원본 PSD는 보존하고 편집 복사본/참조 내보내기는 로컬 `design/hero/`에 보관한다. 상세 검수는 `docs/qa-hero-psd-composite.md`를 따른다.
- 슬라이드 사진은 `HomeHeroCarousel`의 `SLIDES`에서 교체한다. 이 마케팅 합성 화면과 고객 메뉴판 원본·엔진은 독립적이다.

## 메뉴판 제외 경계

고객 메뉴판의 서체·팔레트·간격·fit·이미지·레이아웃은 변경하지 않는다.
`.menu-typography`, `.aube-table-root`의 루트와 하위 요소, `[data-template-artwork]` 내부는 사이트 UI 호환 선택자에서 제외한다.
사이트 토큰은 `--ui-*`/`--site-*`를 사용한다. 메뉴의 기존 Tailwind 기본 토큰과 `--menu-*`/`--cafe-*`에는 새 값을 주입하지 않는다.
`app/globals.css`의 메뉴 엔진 CSS는 이 작업의 변경 대상이 아니다.
