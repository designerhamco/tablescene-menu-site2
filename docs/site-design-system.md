# ArtiMenu 공식 사이트 디자인 시스템

2026-10-16 사용자 제공 `IMWEB_DESIGN_SYSTEM_FOR_CODEX.md` 적용.
기존 서비스·계정·신청·운영 흐름은 유지하고, 사이트 UI의 시각 규칙을 통일한다.

- 흰 캔버스, 본문 `#15181e`, 보조 `#4b515b`, muted `#717680`, subtle `#f8f9fb`, border `#dbdee3`.
- 문서의 초록 장식 포인트는 ArtiMenu 노랑 `#f8e731`로 대체한다. 노랑 바탕에는 짙은 글자를 사용하며, 넓은 버튼·탭·필터 배경에는 노랑을 사용하지 않는다. 성공·오류·주의·정보의 의미 색상은 별도로 유지한다.
- 주요 CTA·선택 탭은 검정 배경/흰 글자, 보조 버튼은 흰 배경/검정 글자/옅은 테두리로 구분한다. hover·active는 연회색 또는 짙은 회색으로 연결한다. 노랑은 작은 eyebrow 표시 같은 최소 강조에만 사용한다. Hero eyebrow와 체크리스트의 장식용 초록 표현은 제거한다.
- Pretendard, 히어로는 이미지·프레임 비율·라운드·배치·크롭을 유지하고, 타이포·색상만 공통 토큰을 적용한다. 히어로 제목 32/36/48px, 나머지 페이지 제목 32–48px, 섹션 20–24px, 카드 14–16px, 메뉴 14px. 의미 기반 `.type-*` 역할을 사용한다.
- **브랜드 인상: 밝고 둥글둥글하며 친근한 UI.** 버튼·필터는 완전한 pill(`border-radius: 9999px`), 카드 12px, 큰 섹션 16px. 기본 버튼 높이는 40px. 그림자는 팝오버와 글래스 헤더에 제한한다.
- 사용자 요청에 따라 문서의 1160px 컨테이너 대신 기존 히어로 **안쪽 최대 1520px** 기준을 공유한다. 바깥 컨테이너 1600px, 좌우 `clamp(20px, 3vw, 40px)`. `.site-container`와 `.site-gutter`는 동일한 좌우 경계를 만든다. 폼·법률 본문 같은 읽기 영역은 이 안에서 좁은 폭을 유지할 수 있다.
- 갤러리: 992px 이상 3열, 640–991px 2열, 639px 이하 1열, 간격 24px. 선택 탭은 검정 배경/흰 글자, 키보드 좌우/Home/End 탐색을 지원한다.
- PC·태블릿(768px 이상): 1차 메뉴 목적지(다이닝·디스플레이와 호환 별칭, 고객센터, 템플릿 목록)에서만 스크롤 후 메뉴만 남는 글래스 헤더. 로고·만들기·알림·계정·햄버거는 숨긴다.
- 모바일 및 계정·신청·운영·채팅·법률 등 나머지 경로: 기본 상단 부착 헤더. 모바일 전체 메뉴는 포커스 제한/Escape/포커스 복원을 지원하는 Dialog다.
- 스크롤 200px 이후에는 방향과 무관하게 ‘맨 위로’만 표시한다. 모션 감소 환경은 즉시 이동한다.

## 메뉴판 제외 경계

고객 메뉴판의 서체·팔레트·간격·fit·이미지·레이아웃은 변경하지 않는다.
`.menu-typography`, `.aube-table-root`의 루트와 하위 요소, `[data-template-artwork]` 내부는 사이트 UI 호환 선택자에서 제외한다.
사이트 토큰은 `--ui-*`/`--site-*`를 사용한다. 메뉴의 기존 Tailwind 기본 토큰과 `--menu-*`/`--cafe-*`에는 새 값을 주입하지 않는다.
`app/globals.css`의 메뉴 엔진 CSS는 이 작업의 변경 대상이 아니다.
