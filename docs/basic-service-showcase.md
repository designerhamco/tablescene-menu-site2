# 메인 베이직 기능 시연 — 2026-11-19 (현행)

## 범위와 배치

사용자 최종 시안 `흠.jpg`를 따른다. PC·태블릿은 왼쪽에 선택한 기능의 제목·설명과 바로 아래 이전/번호/다음 탐색, 왼쪽 아래 작은 관리 화면 미디어를 둔다. 오른쪽에는 손으로 든 큰 가로 태블릿을 배치한다. 오른쪽 위의 `01 대표영역`, 별도 기능명 목록, 썸네일 갤러리, 확대 팝업과 태블릿 재생 버튼은 없다. 모바일은 기능 제목·설명 → 탐색 → 태블릿 순서이며 관리 화면과 그 보조 제목은 생략한다.

메인의 공통1600px 중앙 콘텐츠 컨테이너, 의미 타이포와 공통 간격 토큰을 사용한다. 배경은 전체 화면을 채운다. 짧은 화면에서는 콘텐츠가 자연스럽게 스크롤되며 텍스트·탐색·목업이 서로 겹치거나 잘리지 않는다. 다이닝·디스플레이와 실제 고객 메뉴판 렌더러는 변경하지 않는다.

## 탐색과 시연

대표 상품·상품 이미지·가격 옵션·기간 할인·콘텐츠 위젯·광고·직원 호출·테이블 주문의8개를 기존 순서로 제공한다. 첫 화면은 별도 서비스 소개 인트로다. 기존 베이직 소개 제목·설명과 전체 메뉴를 보여주는 태블릿으로 시작하고, 관리 화면은 표시하지 않는다. 인트로 탐색 표기는 `소개`이며8개 기능에 포함하지 않는다. 다음 화살표는 대표 상품 `01 / 08`로 이동하고, 대표 상품의 이전 화살표는 인트로로 돌아간다. 화살표 또는 탐색에 포커스한 좌우 키는 기능명·설명·태블릿 시연·관리 화면을 함께 교체한다. 인트로의 이전 화살표와 마지막 기능의 다음 화살표를 비활성화한다. 기능은 타이머로 자동 전환하지 않는다. 실제 주문·호출 연결 조건과 선결제 준비 상태에 관한 기존 문구를 보존한다.

선택한 태블릿 시연은 별도 재생 버튼 없이 자동 반복한다. 코드 예시는 한 기능만 마운트하고 무한 CSS 모션을 사용한다. 향후 MP4/WebM은 muted·playsInline·loop, GIF/이미지는 원본 img로 연결한다. 다른 기능으로 바꾸면 이전 시연을 해제하고 새 시연을 시작한다. 화면 밖, 다음 서비스 프레임에 가려진 상태, 비활성 탭에서는 정지하고 다시 보이면 재개한다. 모션 감소 환경은 정지 예시/포스터를 보여준다. 비디오 실패는 실제 오류 상태로 안내하며 이전 재생 Promise가 새 시연의 상태를 바꾸지 않도록 정리한다.

현재 태블릿 화면은 기존 사진과 교체 가능한 `ServiceFeatureDemo` 코드 예시다. 확정 영상/GIF는 아직 제공되지 않았다. `MarketingFeature.media`는 poster+mp4(+webm) 또는 poster+image를 받는다. `managementMedia`는 별도 관리 화면 소스이며 현재는 미등록이므로 제목과 비활성 재생 자리만 표시한다. 등록된 관리 화면은 공통 `MediaPlayback`으로 수동 재생하며 기능 전환·이탈 시 정지한다. 모바일에서는 관리 미디어를 표시하지 않는다. 시연은 실제 고객 데이터 변경·주문·호출 요청을 보내지 않는다.

## 목업과 조명

승인한 `public/assets/basic-showcase-v1/tablet-hands-cutout.png`(1536×1024 RGBA)를 재사용한다. 손·기기·알파를 재생성하거나 수정하지 않는다. 시안의 기울기에 맞춰 사진만 좌우 반전하며 화면 콘텐츠의 글자는 반전하지 않는다. 사진에 보존된 따뜻한 윤곽광과 별도의 낮은 불투명도 radial-gradient로 은은한 역광을 표현한다. 기존 배경 템플릿 마키는 사용하지 않는다.

화면 네 모서리는 원본 사진 좌표로 등록하고 기존 projective matrix helper로 합성한다. `ResizeObserver`로 실제 장면 너비를 읽어 사진과 화면에 같은 배율을 적용한다. 화면의 글자·모서리·데모는 동일한800×600 시연 캔버스로 유지한다. 이것은 제품 화면을 축소해 보여주는 그래픽이며 사이트 본문 글자 크기나 고객 메뉴판 정책을 바꾸지 않는다.
