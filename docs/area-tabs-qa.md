# 사이트 탭 역할 검수

[최종 역할 계약](tab-hierarchy-contract.md)과 [사용처 점검표](tab-role-audit.md)를 따른다. 주요 화면은 텍스트와 문구 너비의 검정 밑줄, 독립 콘텐츠는 상단8px 영역 탭, 목록 주제는 밑줄, 작은 조건은 필터, 상태값은 회색 레일 안의 흰 선택 세그먼트다. 영역 콘텐츠는 무테 화이트다.

## 자동 검수

- TypeScript로 제품 Tabs의 명시적 purpose와 기존 hierarchy API 제거를 검사한다.
- 기존 컨트롤 계약 테스트로 공통 역할 매핑·사용처·사설 스타일 우회·고객 메뉴판 경계를 확인한다.
- qa:shaped-tabs는 375/820/1440px에서 라이브러리 두 포함 관계의 선택 결과와 실제 템플릿·고객센터·가이드·미리보기·알림 예시를 검사한다. 최상위 텍스트 크기·문구 너비 밑줄·간격·선택 색, 상태 레일·흰 선택 면, 영역8px 모서리·무테 화이트, 키보드·비활성 건너뛰기·가로 넘침을 확인한다.
- 공개 공통 회귀는 qa:public-surfaces로, 로그인 화면은 기존 사용자 세션으로 읽기·내비게이션만 검수한다. 저장·결제·운영 실행은 하지 않는다.

## 결과

2026-10-28 로컬 검수:

- 전체 테스트 877개 통과. 최종 내비게이션 선언 후 컨트롤·매장 운영 계약 13개도 통과.
- TypeScript, 변경 파일 ESLint, Production 빌드 통과. 홈의 기존 img 성능 경고는 유지된다.
- qa:shaped-tabs가 실제 DOM 기준 375/820/1440px에서 모두 통과. 키보드·선택 결과·영역 경계·가로 넘침·브라우저 오류를 함께 확인했다.
- 공개 페이지 13개를 PC 1440×900/모바일 390×844에서 검사했다. 25개 조건이 첫 실행에 통과했고, 모바일 요금 페이지의 일시적인 스크립트 로딩 오류는 해당 경로 PC/모바일 재실행에서 모두 통과했다.
- 접근성 검사에서는 aria-hidden인 공통 푸터의 장식용 대형 워드마크만 제외한다. 실제 본문·링크·컨트롤 검사는 유지한다.

알림 최종 조정: 전체/읽지 않음은 category 밑줄형으로 복원한다. 역할 검수는 라이브러리 알림 예시의 밑줄 선택을 검사하고, 공통 컨트롤 계약은 헤더·알림 페이지가 같은 NotificationPanel을 사용하는지 확인한다.

Production 배포 상태와 같은 역할 검수의 재실행 결과, 기존 로그인 세션의 마이페이지 전체 탭·편집 설정 점검은 해당 배포 PR과 완료 보고에 남긴다. 이전 고정4단계·사각 페이지 탭·고객센터 밑줄 최상위 결과는 현재 기준으로 사용하지 않는다.


## 2026-10-29 최상위 텍스트 탭 변경

- 공통 page 탭은 배경·둥근 테두리를 제거하고 선택 문구 너비의 3px 검정 밑줄을 사용한다. lg는 48px/20px, md는 44px/16px다. 영역 탭·주제·필터·상태 세그먼트는 기존 기준을 유지한다.
- 전체 테스트 906개, 변경 파일 ESLint, TypeScript, 개발 서버와 출력 폴더를 분리한 Production 빌드를 통과했다. 최신 기준 브랜치에 재정렬한 후 전체 909개와 TypeScript도 다시 통과했다.
- 실제 브라우저 DOM 1280×720·820×1180·390×844·320×780에서 템플릿 목록과 공통 라이브러리를 검수했다. 주요 화면 20px/48px, 하위 영역 16px/44px, 투명 배경·문구 너비 밑줄·가로 넘침 0을 확인했다.
- 방향키·Home 이동, 비활성 탭 건너뛰기, hover·pressed·focus·disabled 상태를 확인했다. 상태 세그먼트는 기존 흰 선택 면/2px 테두리, 영역 탭은 8px 상단 모서리를 유지한다.
- 가이드에서도 같은 주요 화면 표현을 확인했다. 기존 로그인 세션의 편집 링크 탭은 PC에서 16px/투명 배경으로 표시되고, 320px 화면에서는 선택한 마지막 링크가 자동으로 가로 스크롤되어 완전히 보였다. 내비게이션만 확인했으며 저장·공개·결제·운영 작업은 실행하지 않았다.
- 앞서 완료한 PR #408·#410·#412는 모두 병합 및 Vercel 성공 상태를 확인했다. PR #413의 반응형·미리보기 작업은 다른 작업에서 독립적으로 병합했으며, 이번 PR 차이에는 포함하지 않는다.
