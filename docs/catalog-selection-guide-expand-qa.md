# 템플릿 선택·사용가이드 펼침 검수

2026-10-24 사용자 승인 범위: 기획안의 선택 흐름을 기존 디자인 시스템에 적용하고 사용가이드의 스크롤 안내를 실제 더보기/접기로 변경한다.

## 템플릿 목록 `/apply`

- 서비스 pill → 디자인/기본 템플릿 밑줄 탭 → 한 줄 설명·해당 요금/교체 범위 → 필터/목록 순서다. 기본 진입은 디자인 템플릿이며 `category=standard&filter=album` 등 기존 명시 URL은 유지한다.
- 기본 템플릿은 화면 구성(전체/리스트형/앨범형), 디자인 템플릿은 업종으로 구분한다. PC 9rem 사이드바, 태블릿 select, 모바일 원형 필터는 기존 사이트 표현을 공유한다. 서비스·종류 전환 시 전체/1페이지로 초기화한다.
- 공통 컨테이너 안쪽 전체 폭을 유지한다. 실제 DOM 폭 320/390/640/767/768/820/1024/1440/1920px에서 가로 넘침 0, 1/2/3열 분기, 정상 로드 이미지, 밑줄 탭 선택 상태와 반응형 필터를 확인했다. 1920px의 콘텐츠 폭은 1520px, 1440px은 1360px이다.
- 베이직 기본 4,900/5,900원·디자인 6,800/7,800원, 다이닝 기본 6,900/8,900원·디자인 8,800/10,800원이 기존 가격 함수와 일치한다. 필터/요금 전환, 2페이지의 마지막 1개, 빈 업종 결과, 전환 시 필터 초기화를 확인했다. 가격/구독 정책 자체는 변경하지 않는다.
- 모바일 390px의 앨범형 2개, 태블릿 820px의 리스트형 4개·카페베이커리 4개 선택을 확인했다. 서비스와 종류 탭은 방향키/Home/End로 선택·포커스가 함께 이동한다.
- 이미지·제목은 상세, 미리보기는 기존 새 창 주소를 유지한다. 좋아요 로직/저장 경로는 변경하지 않으며 실제 계정의 좋아요·결제/신청을 실행하지 않았다. Display는 1개 미리보기와 신청 준비 중을 표시하고 종류/필터는 숨긴다.

## 사용가이드 `/guides`

- PC/태블릿 영상 60%·설명 40%, 16:9 영상, 공통 전체 폭을 유지한다. 긴 설명은 영상 높이 안에서 일부를 보여주고 페이드·40px outline 더보기 버튼으로 이어진다.
- 더보기를 누르면 설명 전체를 자연 높이로 표시하고 접기로 전환한다. 내부 스크롤은 없다. 접은 뒤 버튼 포커스를 유지하며 키보드로 본문 링크에 진입하면 자동으로 펼치고 링크가 화면 안에 보이도록 이동한다.
- 실제 320/390/767/768/820/1024/1440/1920px의 공통 탭과 390/820/1440/1920px Display 탭에서 가로 넘침 0, 모바일 1열·전체 표시·버튼 없음, PC/태블릿 60:40과 접힌 설명/영상 높이 일치를 확인했다. 1920px의 짧은 Display 연결 설명에는 버튼이 없다.
- 더보기/접기 클릭과 Enter 실행, 마지막 출처 링크 키보드 진입, 폰트/크기 변경 재측정, `?plan=dining#dining-fullscreen`의 공통 탭·기존 anchor 유지, Mac 툴바 안내 보존을 확인했다. 기존 ‘아래에 내용이 더 있어요’ 문구는 없다.
- 두 페이지의 검수 탭 브라우저 오류는 0건이다.
