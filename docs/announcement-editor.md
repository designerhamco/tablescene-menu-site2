# 공지사항 본문 에디터

공지 작성의 일반 텍스트 입력을 Tiptap 기반 편집기로 보완한다. 고객센터 검색창도 배경과 구분되도록 공통 입력 토큰의 흰 배경과 테두리를 사용한다.

## 동작

- 굵게·기울임·밑줄, 글자 크기 14/16/20/24/32px에 해당하는 rem 값, 글머리 기호/번호 목록, 글자 서식 지우기, 실행 취소/다시 실행.
- JPG/PNG/WebP 첨부: 장당 3MiB 이하, 글당 10장. 선택한 이미지의 대체 설명을 수정하거나 본문에서 제거할 수 있다. 업로드 중에는 본문 편집과 저장을 잠근다.
- 기존 제목·유형·공개/비공개·상단 고정과 수정 충돌 검사는 유지한다. 기존 일반 텍스트 공지도 편집기에 문단으로 열리며 수정하지 않은 본문은 원문을 유지한다.

## 저장·권한 경계

기존 `support_announcements.body` 텍스트 필드 안에 `[artimenu-richtext-v1]` 접두사와 검증한 JSON 문서를 저장한다. 테이블·RLS·Storage 설정·기존 공지 데이터의 일괄 변경은 없다. 기존 20,000자 제한은 서식 정보를 포함한 저장 크기에 적용한다. 접두사에 줄바꿈을 넣지 않아 브라우저 FormData의 CRLF 정규화와 충돌하지 않으며, 이전 줄바꿈 접두사도 읽는다.

허용된 문단·텍스트·줄바꿈·목록·이미지, 굵게·기울임·밑줄·지정 글자 크기만 서버에서 받는다. 노드 수/깊이/이미지 수/설명 길이를 제한한다. 공개 상세는 같은 검증기를 거친 문서를 React 요소로 구성하며 저장 HTML이나 `dangerouslySetInnerHTML`을 사용하지 않는다. 일반 텍스트의 HTML 문자열은 문자 그대로 표시한다.

`POST /api/admin/announcement-images`는 동일 출처·사용자 인증·기존 `admin_users`를 검사한 뒤 요청 크기를 제한한다. Sharp로 MIME과 실제 포맷을 대조하고 전체 디코딩/재인코딩한다. 정지 raster만 받으며 긴 변 최대 2560px의 WebP로 변환하고 EXIF를 제거한다. 서버 전용 Storage client가 기존 공개 `menu-images` 버킷의 `support-announcements/{admin-user-id}/{asset-id}.webp`에 덮어쓰기 없이 저장한다. 본문은 설정된 Supabase 원본의 해당 불변 경로만 참조할 수 있다.

기존 공개 버킷 특성상 이미지 URL을 아는 경우 글의 비공개 상태와 별개로 접근할 수 있다. 본문에서 제거해도 파일을 hard delete하지 않는다. 수정 취소·이전 본문·다른 관리자 편집의 참조를 보존하며, 저장하지 않은 첨부 파일의 보관/정리는 별도 운영 정책을 따른다.

## 검증

- 일반 텍스트 호환, CRLF 폼 전송, 서식/목록 JSON 왕복, 빈 문서/초과 본문/잘못된 구조/HTML 실행 요소/임의 스타일/외부 URL 거부를 단위 검사한다.
- 실제 이미지 디코딩·크기 조정·WebP 변환·메타데이터 제거, 위장 MIME·SVG·손상/빈/초과 파일 거부를 단위 검사한다.
- 격리 PGlite/HTTP Storage 어댑터에 연결한 최적화 빌드에서 관리자 로그인 → 일반 텍스트 열기 → 서식/이미지 입력 → 저장 → 다시 열기 → 게시 → 고객센터 목록/상세 표시를 검수한다. 실제 운영 계정·공지·파일은 생성/수정하지 않는다.
- API 검수: 비회원 401, 일반 회원/다른 출처 403, 위장 MIME·손상 파일·초과 파일 거부와 거부 요청의 Storage write 0, 관리자 변환 업로드 성공.
- 실제 내부 viewport 360×800, 390×844, 768×1024, 1440×900에서 관리자 화면 가로 넘침 0, 모든 편집 버튼 높이 44px 이상을 확인했다. 숨김 IAB 탭의 viewport 재정의가 반영되지 않아 격리 iframe 문서의 실제 `innerWidth/innerHeight`로 검증했다.
- 검색창은 실제 390px/1280px 문서에서 흰 배경 `rgb(255,255,255)`과 공통 테두리 `rgb(219,222,227)`를 확인했다. 포커스는 기존 공통 입력 계약을 사용한다.

전체 단위 807건, TypeScript, 전체 ESLint와 최적화 빌드를 통과했다. 최종 실제 운영 환경변수 빌드도 완료했다. 2026-10-23 자동 승인 검토가 공개 GitHub 전송에 대한 이번 변경분의 명시적 승인이 없다는 이유로 push를 거절해, 로컬 구현/검수 완료 상태로 운영 배포를 대기한다. 원격 브랜치/PR/운영 배포는 아직 생성하지 않았다. 승인 후 작업 브랜치 `codex/announcement-editor`에서 이어간다.
