# 테이블·키오스크 목록 단순화

2026-11-04. 등록된 항목을 기본적으로 이름·상태·편집 한 행으로 표시하고, 편집을 눌렀을 때 이름·상태 입력, 연결 상태와 연결 관리 링크, 보관·삭제를 펼친다. 보관 목록도 같은 공통 EditableList를 사용하며 복원·삭제는 편집 영역에 둔다. 한 항목만 펼치며 접었다 다시 열어도 미저장 입력을 유지한다.

리스트형·배치도형 선택을 먼저 두고 바로 아래에 테이블 추가·키오스크 추가를 배치했다. 두 보기에서 같은 등록 폼을 사용하며 보기 전환·등록 종류 전환 때 입력을 보존한다. 룸·지도 위치는 기존 배치도 저장 흐름을 유지한다. 상태의 저장값 disabled는 유지하고 문구만 일시정지로, 보관 실행 문구는 미사용(보관)으로 표시한다.

공통 ContentPanel·Collapsible·Button·Badge와 기존 의미별 간격을 사용한다. 목록 전체에 흰 작업 박스 하나를 사용하고 항목마다 별도 카드를 겹치지 않는다. 회색 등록 폼은 경계가 없다. 제목 최소 너비12ch는 styles/site-spacing.css에서 소유해 좁은 화면에서 상태·편집이 다음 줄로 내려간다.
