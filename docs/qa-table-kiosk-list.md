# 테이블·키오스크 관리 표

2026-11-04. 사용자 시안에 맞춰 운영 목록을 종류·이름·공용 태블릿 연결 여부·상태·관리 열이 있는 평면 표로 변경했다. 보기 전환 → 테이블/키오스크 추가 → 운영 목록 제목 → 표 순서다. 회색 헤더, 흰 행과 가로 구분선을 사용하고 별도 행 카드는 넣지 않는다. 공통 `Table variant="management"`가 셀 여백·최소 너비·열 비율·가로 스크롤을 소유한다. 버튼·Switch·Dialog·InfoTooltip은 기존 공통 API를 사용한다.

각 행에서 연결 설정 진입, 사용 중/일시정지 전환, 보관과 삭제를 실행할 수 있다. 이름과 연필을 누르면 이름 수정창이 열린다. 미연결 테이블은 ‘미사용’, 키오스크는 ‘연결 필요’, 연결 조회 실패는 ‘확인 불가’로 구분한다. 안내 아이콘은 휴대폰·QR은 연결이 불필요하고 테이블 태블릿과 키오스크는 연결이 필요함을 설명한다. 연결됨 상태의 안내에는 실제 OS·모델·브라우저 정보를 표시한다. 연결 링크는 기존 주문 설정의 해당 항목으로 이동한다.

상태 전환은 상태와 수정자만 저장하고 현재 상태 조건으로 동시 수정을 검사한다. 이름 수정은 이름만 저장하므로 서로의 값을 덮어쓰지 않는다. 기존 권한 검사·보관 제외 조건·등록/복원·삭제 미리보기와 확인 절차·기기 연결·QR·배치도 저장 동작을 유지한다. 새 SQL이나 운영 설정 변경은 없다. 보관 목록은 기존 편집 펼침 방식과 복원·영구 삭제 진입을 유지한다.

## 검수

- 실제 로그인된 로컬 관리 경로에서 기존 테이블1개·키오스크1개의 표와 연결 링크, 상태 스위치, 보관·삭제 버튼을 확인했다. 등록·저장·보관·복원·삭제·기기 연결을 실제로 제출하지 않았다. 로컬 프로세스에서만 기존 TABLE_MANAGEMENT_ENABLED 플래그를 사용했고 환경 파일·운영 설정은 변경하지 않았다.
- 임시 개발 화면에 실제 컴포넌트와 예시 데이터만 렌더링해 미연결·연결됨·조회 실패, 긴 이름과 직원 권한을 검수했다. 이름 수정창의 Enter·Escape·취소, 닫은 뒤 입력 초안 보존, 보기 전환 중 등록 초안 보존도 확인했다. 브라우저 오류·경고는0건이었다. 임시 경로는 출시 전에 제거했다.
- 실제 DOM viewport320×780·390×844·820×1180·1440×900·1920×1080에서 페이지 가로 넘침0px을 확인했다. 좁은 화면은 이름을 줄바꿈하고 최소832px 표의 region 안에서만 가로 스크롤한다. 셀 여백16px, compact 버튼32px과 공통 Switch44px 터치 영역을 유지했다. 긴 공백 없는 이름도 셀 경계를 넘지 않는다.
- 상태 전환/이름 수정의 필드 분리, 매장·권한·기존 상태 조건과 오류를 격리된 서비스 테스트로 검증했다. 전체 테스트1,065건, 사이트 UI 계약110건, TypeScript·변경 파일 ESLint·프로덕션 빌드를 통과했다.
