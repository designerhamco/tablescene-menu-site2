# 호출·테이블 운영 연결

## 적용 범위

베이직·다이닝은 기본 디자인/디자인 포함 이용권과 무관하게 같은 운영 기능을 사용한다. 실제 접수에는 기존 사이트별 운영 연결, 공개/사용 가능한 메뉴판, 유효한 구독·테이블 세션, 점주의 사용 설정과 작업 권한이 모두 필요하다. 이번 변경은 운영 대상 목록이나 전역 실행 설정을 확대하지 않는다. 메뉴 디자인·모바일 간격은 변경하지 않는다.

메뉴관리 → 주문·호출 설정에서 호출 항목도 편집한다. 기본 항목 불러오기는 현재 편집 내용만 바꾸고 저장해야 반영한다. 손님은 한 번에 하나를 선택하며 최대 5개, 항목명 30자 제한이다. 기존 저장 항목·비활성 항목·과거 호출 스냅샷을 유지한다. 기존 6개 이상 구성은 읽을 수 있고 새 저장 때만 5개 이하로 정리한다.

- 베이직 기본: 물 요청, 식기 요청, 테이블 정리, 계산 요청, 직원 호출.
- 다이닝 기본: 주문 요청, 계산 요청, 와인 문의, 물 요청, 직원 호출.
- 미리보기와 실제 기본 항목은 같은 원본을 따른다. 저장된 항목이 있으면 기본값보다 우선한다.
- 운영 연결 전에는 설정을 미리 준비할 수 있음을 알린다. 연결된 테이블·호출·주문 관리 링크만 표시하며 검수용 페이지 링크는 노출하지 않는다.
- 기존 테이블 이름 변경은 QR을 바꾸지 않는다. 명시적 QR 재발급은 이전 방문 세션을 무효화한다. 단순 이름 변경·설정 확인을 위해 테이블/QR을 자동 재발급하지 않는다.

## 승인 SQL 적용 기록

사용자가 `20261021145548_align_staff_call_service_defaults.sql` 한 건 적용을 명시적으로 승인했다. 운영 tablescene-prod에 원문 7,121자를 대조하고 한 번 실행하여 Success. No rows returned를 확인했다. 일괄 migration 실행은 하지 않았다.

두 기존 RPC만 교체했다. list_menu_call_items는 저장 항목이 없을 때만 서비스별 5개 가상 기본값을 반환한다. replace_menu_call_items는 새 저장의 개수·순서 제한만 최대 5개로 맞추며 기존 행을 이관하지 않는다. 두 함수 모두 security invoker/빈 search_path이고 anon/authenticated 실행 불가, service_role만 실행 가능임을 적용 후 확인했다.

- 실행 기록: `c345c21a-42dc-49a2-b72b-989816711d8d`.
- 함수 본문·권한 읽기 검사: `a72c31ad-ef00-47fe-8d83-1a4a8f218e87`.
- 적용 전후 호출 항목 4건, 호출 3건, 테이블 4건, 방문 세션 22건, 구독 24건, 주문 45건, 결제 40건의 전체 행 SHA-256 지문이 일치했다.
- 실제 운영의 미설정 베이직·다이닝 메뉴에서 읽기 RPC로 각 5개 기본값을 확인했다. 실제 호출·주문·결제·QR 방문/재발급·고객 설정 저장은 검수로 실행하지 않았다.
- 원상 확인 자료: `/private/tmp/call-table-production-before.json`, `/private/tmp/call-table-production-after.json`, `/private/tmp/call-table-sql-applied.jpg`.

## 검증

단위 검사 743건, 임시 DB 및 실제 서버 서비스 통합 44건, 실제 컴포넌트 UI 11건, 타입·변경 파일 린트·최적화 빌드를 통과했다. UI는 베이직/다이닝과 실제 320/390/820/1180/1440px에서 기존 값 보존, 기본 불러오기, 추가/제거/순서/5개 제한, 운영 연결 안내, 가로 넘침과 브라우저 오류를 확인했다. UI의 외부 쓰기 요청은 차단했다.

임시 DB는 실제 호출·테이블·QR migration 및 승인 SQL을 적용한다. 서비스별 기본값, 저장된 기존 6개 보존, 잘못된 저장의 원자적 롤백, 단일 항목 호출, 중복 ID/쿨다운, 접수 후 취소 차단, 다른 매장/폐기/중지 세션 거절, 이름 변경 QR 보존과 명시적 재발급 세션 폐기를 확인한다. 실제 서버 서비스의 읽기·쓰기·권한 차단도 같은 임시 DB에서 실행한다.

운영 배포 후 확인 결과는 다음 절에 기록한다. 남은 단계는 고객 주문내역·상태/취소·결제 표시 연결과 전체 고객 동선 검수다.
