# 유료 메뉴판 운영 기능 자동 연결 (2026-11-02)

## 원인과 현재 계약

결제가 완료된 `261102`도 과거 시범 운영용 UUID 허용 목록에 없어 테이블 등록이 차단됐다. 새 구매마다 환경변수를 수정하는 대신, 유효한 사업자 이용권과 베이직·다이닝 템플릿으로 자격을 판단한다.

- `TABLE_MANAGEMENT_ENABLED`, `CALL_ENABLED`, `POSTPAY_ORDER_ENABLED`, `ORDER_DASHBOARD_ENABLED` 전역 중단 스위치는 유지한다. 해당 네 기능의 과거 `*_ALLOWED_SITE_IDS` 값은 더 이상 판정에 사용하지 않는다. Pickup Queue는 별도 정책을 유지한다.
- 사장님·직원별 권한을 검증한다. 무료·만료·쓰기 불가 이용권, Display·알 수 없는 템플릿은 허용하지 않는다. 주문·호출·매출 관리의 직접 서비스 접근도 최신 이용권과 템플릿을 확인한다.
- 유료 메뉴판은 공개 전에도 테이블을 준비한다. 실제 접수는 공개 상태, 활성 테이블, 유효한 서버 방문 세션, 사장님이 저장한 해당 기능 ON 설정이 모두 필요하다.
- 주문·호출은 자동으로 ON이 되지 않는다. 설정을 켜려면 활성 테이블이 필요하고, OFF 저장은 기존처럼 가능하다. 접수된 주문·호출은 삭제하지 않는다.
- 단말 연결, 개인 기기 1시간 주문 권한, 공용 단말 2분 장바구니 초기화, 전화번호·재주문·중복 요청 처리 계약은 변경하지 않는다.

## 검증

- 전체 단위 테스트 985개, 별도 PostgreSQL 격리 DB/API 검사 176개, TypeScript·배포 빌드·대상 ESLint 통과.
- 격리 DB 검사는 수동 허용 목록이 없는 상태에서 실제 주문 API와 서비스, 만료·회수·다른 방문·직원 권한 및 무료/만료 이용권 거부를 검증한다.
- 운영 DB 스키마·환경변수·주문 설정을 변경하지 않는 코드 수정이다. 실제 테이블 생성·주문·결제·알림톡 발송 없이 운영에서 테이블 등록 폼과 설정 화면을 확인한다.
