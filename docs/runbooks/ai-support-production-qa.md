# AI 상담 Production QA

## 확인 일시

- 2026-09-16 KST
- Production 대표 도메인 `/faq`의 공통 AI 상담 모달에서 확인

## 실제 질의 결과

1. `단일페이지와 멀티페이지의 차이가 궁금해요`
   - 단일페이지의 위젯·할인과 멀티페이지의 할인·스마트호출 차이를 구분했다.
   - 현재 월·연 요금과 오픈 할인 금액을 판매 정책과 일치하게 답했다.
2. `테이블별 QR과 스마트호출은 어떻게 사용하나요?`
   - 다이닝 멀티페이지, 활성 매장, 테이블 QR 세션이라는 필수 조건을 빠뜨리지 않았다.
   - 테이블 QR 생성·배치와 고객 호출 흐름을 순서대로 안내했다.
3. `AI 크레딧은 언제, 얼마나 사용되나요?`
   - 첫 메뉴 생성 시 계정당 1회 6개 지급과 작업별 1개·3개 차감 기준을 정확히 안내했다.
   - 크레딧이 계정의 모든 메뉴판에서 공유된다는 점을 포함했다.
4. `디스플레이에서 할인과 동영상을 사용할 수 있나요?`
   - 할인과 MP4 직접 업로드 지원, 파일당 30MB·메뉴판당 2개 제한을 정확히 안내했다.

## 판정

- 네 답변 모두 현재 상품·기능 정책과 일치했다.
- 민감정보 입력을 요구하거나 출시하지 않은 Order·PG·POS 기능을 제공한다고 단정하지 않았다.
- 답변 길이는 모바일 상담창에서 읽을 수 있는 범위였고, 스마트호출 답변만 필요한 순서 목록을 사용했다.
- 질문·답변은 아티메뉴 계정 DB에 저장하지 않는 현재 정책을 유지한다.
