# 템플릿 교체·상품 등급 계약

최종 갱신: 2026-08-28

## 교체 원칙

- 다이닝 단일 페이지는 단일 페이지끼리, 다이닝 멀티페이지는 멀티페이지끼리만 교체한다. 교체 화면에는 현재 등급과 같은 후보만 노출하며 서버 action도 다른 등급 요청을 거부한다.
- 디스플레이는 디스플레이 템플릿 사이에서만 교체한다.
- 다이닝↔디스플레이 전환은 템플릿 교체가 아니라 별도 메뉴판 생성·메뉴 가져오기 흐름을 사용한다.
- 소유자만 교체할 수 있다. 직원 권한으로는 메뉴를 편집할 수 있어도 상품 등급과 연결된 템플릿은 바꾸지 못한다.
- `available`과 `hidden` 출시 템플릿만 교체한다. `coming_soon`은 서버에서 거부한다.
- 템플릿 교체 화면은 이름만 있는 select 대신 미리보기 썸네일 카드로 제공한다.

## 보존·재검수 범위

| 정보 | 교체 후 처리 |
| --- | --- |
| 메뉴·카테고리·가격·이미지 | 보존 |
| 번역·활성 언어 | 보존 |
| 공개 slug·URL·QR | 보존 |
| 페이지 구성·정렬 | 보존, 새 템플릿 capability가 사용하는 범위만 노출 |
| 타임세일 | 행·번역·대상 보존, 활성 상태만 끄고 재검수 |
| 위젯 | 내용·이미지·번역 보존, 노출 상태만 끄고 재배치 |
| 배경·폰트·배지 | 템플릿별 스냅샷 보존, 해당 템플릿으로 돌아오면 복원 |

교체 처리는 데이터를 삭제하지 않는다. 템플릿 변경이 실패하면 먼저 전환한 할인·위젯 노출 상태를 복구한다.

## 상품 등급

- 다이닝 단일 페이지: 사용자가 확정한 신규 월 5,900원 후보.
- 다이닝 멀티페이지: 사용자가 확정한 신규 월 9,900원 후보. 현재 `cafe_brew_chapter_a`가 해당한다.
- 디스플레이 이미지형: 현재 기본 상품 계약.
- 디스플레이 영상형: 현재 영상 파일 직접 업로드 addon 계약을 보존한다. 영상 템플릿 별도 요금은 추후 상품 표 확정 후 연결한다.

현재 운영 중인 다이닝 월결제 SKU는 단일·멀티 구분 없이 9,900원이며, 코드와 PortOne에는 신규 가격이 아직 연결되지 않았다. 기존 고객 권한을 줄이지 않으면서 신규 SKU, 연결제 가격, 승계 정책을 분리 적용해야 한다. 실제 결제 금액·PortOne 상품은 별도 결제 마일스톤에서 변경한다.

## Order·Call 경계

- 단일·멀티페이지 모두 공통 Call Layer를 사용하며 멀티페이지도 Order 없이 Call만 활성화할 수 있다.
- Order는 템플릿 가격에 자동 포함하지 않는다. 당분간 실제 상품·Production runtime을 활성화하지 않고 기존 default-off 경계를 유지한다.
