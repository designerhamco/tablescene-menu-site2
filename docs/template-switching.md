# 템플릿 교체·상품 등급 계약

최종 갱신: 2026-08-28

## 교체 원칙

- 다이닝 단일 페이지는 단일 페이지끼리, 다이닝 멀티페이지는 멀티페이지끼리만 교체한다. 교체 화면에는 현재 등급과 같은 후보만 노출하며 서버 action도 다른 등급 요청을 거부한다.
- 디스플레이는 디스플레이 템플릿 사이에서만 교체한다.
- 다이닝↔디스플레이 전환은 템플릿 교체가 아니라 별도 메뉴판 생성·메뉴 가져오기 흐름을 사용한다.
- 소유자만 교체할 수 있다. 직원 권한으로는 메뉴를 편집할 수 있어도 상품 등급과 연결된 템플릿은 바꾸지 못한다.
- `available`과 `hidden` 출시 템플릿만 교체한다. `coming_soon`과 `retired`는 서버에서 거부한다.
- 템플릿 교체 화면은 이름만 있는 select 대신 미리보기 썸네일 카드로 제공한다.
- 현재 템플릿은 큰 중복 미리보기 카드 없이 이름과 페이지 등급만 표시한다. 실제 썸네일 카드는 교체 후보에만 사용한다.
- 누아 메뉴는 신규 생성·구매·교체 후보에서 제외한다. 기존 저장 데이터의 안전한 표시를 위해 renderer와 starter 호환성만 유지한다.

## 보존·재검수 범위

| 정보 | 교체 후 처리 |
| --- | --- |
| 메뉴·카테고리·가격·이미지 | 보존 |
| 번역·활성 언어 | 보존 |
| 공개 slug·URL·QR | 보존 |
| 페이지 구성·정렬 | 보존, 새 템플릿 capability가 사용하는 범위만 노출 |
| 타임세일 | 행·번역·대상 보존, 활성 상태만 끄고 재검수 |
| 위젯 | 내용·이미지·번역 보존, 노출 상태만 끄고 재배치 |
| 배경·폰트·배지 | 템플릿별 스냅샷 보존, 해당 템플릿으로 돌아오면 복원 |

교체 처리는 데이터를 삭제하지 않는다. 템플릿 변경이 실패하면 먼저 전환한 할인·위젯 노출 상태를 복구한다.

## 상품 등급

- 다이닝 단일 페이지: 정상가 월 8,900원, 오픈할인 월 5,900원. 연결제는 오픈할인 월 금액 × 12개월에서 10% 할인 후 100원 단위로 내림한 63,700원이다.
- 다이닝 멀티페이지: 정상가 월 12,900원, 오픈할인 월 9,900원. 연결제는 오픈할인 월 금액 × 12개월에서 10% 할인 후 100원 단위로 내림한 106,900원이다. 현재 `cafe_brew_chapter_a`가 해당한다.
- 디스플레이 이미지형: 현재 기본 상품 계약.
- 디스플레이 영상형: 현재 영상 파일 직접 업로드 addon 계약을 보존한다. 영상 템플릿 별도 요금은 추후 상품 표 확정 후 연결한다.

신규 구매에는 단일·멀티 월결제/연결제 SKU를 사용하고 결제 화면과 서버 preflight·완료 검증·자동 갱신·환불·재구독 복구를 같은 금액으로 연결한다. 기존 `business_basic_monthly`·`business_basic_yearly` 구독은 가격과 템플릿 권한을 강제로 바꾸지 않고 기존 고객 호환 상품으로만 유지한다. 신규 상품은 단일 상품으로 멀티 템플릿을 구매하거나 그 반대로 우회할 수 없도록 서버에서도 거부한다.

## Order·Call 경계

- 단일·멀티페이지 모두 공통 Call Layer를 사용하며 멀티페이지도 Order 없이 Call만 활성화할 수 있다.
- Order는 템플릿 가격에 자동 포함하지 않는다. 당분간 실제 상품·Production runtime을 활성화하지 않고 기존 default-off 경계를 유지한다.
