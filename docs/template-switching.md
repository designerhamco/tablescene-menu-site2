# 템플릿별 구독·메뉴 이전 계약

최종 갱신: 2026-09-29

## 구독 원칙

- 신규 월 구독 1건은 선택한 디자인 템플릿 1개와 메뉴판 1개에 연결된다.
- 다른 템플릿을 이용하려면 해당 템플릿을 별도로 구독해야 하며, 기존 구독 내에서 템플릿을 무제한 교체하지 않는다.
- 기존 메뉴 데이터는 `메뉴 가져오기`로 새로 구독한 템플릿의 메뉴판에 복사할 수 있다.
- 메뉴·카테고리·가격·설명·이미지 등 공통 콘텐츠는 가져오되, 레이아웃·폰트·색상·위젯 배치 등 디자인 설정은 새 템플릿 기본값을 사용한다.
- 기존 연결제 상품과 이미 생성된 메뉴판은 결제·갱신·해지·환불 호환성을 위해 유지하지만 신규 판매하지 않는다.

## 보존·재검수 범위

| 정보 | 교체 후 처리 |
| --- | --- |
| 메뉴·카테고리·가격·이미지 | 보존 |
| 번역·활성 언어 | 보존 |
| 공개 slug·URL·QR | 보존 |
| 페이지 구성·정렬 | 보존, 새 템플릿 capability가 사용하는 범위만 노출 |
| 타임세일 | 행·번역·대상 보존, 활성 상태만 끄고 재검수 |
| 위젯 | 내용·이미지·번역 보존, 노출 상태만 끄고 재배치 |
| 배경·폰트·배지 | 템플릿별 스냅샷 보존, 해당 템플릿으로 돌아오면 복원 |

메뉴 가져오기는 원본 메뉴판을 삭제하거나 구독 상태를 변경하지 않는다.

## 상품 등급

- 원페이지: 기존 출시 템플릿 모두 정상가 월 5,900원, 오픈 얼리버드 월 4,900원. 추후 지정된 템플릿만 정상가 4,900원으로 분리한다.
- 다이닝 멀티페이지: 정상가 월 8,900원, 오픈 얼리버드 월 6,900원.
- 디스플레이: 정상가 월 12,900원, 오픈 얼리버드 월 10,900원.
- 오픈 얼리버드는 2026년 10월 1일부터 12월 31일까지 가입한 신규 월 구독에 적용하며, 구독을 중단 없이 유지하는 동안 가입 가격으로 갱신한다.
- 30일 무료체험은 위 월 구독 전체를 통틀어 계정당 최초 1회만 제공한다.

신규 구매는 월결제 SKU만 사용하고 결제 화면과 서버 preflight·완료 검증·자동 갱신·재구독 복구를 같은 확정 금액으로 연결한다.

## Order·Call 경계

- 단일·멀티페이지 모두 공통 Call Layer를 사용하며 멀티페이지도 Order 없이 Call만 활성화할 수 있다.
- Order는 템플릿 가격에 자동 포함하지 않는다. 당분간 실제 상품·Production runtime을 활성화하지 않고 기존 default-off 경계를 유지한다.
