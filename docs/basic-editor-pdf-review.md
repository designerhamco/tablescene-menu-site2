# 베이직 메뉴판 구성 PDF 대조

2026-11-24. 사용자 제공 「메뉴 편집 페이지」 PDF의 카테고리 설정·메뉴아이템 설정 두 화면을 기준으로 비교했다. 이 문서는 다른 여섯 탭의 검수 완료를 뜻하지 않는다.

| 위치 | 이전 구현의 차이 | 수정 기준 |
| --- | --- | --- |
| 메뉴판 구조 | 상품 선택 시 카테고리·위젯 추가가 사라짐 | 두 편집 화면에서 같은 추가 도구 유지 |
| 카테고리 선택 화면 | 초기 진입·상품 편집 복귀 시 기존 요약과 등록된 메뉴 아이템 목록이 다시 표시될 수 있음 | 카테고리 선택 상태에서 설정으로 바로 이동하고, 등록된 아이템은 설정 버튼 아래 별도 목록에서 표시 |
| 구조 목록 | 행이 과도하게 높고 선택 상품이 회색 | 공통 compact 조작 크기, 선택 항목 검정 표시 |
| 배치 방식 | 회색 카드와 공통 설명 | 열린 두 선택 행, 각 선택지의 도움말 |
| 카테고리 이름·순서 | 숫자 순서 입력 | 이름과 위치 드롭다운 한 줄, 전체 형제 순서 함께 변경 |
| 카테고리 설명 | 큰 textarea, 분리된 스위치 | 한 줄 입력, 제목 옆 사용 여부 |
| 가격 옵션 컬럼 | 개별 숨기기 추가 | 추가 입력줄, 위/아래·이름·수정→등록·삭제 |
| 메뉴아이템 배지 | 선택·문구·색상·미리보기 여러 단락 | 넓은 화면에서 한 줄, 작은 화면에서는 줄바꿈 |
| 상품 이미지 | 사용 여부 없음 | 원본을 보관하는 사용 여부 스위치, 파일 선택·썸네일 |
| 가격 입력 방식 | 설명이 들어간 큰 선택 카드 | 숫자 가격·직접 표시 문구 선택과 각 도움말 |
| 상품 옵션 | 빈 행 추가 후 바로 편집·삭제 | 새 옵션 입력·추가, 순서 이동, 수정→등록·삭제 |
| 고객 요청사항 | 스위치와 라벨의 배치 차이 | 요청사항 패널의 오른쪽 스위치 |
| 타임세일 | 관리 이름·추가 활성화 스위치 노출 | 사용 여부 하나, 할인 일정 → 시작·종료·표시 방식 → 배지 |
| 노출 방식 | 정렬 숫자·전체 메뉴 표시 추가 | 가격 노출 여부·품절 여부 두 스위치 |
| 하단 작업 | 반영·취소와 최종 저장을 나눈 두 단계 | 최종 저장·복사·삭제 한 묶음; 편집 중인 값도 최종 제출 |

폰트·버튼·필드는 공식 사이트의 공통 역할과 크기를 사용한다. 모바일 편집창은 상위 컨테이너에 잘리지 않도록 화면 전체에 표시하고 목록 복귀·스크롤 접근을 유지한다.

PDF에 그려지지 않은 실제 **할인가 입력**은 할인 저장에 필수이므로 할인 일정 다음에 유지한다. 기존 데이터의 허용 글자 수와 가격 검증은 변경하지 않는다. 상품 이미지 OFF는 원본 경로를 지우지 않으며 해당 상품의 이미지 표시만 끈다. 기존 이미지 표시와 배지의 자동 글자색은 새 설정이 없는 경우 유지된다.

검수는 실제 컴포넌트를 사용하는 격리된 로컬 예시 데이터에서 진행한다. 운영 데이터 쓰기나 실제 결제·AI 실행은 포함하지 않는다. 최종 저장의 제출 데이터, 새 상품 추가, 상품 옵션의 추가·이동·수정, 배지 색상, 이미지 OFF, 타임세일 값과 모바일 창의 위치를 확인한다.

2026-11-25 수정. 카테고리 설정 아래에 최종 저장·복사·삭제를 배치한다. 등록된 아이템은 그 아래 구분선 목록으로 표시한다. 대표 영역·메뉴 구성·디자인의 복원 버튼은 ‘템플릿 샘플로 되돌리기’라는 이름을 사용한다. 디자인 복원은 디자인 설정 바로 아래에 둔다.

디자인 설정은 저장한 메뉴판을 템플릿 미리보기와 같은 기기 프레임과 디자인 패널에 표시한다. 기기 전환·회전·실제 화면 보기를 제공하며, 호출·주문 및 배치 방식 전환을 제외하고 디자인 반영을 배치한다. ‘디자인 반영’은 편집한 값을 디자인 탭으로 가져온다. 디자인 탭의 ‘최종 저장’에서 패턴 띠 설정과 함께 확정한다.

베이직 디자인 탭에서 템플릿 샘플 복원도 임시 변경으로 처리한다. 미리보기의 도구막대 첫 항목인 ‘편집기로 돌아가기’는 미리보기 진입 전에 반영했던 초안을 유지한다.
