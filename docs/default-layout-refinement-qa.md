## 정책

- 기본 베이직 1열/중앙열 대표 이미지만 전 기기 4:5로 보존한다. PC/태블릿은 가용 높이 안에서 이미지 너비도 줄인다. 개별 상품 정사각형 썸네일, 기존 디자이너 템플릿, 상단행 이미지, 좌상단 4:3은 변경하지 않는다.
- 좌상단 대표상품 보기의 기본값은 OFF다. 쿼리/체크의 명시적 ON/OFF는 우선한다. 대표 이미지 자체는 계속 표시한다.
- 중앙열 호출/주문은 대표열의 아래에 세로로 고정한다. 메뉴 양쪽은 기존 하나의 스크롤 영역을 사용한다. 다른 구조의 메뉴 하단 버튼, 모바일 상단/하단 동선은 유지한다.
- 기본 상단행 가게 설명만 길게 구성하고 네 언어를 명시적으로 번역한다. 폰트 크기나 헤더 높이 정책을 억지로 바꾸지 않는다.
- 기본 다이닝 좌측 내비게이션은 #f4f5f3이다. 원래 디자이너 B의 내비게이션 테마는 유지한다.
- 다이닝 A/B 공통 렌더러의 실제 컨테이너 768px 이상에서 상품명/보조명/설명/가격과 코스 설명/가격을 1.06배로 표시한다. 페이지/카테고리/코스 제목은 그대로다. 모바일은 1배를 유지한다.
- 묶음형/채움형은 삭제하지 않는다. 동일 기기 크기/간격과 읽기 규칙을 공유하며 카테고리 분할만 다르다. 전개 후 사용자 판단 항목이다.
